시스템 오디오 캡처는 내 마이크 소리에 더해, 컴퓨터가 스피커나 헤드셋으로 내보내는 소리를 함께 녹음하는 기능입니다. 화상회의에서 상대방의 목소리까지 회의록에 남기고 싶을 때 씁니다.

## 언제 쓰나요

| 상황 | 시스템 오디오 캡처 |
|---|---|
| 한 회의실에서 사람들이 모여 대화하는 회의 | 필요 없습니다. 마이크만으로 충분합니다. |
| 화상회의 앱으로 진행하는 온라인 회의 | 켜 두면 상대방 목소리가 함께 기록됩니다. |
| 동영상·강연 영상을 보며 내용을 정리할 때 | 켜 두면 재생되는 소리가 기록됩니다. |

## 사용 조건

- 데스크톱 앱(macOS, Windows)에서만 쓸 수 있습니다. 웹 브라우저로 접속했거나 모바일 앱이면 스위치가 보이지 않습니다.
- 라이브 녹음 화면에서 설정합니다. 라이브 녹음 화면 자체는 [라이브 녹음](../live/)을 보세요.
- macOS에서는 운영체제가 화면·시스템 소리 녹화 권한을 물어볼 수 있습니다. 이때 허용해야 컴퓨터 소리가 잡힙니다.
- Windows에서는 기본 출력 장치(현재 소리가 나오는 스피커나 헤드셋)에서 나오는 소리를 가져옵니다.

## 켜고 끄는 방법

1. 라이브 녹음 화면 위쪽 컨트롤 바의 오른쪽에서 모니터 모양 아이콘 옆의 스위치를 찾습니다. 마우스를 올리면 「시스템 오디오 캡처」라고 나옵니다.
2. 스위치를 켭니다. 켜면 모니터 아이콘이 보라색으로 바뀝니다.
3. 「회의 시작」을 눌러 녹음합니다. 스위치를 미리 켜 두었다면 녹음이 시작될 때 함께 시작됩니다.
4. 녹음 도중에도 스위치를 켜거나 끌 수 있습니다. 켜는 즉시 컴퓨터 소리 녹음이 시작되고, 끄면 곧바로 멈춥니다.

![시스템 오디오 캡처 스위치](../../../assets/screens/live-system-audio-toggle.png)

:::note
스위치 상태는 저장되지 않습니다. 회의 화면에 새로 들어가면 다시 꺼진 상태에서 시작하므로, 필요한 회의마다 켜 주세요.
:::

## 어떻게 기록되나요

- 마이크 소리와 컴퓨터 소리는 하나로 섞여 녹음됩니다. 회의가 끝난 뒤 다시 들을 때도 두 소리가 함께 재생됩니다.
- 섞인 소리는 마이크 소리와 같은 방식으로 음성 인식에 들어가 자막이 됩니다. 별도의 설정 없이 「라이브 기록」에 상대방 말이 이어서 나타납니다.
- 컴퓨터 소리는 보통 마이크보다 작게 잡히므로, 앱은 조용한 소리도 놓치지 않도록 컴퓨터 소리 쪽의 말 감지 기준을 더 민감하게 두고, 말 사이의 짧은 쉼도 더 길게 허용합니다.
- 켜진 상태에서는 컴퓨터가 내는 모든 소리가 기록됩니다. 알림음이나 음악도 포함될 수 있습니다.

## 소리가 안 잡히거나 이상할 때

| 증상 | 확인할 것 |
|---|---|
| 상대방 목소리가 자막에 안 나옴 | 스위치가 켜져 있는지, 상대방 소리가 실제로 컴퓨터에서 재생되고 있는지 확인합니다. macOS는 운영체제 설정에서 앱의 녹화 권한이 허용되어 있는지도 봅니다. |
| 같은 말이 두 번 기록됨 | 스피커로 소리를 내고 있으면 마이크가 스피커 소리를 다시 주워 중복됩니다. 헤드셋을 쓰거나 스위치를 끄세요. |
| 켰는데도 컴퓨터 소리가 안 들어감 | 스위치를 껐다 켜거나, 녹음을 다시 시작해 보세요. 그래도 안 되면 앱을 다시 실행합니다. |
| 스위치가 아예 안 보임 | 웹 브라우저나 모바일 앱에서는 표시되지 않습니다. 데스크톱 앱인지 확인하세요. |

:::tip
상대방 목소리를 더 또렷하게 기록하려면 헤드셋을 쓰는 것이 좋습니다. 마이크가 스피커 소리를 다시 주워 담는 일이 줄어 자막 품질이 좋아집니다.
:::

:::caution
다른 사람의 목소리를 녹음하는 일이므로, 회의 참석자에게 녹음 사실을 미리 알리고 각 조직의 녹음 지침을 지켜 주세요.
:::
