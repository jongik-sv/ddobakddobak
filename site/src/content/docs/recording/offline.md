오프라인 녹음은 Android 앱에서 서버에 연결하지 않고도 폰 안에서 녹음하고 음성 인식까지 처리하는 기능입니다. 지하 회의실이나 이동 중처럼 네트워크가 불안정한 곳에서 씁니다. 기록은 폰에 저장되고, 나중에 서버에 연결되면 올려서 공유·검색·요약을 쓸 수 있습니다.

:::note
오프라인 회의는 Android 앱에서만 쓸 수 있습니다. 데스크톱 앱과 웹에서는 이 화면이 제공되지 않습니다.
:::

## 오프라인 회의와 일반 회의의 차이

| 항목 | 일반(서버) 회의 | 오프라인 회의 |
|---|---|---|
| 음성 인식 | 서버에서 처리 | 폰 안에서 처리(온디바이스) |
| 저장 위치 | 서버 | 폰 |
| 화자 분리 | 가능 | 지원하지 않음 |
| 지원 언어 | 여러 언어 | 한국어 등 단일 언어 |
| AI 회의록·메모 | 가능 | 사용할 수 없음(서버에 올린 뒤 가능) |
| 공유·검색 | 가능 | 서버에 올린 뒤 가능 |

## 시작하기

오프라인 회의 화면에 들어가는 길은 두 가지입니다.

- 서버를 한 번도 설정하지 않았거나 로그인하지 않은 상태에서는 시작 화면 맨 아래의 「서버 없이 오프라인으로 시작 →」 링크를 누릅니다. 서버 설정 화면과 로그인 화면에 모두 있습니다. 자세한 내용은 [첫 실행](../../start/first-run/)을 보세요.
- 서버 모드에서는 「오프라인 회의」 화면의 뒤로 가기 단추(「서버 모드로」)로 서버 모드와 오갑니다.

## 1단계. 온디바이스 모델 받기

오프라인 전사를 하려면 음성 인식 모델을 폰에 한 번 받아 두어야 합니다. 「오프라인 회의」 화면 위쪽의 「온디바이스 모델」 영역에서 받습니다.

![오프라인 회의 홈과 모델 관리](../../../assets/screens/offline-home.png)

1. 「오프라인 회의」 화면 위쪽에서 「온디바이스 모델」 영역을 확인합니다. 아직 받지 않았으면 「오프라인 전사를 쓰려면 모델(~2.7GB)을 한 번 받아야 합니다. Wi-Fi + 충분한 저장공간 권장.」이라고 나옵니다.
2. 「모델 다운로드」를 누릅니다. 「모델 다운로드 중...」 표시와 함께 받기가 진행됩니다.
3. 받기가 끝나면 「준비됨 · 용량 (오프라인 전사 가능)」으로 바뀝니다.

- 모델을 받을 때는 서버에 연결되어 있어야 합니다. 서버에 연결되지 않은 상태에서는 「서버에 연결되어 있어야 다운로드할 수 있습니다.」가 함께 보이고, 받기를 시도하면 「서버에 연결되어 있어야 모델을 받을 수 있습니다. Wi-Fi로 회의 서버에 연결한 뒤 다시 시도하세요.」라고 안내합니다. 오프라인으로 나가기 전에 미리 받아 두세요.
- 용량이 크므로 Wi-Fi 환경과 충분한 저장 공간에서 받으세요.
- 모델을 지우려면 「모델 삭제」를 누르고, 「삭제할까요?」 확인에서 「삭제」를 누릅니다. 취소하려면 「취소」를 누릅니다.

## 2단계. 전사 위치 정하기

서버에 닿을 때도 이 폰에서 전사할지, 서버에서 전사할지를 정합니다. 설정 화면의 「개인설정」 탭에 있는 「전사 위치 (온디바이스)」에서 고릅니다. 자세한 내용은 [개인설정](../../settings/personal/)을 보세요.

| 선택지 | 뜻 |
|---|---|
| 자동 | 서버 연결이 안 되면 자동으로 온디바이스 전사를 합니다. |
| 서버 | 항상 서버에서 전사합니다(화자분리·다국어·태국어 지원). |
| 온디바이스 | 항상 폰에서 전사합니다(오프라인, 단일언어, 화자분리 없음). |

같은 곳의 「로컬 회의 서버로 전송」 체크를 켜면, 온디바이스로 만든 회의의 기록과 오디오를 서버에 올려 공유·검색·요약을 쓸 수 있게 합니다.

서버 회의를 녹음하던 중 서버에 닿지 못해 이 폰에서 전사하게 되면 화면 맨 아래 상태 표시줄에 「온디바이스 STT」가 나타납니다. 이때 전사는 서버 회의록이 아니라 폰에 저장됩니다.

## 3단계. 오프라인 회의 녹음하기

1. 「오프라인 회의」 화면에서 「오프라인 회의 시작」을 누릅니다. 「오프라인 회의 2026-..」처럼 날짜가 붙은 제목으로 새 회의가 만들어지고 녹음 화면이 열립니다.
2. 위쪽 컨트롤의 「회의 시작」을 누릅니다. 모델을 불러오는 동안 「모델 로딩 중...」이 표시됩니다. 불러오기가 끝나기 전에 눌러도 준비되면 자동으로 시작됩니다.
3. 녹음 중에는 위쪽에 경과 시간이 보이고, 「기록」 탭에 인식된 말이 자막으로 쌓입니다.
4. 「일시정지」·「재개」로 잠시 멈추거나 이어갈 수 있고, 마치려면 「종료」를 누릅니다.

![오프라인 녹음 화면](../../../assets/screens/offline-live.png)

- 모델이 없으면 「기록」 탭에 「오프라인 전사를 시작하려면 먼저 온디바이스 모델을 받아야 합니다.」와 모델 받기 영역이 나옵니다. 「회의 시작」을 누르면 「온디바이스 모델을 먼저 받아주세요. (아래 기록 탭)」 안내가 뜹니다.
- 화면 맨 아래 상태 표시줄에는 음성 인식 엔진으로 「온디바이스」가 표시됩니다.
- 녹음 화면은 「기록」 탭 하나로 구성됩니다. 오프라인에서는 AI 회의록과 AI 챗을 사용하지 않습니다. 실시간 녹음 화면의 일반 구성은 [라이브 녹음](../live/)을 보세요.

:::caution
녹음 중에 뒤로 가기를 누르면 녹음이 자동으로 종료되고 저장된 뒤 목록으로 돌아갑니다. 녹음을 이어갈 생각이라면 뒤로 가지 말고 「일시정지」를 쓰세요.
:::

## 오프라인 회의 목록

「오프라인 회의」 화면 아래쪽 목록에 기기에 저장된 오프라인 회의가 보입니다. 각 항목에는 제목, 만든 날짜, 언어, 저장 상태가 표시됩니다.

| 표시 | 뜻 |
|---|---|
| 기기 저장 | 아직 서버에 올리지 않고 폰에만 있습니다. |
| 서버 동기됨 | 서버에 올라가 있습니다. 오른쪽에 초록 체크가 표시됩니다. |

항목 오른쪽의 단추는 다음과 같습니다.

- 「서버로 업로드」(구름 아이콘): 이 회의 하나를 서버에 올립니다. 아직 서버에 올리지 않은 회의에만 보입니다.
- 「삭제」(휴지통 아이콘): 누르면 「삭제」와 「취소」가 나란히 나타납니다. 「삭제」를 한 번 더 눌러야 지워집니다.

항목을 누르면 오프라인 회의 상세 화면으로 이동합니다.

## 오프라인 회의 상세 화면

![오프라인 회의 상세 화면](../../../assets/screens/offline-detail.png)

위쪽에는 뒤로 가기, 제목, 그리고 다음 단추가 있습니다.

| 단추 | 하는 일 |
|---|---|
| 이름 수정(연필) | 제목을 고칩니다. 확인은 「저장」, 취소는 「취소」입니다. |
| 녹음 이어하기 | 이 회의에 이어서 녹음합니다. 녹음 화면이 열리고 기존 타임라인을 이어받습니다. |
| STT 재전사 | 저장된 전체 녹음을 다시 인식해 전사를 새로 만듭니다. 라이브 중의 조각 인식보다 정확도가 오를 수 있습니다. |
| 서버로 업로드 | 이 회의를 서버에 올립니다. 올린 뒤에는 이 단추가 사라집니다. |
| 더보기 | 「내보내기」 시트를 엽니다. |

- 본문의 「기록」 탭에는 전사가 보입니다. 항목을 누르면 그 지점부터 재생됩니다. 오프라인 회의의 전사는 읽기 전용이라 글자를 고칠 수 없습니다.
- 「요약」, 「메모」 탭은 흐리게 표시되며 눌러지지 않습니다. 열어 보면 「오프라인 회의는 AI 요약을(를) 사용할 수 없습니다.」처럼 안내합니다. 서버에 올린 뒤 서버 회의 화면에서 쓸 수 있습니다.
- 오디오가 있으면 화면 아래쪽 미니 플레이어(모바일)로 재생합니다. 플레이어를 눌러 펼칠 수 있습니다.

### STT 재전사

1. 위쪽의 「STT 재전사」(회전 화살표) 단추를 누릅니다.
2. 「재전사 준비 중…」에 이어 「재전사 중… 3/12」처럼 진행 상황이 아래쪽에 나옵니다.
3. 끝나면 「기록」 탭이 새 전사로 바뀝니다.

실패하면 「재전사 실패: 이유 (탭하여 닫기)」가 나옵니다. 흔한 이유는 다음과 같습니다.

- 「재전사할 연속 녹음이 없습니다.」: 저장된 연속 녹음이 없을 때입니다.
- 「온디바이스 모델이 없습니다. 먼저 모델을 받아주세요.」: 모델을 받지 않았을 때입니다.

### 내보내기

위쪽의 「더보기」를 누르면 「내보내기」 시트가 열립니다.

- 「텍스트(.txt) 내보내기」
- 「마크다운(.md) 내보내기」
- 「오디오 내보내기」: 저장된 오디오가 있을 때만 눌러집니다.

## 서버에 올리기

서버에 연결되면 오프라인 회의를 서버 회의로 올릴 수 있습니다. 올린 뒤에는 AI 회의록, 검색, 공유, 내보내기를 모두 쓸 수 있습니다.

- 회의마다 올리기: 목록이나 상세 화면의 「서버로 업로드」를 누릅니다. 이미 올린 회의에 다시 올려도 중복으로 쌓이지 않습니다.
- 자동으로 올리기: 「개인설정」 탭의 「로컬 회의 서버로 전송」을 켜 두면, 온디바이스로 만든 회의의 기록과 오디오가 서버로 전송됩니다.

:::tip
오프라인 회의를 서버에 올린 뒤에 화자를 구분하고 싶으면, 서버 회의 화면에서 [화자 분리와 이름 바꾸기](../../minutes/speakers/)의 방법을 쓰세요.
:::

## 문제가 생기면

- 모델 받기가 계속 실패하면 Wi-Fi와 서버 연결 상태, 저장 공간을 확인하세요.
- 인식 결과가 부정확하면 「STT 재전사」를 시도해 보세요.
- 그 밖의 증상은 [문제 해결](../../help/troubleshooting/)을 보세요.
