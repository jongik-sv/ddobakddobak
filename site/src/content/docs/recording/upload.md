회의를 실시간으로 녹음하지 못했더라도, 따로 녹음해 둔 오디오 파일을 올리면 같은 방식으로 전사와 AI 회의록을 만들 수 있습니다. 여러 파일을 순서대로 이어 하나의 회의로 만들 수도 있습니다.

## 지원하는 파일 형식

| 확장자 | 비고 |
|---|---|
| mp3, wav, m4a, aac | 일반적인 음성 파일 |
| webm, ogg, flac | 브라우저·녹음 앱에서 만든 파일 |
| mp4 | 영상 파일에서 소리를 가져옵니다. |

다른 확장자의 파일은 오디오 업로드로 받아들여지지 않습니다.

## 업로드하는 방법

업로드는 세 가지 길이 있습니다. 어느 쪽이든 같은 「오디오 파일로 회의록 작성」 창이 열립니다.

### 방법 1. 회의 목록의 단추

1. 「회의 목록」 화면 오른쪽 위의 「오디오 업로드」 단추를 누릅니다. 모바일에서는 위쪽 아이콘(마우스를 올리면 「오디오 파일 업로드」)을 누릅니다.
2. 열린 창의 점선 영역을 눌러 파일을 고르거나, 파일을 끌어다 놓습니다.

### 방법 2. 회의 목록 화면에 끌어 놓기

회의 목록 화면에 오디오 파일을 끌어 오면 화면 전체에 「파일을 놓아 추가」 안내가 나타납니다. 놓으면 같은 창이 파일이 채워진 채로 열립니다.

### 방법 3. 앱 어느 화면에서든 끌어 놓기

대시보드, 검색, AI 챗, 설정 화면처럼 회의 목록이 아닌 곳에서도 오디오 파일을 앱 창으로 끌어 놓으면 업로드 창이 열립니다.

- 오디오 파일이 아닌 파일만 놓으면 「오디오 파일만 업로드할 수 있습니다.」 안내가 나옵니다. 오디오와 다른 파일을 섞어 놓으면 오디오 파일만 가려서 받습니다.
- 프로젝트를 고르지 않은 상태(첫 화면 등)에서는 올릴 곳이 정해지지 않아 끌어 놓기가 동작하지 않습니다. 먼저 프로젝트를 선택하세요. 프로젝트 선택은 [프로젝트 선택](../../start/project-select/)을 보세요.
- 이미 업로드 창이 열려 있으면 창 안의 점선 영역이 이어서 받습니다.
- 이 방식으로 올린 회의는 프로젝트의 맨 위(폴더 밖)에 만들어집니다.
- 회의 목록과 회의 상세 화면에서는 각자의 끌어 놓기 처리가 따로 있습니다. 회의 상세 화면에서의 동작은 이 쪽의 「이미 녹음이 있는 회의에 오디오 붙이기」를 보세요.

## 업로드 창의 항목

![오디오 파일로 회의록 작성 창](../../../assets/screens/upload-audio-modal.png)

1. 파일 영역: 점선 상자입니다. 파일을 고르면 파일 이름과 크기가 보입니다. 안내 문구는 「오디오 파일을 드래그하거나 클릭하여 선택 (다중 선택 가능)」입니다.
2. 「회의 제목」: 첫 번째 파일의 이름(확장자 제외)이 자동으로 채워집니다. 원하는 제목으로 바꾸세요. 제목이 비어 있으면 업로드할 수 없습니다.
3. 「회의 유형」: 회의 유형을 고릅니다. 유형에 맞춰 AI 회의록의 항목 구성이 달라집니다. 자세한 내용은 [새 회의 만들기](../../meetings/new-meeting/)를 보세요.
4. 「연결 회의 (선택)」: 같은 폴더의 지난 회의를 고르면 그 회의록을 이어받아 작성합니다. 기본은 「없음」입니다. [연결 회의](../../minutes/linked-meetings/)를 보세요.
5. 「회의록 압축율」: 「직전 회의 설정 따름 (기본)」 외에 「아주 간결」, 「간결」, 「보통」, 「상세」, 「아주 상세」 중에서 고릅니다.
6. 「회의록 구성 방식」: 「직전 회의 설정 따름 (기본)」, 「주제별 재구성 — 전체를 주제별로 재정리」, 「시간 흐름 — 회의 진행 순서대로 요약」 중에서 고릅니다.
7. 아래쪽 단추: 「취소」와 실행 단추입니다. 파일이 하나면 「업로드 및 변환」, 둘 이상이면 「병합 후 업로드」입니다.

## 파일 하나 올리기

1. 「오디오 업로드」 창을 열고 파일을 고릅니다.
2. 제목과 유형을 확인하고 필요하면 압축율과 구성 방식을 바꿉니다.
3. 「업로드 및 변환」을 누릅니다. 단추가 「업로드 중...」으로 바뀝니다.
4. 업로드가 끝나면 새 회의의 화면으로 이동하고, 변환 진행 화면이 나타납니다.

## 여러 파일 이어서 하나의 회의로 올리기

회의를 여러 조각으로 나누어 녹음했거나, 휴대폰이 긴 녹음을 여러 파일로 저장했을 때 쓰는 기능입니다. 파일을 순서대로 이어 하나의 오디오로 만든 뒤 한 회의로 올립니다.

1. 파일을 여러 개 한꺼번에 고르거나, 여러 번에 나누어 끌어 놓습니다. 두 번째 파일부터는 목록 뒤에 덧붙고, 이름과 크기가 같은 파일은 중복으로 보고 건너뜁니다.
2. 파일이 둘 이상이면 점선 영역 아래에 순서 목록이 나타납니다. 안내 문구는 「위에서부터 순서대로 하나의 오디오로 병합됩니다 (파일 사이 3초 무음 삽입) · 총 N개 · 크기」입니다.
3. 처음 목록은 파일 이름의 자연 순서(1, 2, 10 순)로 정렬됩니다. 순서를 바꾸려면 항목을 끌어 놓거나, 항목 오른쪽의 위·아래 이동 단추를 누릅니다. 필요 없는 파일은 삭제 단추로 뺍니다.
4. 「병합 후 업로드」를 누릅니다. 병합이 진행되는 동안 단추에 「병합 중... (2/5)」처럼 진행 상황이 나옵니다.
5. 병합이 끝나면 「업로드 중...」을 거쳐 새 회의가 만들어집니다.

:::note
파일과 파일 사이에는 3초의 무음이 들어갑니다. 그래서 이어 붙인 지점이 구분되고, 말이 뭉개져 서로 붙지 않습니다. 이어 붙인 결과는 하나의 오디오 파일이 되어 회의 상세 화면에서 처음부터 끝까지 재생됩니다.
:::

:::caution
병합은 사용 중인 컴퓨터(또는 휴대폰)에서 처리합니다. 파일이 아주 크거나 많으면 시간이 걸리고 메모리를 많이 쓸 수 있습니다. 병합에 실패하면 「오디오 병합에 실패했습니다.」, 업로드에 실패하면 「업로드에 실패했습니다.」가 창 위쪽에 표시됩니다. 이때는 파일 목록이 그대로 남아 있으니 다시 시도하세요.
:::

## 변환 진행 화면

업로드가 끝나면 새 회의 화면이 열리면서 변환 진행 화면이 나타납니다. 화면에는 회의 제목, 진행 상태 문구, 진행 막대와 백분율이 보입니다.

| 진행률 | 상태 문구 |
|---|---|
| 10% 미만 | 오디오 파일 처리 준비 중... |
| 10% 이상 70% 미만 | 음성 인식 중... |
| 70% 이상 95% 미만 | AI 회의록 생성 중... |
| 95% 이상 | 마무리 중... |

- 다른 변환 작업이 먼저 있으면 진행 막대 대신 「앞에 N건 대기 중」이 보입니다. 순서가 되면 자동으로 시작됩니다.
- 변환에 실패하면 「오류: …」 문구가 빨간 상자로 나타납니다.
- 변환이 끝나면 완성된 회의 화면으로 저절로 넘어갑니다. 이 화면은 [회의 상세 화면](../../minutes/meeting-detail/)에서 설명합니다.

긴 파일도 자동으로 나누어 처리합니다. 변환에 걸리는 시간은 파일 길이와 사용하는 음성 인식 엔진에 따라 다릅니다.

## 업로드 후 AI 회의록이 만들어지는 방식

- 기본 동작: 음성 인식이 끝나면 이어서 AI 회의록이 자동으로 만들어집니다. 별도의 조작은 필요 없습니다. 「회의록 구성 방식」에서 「시간 흐름」을 고르면 회의 진행 순서대로, 「주제별 재구성」을 고르면 주제별로 정리합니다. 고르지 않으면 직전 회의 설정을 따릅니다.
- 화자 분리가 켜져 있어도 같은 방식으로 동작합니다. 전사가 끝나면 회의록까지 자동으로 만들어집니다. 회의록에 실제 이름을 넣고 싶다면 화자 목록에서 이름을 지정한 뒤 「회의록 재생성」을 누르세요. 방법은 [화자 분리와 이름 바꾸기](../../minutes/speakers/)를 보세요.
- 회의록이 마음에 들지 않으면 상세 화면에서 다시 만들거나 추가 지시를 줄 수 있습니다. [AI 회의록](../../minutes/ai-summary/)을 보세요.

## 이미 녹음이 있는 회의에 오디오 붙이기

회의 상세 화면에 오디오 파일을 끌어 놓으면 그 회의에 직접 붙일 수 있습니다.

1. 회의 상세 화면 어디든 오디오 파일을 끌어 놓습니다.
2. 이 회의에 이미 오디오가 있으면 「오디오 파일 N개 감지」 창이 열립니다. 「이 회의에는 이미 오디오가 있습니다. 기존 녹음 뒤에 이어붙이거나, 새 회의로 만들 수 있습니다.」라고 안내하며, 「기존 녹음 뒤에 연결」, 「새 회의로 생성」, 「취소」 중에서 고릅니다.
3. 「기존 녹음 뒤에 연결」을 고르면 「기존 녹음 뒤에 연결」 창에서 순서를 정하고 「병합 시작」을 누릅니다. 창이 화면 오른쪽 아래의 작은 안내로 줄어들며 「병합 중」, 「업로드 중...」 순으로 진행됩니다.
4. 업로드가 끝나면 「업로드가 완료됐습니다. 재전사를 실행할까요? (음성 인식 후 AI 회의록 요약까지 이어서 생성합니다)」라고 묻습니다. 「예, 재전사」를 누르면 전체를 다시 전사하고, 「아니오」를 누르면 오디오만 붙인 채 둡니다. 실패하면 「재시도」와 「닫기」가 나옵니다.
5. 「새 회의로 생성」을 고르면 위의 「오디오 파일로 회의록 작성」 창이 열립니다.
6. 이 회의에 오디오가 아직 없으면 위 2번 단계 없이 곧바로 이어 붙이기 창이 열립니다.
7. 녹음이나 전사가 진행 중인 회의에는 붙일 수 없으며 「녹음/전사 중인 회의에는 오디오를 추가할 수 없습니다.」 안내가 나옵니다.

오디오가 아닌 파일을 끌어 놓으면 첨부 파일로 분류하는 창이 열립니다. 첨부는 [라이브 녹음](../live/)의 안건·참고자료 첨부와 같은 기능입니다.

:::tip
회의가 끝난 뒤 빠뜨린 부분을 따로 녹음했다면, 그 파일을 회의 상세 화면에 끌어 놓고 「기존 녹음 뒤에 연결」하면 하나의 회의록으로 정리할 수 있습니다.
:::

- 업로드한 회의의 전사에 오타가 있으면 [전사 편집](../../minutes/transcript/)에서 고칩니다.
- 변환이 오래 멈춰 있거나 실패하면 [문제 해결](../../help/troubleshooting/)을 보세요.
