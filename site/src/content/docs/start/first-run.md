앱을 처음 켜면 어떤 방식으로 쓸지 묻는 화면이 나옵니다. 여기서 정한 방식에 따라 이후 화면이 달라집니다. 이 페이지는 데스크톱 앱과 Android 앱 기준입니다. 웹 브라우저로 접속한다면 이 과정이 없으며 바로 [로그인](../login/) 화면이 열립니다.

## 실행 방식 고르기

화면 위쪽에 「또박또박」과 「AI 회의록 - 실행 모드를 선택하세요」라는 안내가 나옵니다. 두 가지 카드 중 하나를 고릅니다.

1. **로컬 실행** — 「이 컴퓨터에서 직접 실행합니다」. 내 컴퓨터 안에서 모든 처리가 이루어집니다. 로그인 없이 바로 쓸 수 있습니다.
2. **서버 연결** — 「원격 서버에 연결하여 사용합니다」. 팀의 회의 서버에 접속합니다. 로그인이 필요합니다.
3. 아래쪽 「시작하기」 버튼. 선택이 끝나면 이 버튼을 눌러 앱으로 들어갑니다.
4. 「취소」 버튼. 이미 쓰고 있다가 방식을 바꾸러 들어온 경우에만 보이며, 눌러서 원래 화면으로 돌아갑니다.

![실행 모드 선택 화면](../../../assets/screens/first-run-mode-select.png)

| | 로컬 실행 | 서버 연결 |
|---|---|---|
| 처리 위치 | 내 컴퓨터 | 회의 서버 |
| 로그인 | 필요 없음 | 필요함 |
| 여러 사람과 회의록 공유 | 어려움 | 가능 |
| 웹 브라우저 접속 | 불가 | 가능 |
| 처음 한 번 환경 점검 | 필요함 | 필요 없음 |

:::note
Android와 휴대폰 웹 브라우저에서는 이 선택 없이 항상 서버 연결 방식입니다. 이때는 「AI 회의록 - 서버 주소를 입력하세요」 화면이 바로 나옵니다.
:::

## 서버 연결: 서버 지정하기

「서버 연결」을 고르면 접속할 서버를 정하는 영역이 나타납니다. 세 가지 방법이 있습니다.

### 방법 1. 같은 Wi-Fi에서 서버 찾기

1. 「같은 Wi-Fi에서 서버 찾기」 버튼을 누릅니다. 「서버 검색 중...」이 표시되며 수 초 걸립니다.
2. 찾은 서버가 목록에 나타납니다. 이름이 있으면 이름과 주소가 함께 보입니다.
3. 접속할 서버를 누르면 주소가 자동으로 채워지고 곧바로 연결을 확인합니다.

서버를 찾지 못하면 「같은 Wi-Fi에서 서버를 찾지 못했어요. 아래에 주소를 직접 입력하세요.」라고 안내합니다.

### 방법 2. 저장된 서버에서 고르기

이전에 연결했던 서버는 「저장된 서버」 목록에 남습니다. 서버를 누르면 바로 선택됩니다. 각 줄의 오른쪽에는 연결 가능 여부를 나타내는 아이콘이 표시되며, 「편집」 아이콘으로 이름과 위치(예: 이름 「사무실 서버」, 위치 「회의실 A」)를 붙이거나 「삭제」 아이콘으로 목록에서 지울 수 있습니다.

### 방법 3. 주소 직접 입력

1. 「서버 URL」 입력칸에 서버 관리자가 알려 준 주소를 입력합니다. 예: `192.168.0.10` 또는 `http://example.com:13323`
2. 「연결 확인」 버튼을 누릅니다.
3. 결과 메시지를 확인합니다.

| 메시지 | 의미 |
|---|---|
| 서버에 연결 중... | 확인하고 있습니다. |
| 서버 연결 성공 | 접속할 수 있습니다. 「시작하기」를 눌러 진행합니다. |
| 서버에 연결할 수 없습니다. URL을 확인해주세요. | 주소가 틀렸거나 서버가 꺼져 있거나 같은 네트워크가 아닙니다. |
| 서버 응답 오류 (HTTP …) | 서버에는 닿았지만 정상 상태가 아닙니다. 서버 관리자에게 알리세요. |
| 서버 응답 시간이 초과되었습니다 (5초) | 서버가 5초 안에 응답하지 않았습니다. |

:::tip
주소를 `192.168.0.10`처럼 적으면 앞의 `http://`와 뒤의 포트 번호는 자동으로 보충됩니다. 공백이나 마지막 슬래시는 신경 쓰지 않아도 됩니다.
:::

연결에 성공하면 「시작하기」를 누릅니다. 서버 연결 방식은 앱이 한 번 다시 시작된 뒤 [로그인](../login/) 화면으로 이어집니다.

### 서버 없이 오프라인으로 시작 (Android)

Android 앱에서는 화면 맨 아래에 「서버 없이 오프라인으로 시작 →」 링크가 있습니다. 서버가 없어도 휴대폰 안에서만 녹음하고 전사할 수 있습니다. → [오프라인 녹음](../../recording/offline/)

## 로컬 실행: 초기 셋업

「로컬 실행」을 고르고 「시작하기」를 누르면 초기 셋업 화면(「AI 회의록 서비스를 준비하고 있습니다」)이 나옵니다. 또박또박이 동작하는 데 필요한 도구가 준비됐는지 점검하고, 서비스를 켜는 과정입니다. 대부분 자동으로 끝납니다.

![초기 셋업 화면](../../../assets/screens/first-run-setup.png)

화면은 위에서부터 다음 순서입니다.

1. **환경 확인** — 필요한 세 가지 도구가 설치돼 있는지 보여 줍니다. 준비된 항목은 초록색 체크와 버전이 표시되고, 없는 항목은 빨간색 표시가 나타납니다.

   | 도구 | 용도 |
   |---|---|
   | Ruby | 회의록 서비스의 기본 프로그램 |
   | uv (Python) | 음성 인식 구성요소 |
   | ffmpeg | 오디오 변환 |

2. **필수 도구가 설치되지 않았습니다** — 빠진 도구가 있을 때만 나오는 안내입니다. 아래 두 버튼 중 하나를 누릅니다.
   - 「자동 설치」: 또박또박이 부족한 도구를 알아서 설치합니다. 설치하는 동안 「설치 중...」이 표시되고 진행 상황이 한 줄씩 나옵니다.
   - 「다시 확인」: 직접 설치한 뒤 다시 점검합니다. 안내에 적힌 설치 명령을 터미널에서 실행한 경우에 사용합니다.
3. **서비스 준비** — 도구가 모두 준비되면 서비스를 켜며 「Backend (Rails)」와 「Sidecar (Python)」가 하나씩 준비 상태로 바뀝니다. 처음에는 필요한 구성요소를 내려받느라 몇 분 걸릴 수 있습니다.
4. **준비 완료!** — 두 서비스가 모두 켜지면 이 문구가 나오고 잠시 뒤 자동으로 다음 화면으로 넘어갑니다.

화면 맨 아래 작은 글씨로 현재 운영체제 정보가 표시됩니다.

:::note
환경 점검과 서비스 준비는 앱을 켤 때마다 짧게 반복됩니다. 도구 설치와 초기 구성은 처음 한 번만 오래 걸립니다.
:::

### 오류가 나올 때

「오류가 발생했습니다」라는 붉은 안내와 함께 오류 내용이 표시되면 「다시 시도」 버튼을 눌러 처음부터 다시 진행합니다. 계속 실패하면 오류 내용을 복사해 두었다가 [문제 해결](../../help/troubleshooting/)을 참고하거나 관리자에게 전달하세요.

## 나중에 실행 방식 바꾸기

한 번 정한 방식은 나중에 바꿀 수 있습니다.

- 서버 연결 방식이면 로그인 화면의 「서버 주소 변경」 버튼을 누릅니다. 위의 실행 방식 선택 화면으로 돌아옵니다.
- 서버 연결 방식으로 정했는데 서버 주소가 비어 있으면 앱이 실행될 때마다 이 화면으로 돌아옵니다. 주소를 다시 입력해 주세요.

:::caution
로컬 실행과 서버 연결은 서로 다른 데이터 저장소를 씁니다. 로컬에서 만든 회의는 서버에 자동으로 올라가지 않고, 반대도 마찬가지입니다. 옮기려면 [아카이브 내보내기/가져오기](../../share/archive/)를 이용하세요.
:::
