또박또박의 회의는 모두 **프로젝트** 안에 모입니다. 로그인한 뒤 처음 접속하면 어떤 프로젝트에서 작업할지 고르는 화면이 나옵니다.

:::note
이 화면은 **작업할 프로젝트를 한 번도 고르지 않았을 때만** 나옵니다. 한 번 고르면 다음부터는 마지막에 쓰던 프로젝트의 회의 목록이 바로 열립니다. 다른 프로젝트로 옮기려면 사이드바 위쪽의 프로젝트 전환 버튼(「프로젝트 전환」)을 사용하세요. → [프로젝트 관리](../../projects/projects/)
:::

## 화면 구성

![프로젝트 선택 화면](../../../assets/screens/project-select-landing.png)

1. **왼쪽 「프로젝트」 목록** — 내가 멤버인 프로젝트가 한 줄씩 나옵니다. 좁은 화면(휴대폰)에서는 이 목록이 숨겨지고 카드만 보입니다.
2. **제목 영역** — 「프로젝트 선택」, 「작업할 프로젝트를 선택하세요.」
3. **프로젝트 카드** — 프로젝트마다 카드가 하나씩 있고, 다음 정보가 보입니다.
   - 프로젝트 아이콘과 이름
   - 「멤버 N · 회의 N」 — 참여자 수와 회의 수
   - 프로젝트 설명(있는 경우 두 줄까지)
4. **별 표시가 붙은 프로젝트** — 추천 프로젝트입니다. 팀 프로젝트가 있으면 팀 프로젝트가, 없으면 첫 번째 프로젝트가 강조됩니다. 자동으로 들어가지는 않으며 눈에 띄게만 해 줍니다.
5. **「새 프로젝트」** — 목록 아래와 카드 맨 끝의 점선 카드에 있습니다. 프로젝트를 만들 수 있는 사람에게만 보입니다.

## 프로젝트 고르기

1. 왼쪽 목록이나 가운데 카드에서 작업할 프로젝트를 누릅니다.
2. 그 프로젝트의 **회의 목록**이 열립니다. → [회의 목록](../../meetings/list/)

## 프로젝트 종류

| 종류 | 표시 | 설명 |
|---|---|---|
| 개인 프로젝트 | 「내 회의」 | 나만 쓰는 프로젝트입니다. 처음 시작할 때 자동으로 만들어져 있어, 팀 프로젝트가 없어도 바로 회의를 시작할 수 있습니다. |
| 팀 프로젝트 | 지정한 이름 | 여러 멤버가 함께 쓰는 프로젝트입니다. 초대받은 멤버만 보입니다. |

목록에는 내가 멤버로 참여 중인 프로젝트만 나옵니다. 다른 사람의 개인 프로젝트나 초대받지 않은 팀 프로젝트는 보이지 않습니다.

## 새 프로젝트 만들기

「새 프로젝트」는 프로젝트 생성 권한이 있는 계정(관리자, 매니저)에게 보입니다. 로컬 실행 방식에서는 누구나 만들 수 있습니다.

1. 「새 프로젝트」를 누르면 「새 프로젝트」 창이 열립니다.
2. 「이름」에 프로젝트 이름을 입력합니다(「프로젝트 이름」 안내가 보입니다).
3. 필요하면 「설명 (선택)」을 적고 「아이콘」을 고릅니다.
4. 「생성」 버튼을 누릅니다.
5. 만들어진 프로젝트의 회의 목록으로 바로 이동합니다.

멤버를 초대하는 방법과 프로젝트 설정은 [프로젝트 관리](../../projects/projects/)를 참고하세요.

:::tip
권한이 없어 「새 프로젝트」가 보이지 않는다면 관리자나 매니저에게 프로젝트를 만들어 달라고 하거나, 초대 링크로 기존 프로젝트에 합류하세요.
:::

## 문제가 있을 때

| 증상 | 확인할 것 |
|---|---|
| 「불러오는 중…」에서 멈춥니다 | 서버 연결 상태를 확인하고 잠시 뒤 다시 열어 보세요. |
| 붉은 오류 표시와 「다시 시도」가 보입니다 | 「다시 시도」를 눌러 목록을 다시 불러옵니다. 계속되면 [문제 해결](../../help/troubleshooting/)을 참고하세요. |
| 카드가 하나도 없습니다 | 아직 참여한 프로젝트가 없는 것입니다. 초대 링크를 받거나 프로젝트 생성 권한이 있는 사람에게 요청하세요. |

프로젝트를 골랐다면 [회의 목록](../../meetings/list/)과 [새 회의 만들기](../../meetings/new-meeting/)로 이어서 진행하세요.
