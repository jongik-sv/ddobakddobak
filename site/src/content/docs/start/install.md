또박또박은 설치하는 방법이 환경에 따라 세 가지입니다. 사용하는 기기에 맞는 항목을 따라 하세요.

| 사용 환경 | 설치 | 비고 |
|---|---|---|
| 데스크톱 앱 (macOS) | 설치 파일(`.dmg`) | 로컬 실행과 서버 연결 모두 가능 |
| 데스크톱 앱 (Windows) | 설치 파일(`.msi` 또는 `.exe`) | 서버 연결 방식을 기본으로 안내합니다. 로컬 실행 가능 여부는 PC 환경에 따라 다를 수 있습니다 |
| 휴대폰 (Android) | 설치 파일(`.apk`) | 서버 연결, 서버 없는 오프라인 녹음 |
| 웹 브라우저 | 설치 없음 | 서버 주소로 접속만 하면 됩니다 |

:::tip
팀 회의 서버가 이미 있다면 가장 간단한 방법은 **설치 없이 웹 브라우저로 서버 주소에 접속**하는 것입니다. 녹음 중에도 브라우저 탭을 닫지만 않으면 됩니다. 시스템 오디오 캡처 같은 일부 기능은 데스크톱 앱에서만 쓸 수 있습니다.
:::

## 설치 파일 받기

설치 파일은 프로젝트의 GitHub 저장소(상단의 GitHub 링크)와 서버 관리자가 안내하는 곳에서 받을 수 있습니다. 어디서 받아야 할지 모르겠다면 서버 관리자에게 문의하세요.

운영체제별로 받을 파일은 다음과 같습니다.

| 운영체제 | 칩/아키텍처 | 파일 형식 |
|---|---|---|
| macOS | Apple Silicon(M1 이상), Intel | `.dmg` |
| Windows | 64비트 | `.msi`, `.exe` |
| Android | 대부분의 휴대폰 | `.apk` |

## macOS에서 설치하기

1. 받은 `.dmg` 파일을 더블클릭해서 엽니다.
2. 열린 창에서 「또박또박」(앱 아이콘)을 「응용 프로그램」 폴더로 끌어다 놓습니다.
3. 「응용 프로그램」 폴더(또는 Launchpad)에서 또박또박을 실행합니다.
4. 처음 실행하면 마이크 사용 권한을 묻는 창이 나옵니다. **허용**을 누르세요. 녹음에 꼭 필요합니다.

### 「확인되지 않은 개발자」 경고가 뜰 때

인터넷에서 받은 앱은 macOS가 처음 한 번 실행을 막을 수 있습니다.

1. 경고 창은 **취소**(또는 **완료**)로 닫습니다.
2. 「시스템 설정」 → 「개인정보 보호 및 보안」을 엽니다.
3. 아래쪽에 표시된 또박또박 차단 안내 옆의 **그래도 열기**를 누릅니다.
4. 암호나 Touch ID로 확인하면 이후에는 경고 없이 실행됩니다.

## Windows에서 설치하기

1. 받은 `.msi` 또는 `.exe` 파일을 실행합니다.
2. 설치 마법사의 안내에 따라 **다음**을 눌러 진행하고 설치를 마칩니다.
3. 시작 메뉴에서 또박또박을 실행합니다.
4. 마이크 권한을 묻는 창이 나오면 **허용**합니다.

### 「Windows의 PC 보호」 창이 뜰 때

서명되지 않은 설치 파일은 SmartScreen이 경고할 수 있습니다.

1. 창에서 **추가 정보**를 누릅니다.
2. 아래에 나타나는 **실행** 버튼을 누릅니다.

:::caution
회사 PC에서는 보안 프로그램이 설치나 실행을 막을 수 있습니다. 「추가 정보」가 나타나지 않는다면 PC의 정책이 막고 있는 것이므로 PC 관리자에게 문의하세요.
:::

## Android에서 설치하기

1. 휴대폰으로 `.apk` 파일을 받습니다.
2. 받은 파일을 누르면 「출처를 알 수 없는 앱 설치」를 허용하라는 안내가 나올 수 있습니다. 파일을 연 앱(브라우저 또는 파일 관리자)에 대해 허용하세요.
3. **설치**를 누릅니다.
4. 설치가 끝나면 또박또박을 실행하고, 마이크 권한을 **허용**합니다.
5. 서버 주소를 입력하는 화면이 나옵니다. → [첫 실행](../first-run/)

Android 앱은 서버가 없어도 휴대폰 안에서만 녹음하고 전사하는 **오프라인 시작**을 지원합니다. → [오프라인 녹음](../../recording/offline/)

## 웹 브라우저로 쓰기

설치 없이 서버 관리자가 알려 준 주소를 브라우저 주소창에 입력하면 로그인 화면이 열립니다. → [로그인과 계정 만들기](../login/)

:::note
휴대폰 브라우저로도 접속할 수 있습니다. 브라우저에서 마이크를 쓰려면 마이크 권한을 허용해야 하며, 서버 주소가 보안 연결(`https://`)이어야 마이크가 동작하는 환경이 있습니다. 마이크가 켜지지 않으면 [문제 해결](../../help/troubleshooting/)을 확인하세요.
:::

## 삭제하기

- **macOS**: 「응용 프로그램」 폴더에서 또박또박을 휴지통으로 옮깁니다.
- **Windows**: 「설정」 → 「앱」 → 「설치된 앱」에서 또박또박을 찾아 제거합니다.
- **Android**: 앱을 길게 눌러 제거합니다.

서버 연결 방식으로 쓰던 회의 데이터는 서버에 남아 있어 앱을 지워도 사라지지 않습니다.

설치가 끝났다면 [첫 실행](../first-run/)으로 이어서 진행하세요.
