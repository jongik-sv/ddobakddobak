또박또박은 회의 음성을 **실시간으로 받아쓰고**, 말한 사람을 **자동으로 구분**하며, AI가 **회의록까지 정리**해 주는 회의 도우미입니다. 데스크톱 앱(macOS·Windows), 웹 브라우저, Android 앱에서 사용할 수 있습니다.

이 매뉴얼은 처음 쓰는 분이 화면을 보며 그대로 따라 할 수 있도록 작성했습니다. 서비스가 어떤 서비스인지 먼저 알고 싶다면 상단의 「또박또박 소개」 링크에서 소개 페이지를 볼 수 있습니다.

## 할 수 있는 일

| 하고 싶은 일 | 또박또박에서는 | 자세한 설명 |
|---|---|---|
| 회의 내용을 받아 적고 싶다 | 마이크로 말하는 즉시 자막(전사)이 만들어집니다 | [라이브 녹음](../../recording/live/) |
| 이미 녹음해 둔 파일로 회의록을 만들고 싶다 | 오디오 파일을 올리면 전사와 회의록을 만듭니다 | [오디오 파일 업로드](../../recording/upload/) |
| 누가 무슨 말을 했는지 알고 싶다 | 화자를 자동으로 나누고 이름을 붙일 수 있습니다 | [화자 정리](../../minutes/speakers/) |
| 회의록을 빠르게 얻고 싶다 | AI가 회의 중에도 회의록을 계속 갱신합니다 | [AI 회의록](../../minutes/ai-summary/) |
| 지난 회의 내용을 찾고 싶다 | 전역 검색과 AI 챗으로 찾고 물어봅니다 | [전역 검색](../../ai/search/), [회의 AI 챗](../../ai/chat/) |
| 팀원과 나누고 싶다 | 다른 기기에서 실시간 보기, 협업자 권한, 내보내기를 지원합니다 | [다른 기기에서 실시간으로 보기](../../share/live-share/), [내보내기](../../share/export/) |

## 핵심 흐름

회의 한 건은 보통 다음 순서로 만들어집니다.

1. **설치하고 처음 실행합니다.** 앱을 설치한 뒤 실행 방식(로컬 실행 또는 서버 연결)을 고릅니다. → [설치](../install/), [첫 실행](../first-run/)
2. **로그인하고 프로젝트를 고릅니다.** 회의는 모두 프로젝트 안에 모입니다. → [로그인과 계정 만들기](../login/), [프로젝트 선택](../project-select/)
3. **새 회의를 만듭니다.** 제목과 회의 유형을 정합니다. → [새 회의 만들기](../../meetings/new-meeting/)
4. **녹음합니다.** 「회의 시작」을 누르면 말하는 대로 자막과 AI 회의록이 채워집니다. → [라이브 녹음](../../recording/live/)
5. **회의를 마치고 회의록을 확인합니다.** 필요하면 오타를 고치고 화자 이름을 바꿉니다. → [회의 상세 화면](../../minutes/meeting-detail/)
6. **공유하거나 내보냅니다.** 마크다운·PDF·DOCX 같은 형식으로 저장하거나 외부 시스템으로 전송합니다. → [회의록 내보내기](../../share/export/)

## 용어

매뉴얼 전체에서 다음 낱말이 같은 뜻으로 쓰입니다.

| 용어 | 뜻 |
|---|---|
| 프로젝트 | 회의를 모아 두는 가장 큰 단위입니다. 팀이 함께 쓰는 **팀 프로젝트**와 나만 쓰는 **개인 프로젝트**(「내 회의」)가 있습니다. |
| 폴더 | 프로젝트 안에서 회의를 분류하는 폴더입니다. |
| 회의 | 녹음 한 건과 거기서 만들어진 전사·회의록·첨부를 묶은 단위입니다. |
| 전사 | 음성을 글자로 옮긴 결과입니다. 화자별로 줄이 나뉩니다. |
| 화자 | 회의에서 말한 사람입니다. 자동으로 구분되며 이름을 붙일 수 있습니다. |
| AI 회의록 | 전사를 바탕으로 AI가 정리한 회의록입니다. 편집하고 다시 만들 수 있습니다. |
| 북마크·메모 | 녹음 중 중요한 시점에 남기는 표시와 글입니다. |
| 로컬 실행 | 내 컴퓨터 안에서 또박또박이 통째로 동작하는 방식입니다. |
| 서버 연결 | 팀이 함께 쓰는 회의 서버에 접속해서 쓰는 방식입니다. |
| 회의 API | 외부 프로그램이나 AI 에이전트가 회의 내용을 조회하는 기능입니다. → [회의 API](../../settings/meeting-api/) |

## 사용 방식 두 가지

또박또박은 데이터가 처리되는 위치에 따라 두 가지 방식으로 씁니다.

- **로컬 실행**: 앱 하나에 필요한 구성요소가 모두 들어 있어, 내 컴퓨터 안에서 음성 인식과 요약이 이루어집니다. 혼자 쓰거나 회의 내용을 밖으로 보내고 싶지 않을 때 알맞습니다.
- **서버 연결**: 팀의 회의 서버에 접속합니다. 여러 사람이 같은 프로젝트와 회의록을 함께 보고, 웹 브라우저로도 접속할 수 있습니다.

:::note
웹 브라우저와 휴대폰(Android) 앱은 항상 서버 연결 방식으로 동작합니다. 로컬 실행은 데스크톱 앱에서만 고를 수 있습니다.
:::

## 이 매뉴얼 보는 법

- 화면에 보이는 버튼과 메뉴 이름은 「」로 묶어 그대로 적었습니다.
- 앱 안에서 **F1** 키를 누르거나 사이드바의 「매뉴얼」 버튼을 누르면 지금 보고 있는 화면에 맞는 매뉴얼 페이지가 열립니다.
- 막히는 일이 생기면 [문제 해결](../../help/troubleshooting/)과 [자주 묻는 질문](../../help/faq/)을 먼저 확인해 보세요.

처음이라면 [설치](../install/)부터 차례로 읽으시면 됩니다.
