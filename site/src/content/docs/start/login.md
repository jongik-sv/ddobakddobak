서버 연결 방식(웹 브라우저 포함)으로 접속하면 로그인이 필요합니다. 로컬 실행 방식은 내 컴퓨터에서만 쓰므로 로그인 없이 바로 들어갑니다.

## 화면 구성

![로그인 화면](../../../assets/screens/login-screen.png)

1. **제목** — 「또박또박」과 「AI 회의록 - 로그인이 필요합니다」.
2. **서버 주소** — 데스크톱 앱에서 서버에 연결한 경우 「서버: …」로 현재 접속 중인 서버가 표시됩니다. 엉뚱한 서버에 접속하지 않았는지 여기서 확인하세요.
3. **이메일** 입력칸.
4. **비밀번호** 입력칸 — 오른쪽의 눈 아이콘으로 입력한 글자를 보거나 숨길 수 있습니다.
5. 「로그인」 버튼.
6. 「브라우저에서 로그인」 버튼 — 웹 브라우저 창에서 로그인한 뒤 앱으로 돌아옵니다.
7. 「서버 주소 변경」 — 접속할 서버를 바꿉니다. [첫 실행](../first-run/)의 실행 방식 선택 화면으로 돌아갑니다.
8. 「또박또박은 어떤 서비스인가요?」 — 소개 페이지를 엽니다.
9. 「서버 없이 오프라인으로 시작 →」 — Android 앱에서만 보이며, 로그인 없이 휴대폰 안에서 녹음합니다. → [오프라인 녹음](../../recording/offline/)

## 로그인하기

1. 「이메일」에 계정의 이메일 주소를 입력합니다. 화면이 열리면 이 칸에 커서가 먼저 놓여 있습니다.
2. 「비밀번호」에 비밀번호를 입력합니다.
3. 「로그인」 버튼을 누르거나 키보드의 Enter를 누릅니다. 진행 중에는 「로그인 중...」으로 바뀝니다.
4. 성공하면 [프로젝트 선택](../project-select/) 화면으로 넘어갑니다.

이메일이나 비밀번호가 맞지 않으면 「이메일 또는 비밀번호가 올바르지 않습니다.」라고 안내합니다. 대소문자와 한/영 상태를 확인하고 다시 입력하세요.

:::tip
앱을 껐다 켜도 로그인 상태가 유지됩니다. 로그인 화면이 다시 나오는 것은 로그아웃했거나, 다른 기기에서 비밀번호가 바뀌었거나, 오랫동안 접속하지 않아 인증이 만료된 경우입니다.
:::

### 브라우저에서 로그인

「브라우저에서 로그인」을 누르면 기본 웹 브라우저에 서버의 로그인 페이지가 열립니다. 거기서 로그인하면 자동으로 또박또박 앱으로 돌아옵니다. 앱 안에서 입력하는 방법이 잘 안 될 때 대신 쓸 수 있습니다.

## 계정 만들기

로그인 화면에는 「회원가입」 버튼이 없습니다. 계정은 다음 두 가지 중 한 가지로 만듭니다.

### 방법 1. 관리자가 계정을 만들어 줍니다

서버 관리자가 「사용자 관리」 화면의 「사용자 추가」에서 이메일·이름·비밀번호·역할을 정해 계정을 만듭니다. 관리자에게 이메일과 비밀번호를 받아 그대로 로그인하고, 임시 비밀번호라면 곧바로 바꾸세요. → [사용자 관리](../../settings/users/)

### 방법 2. 초대 링크로 가입합니다

프로젝트 관리자가 보내 준 초대 링크를 열면 가입 화면이 나옵니다.

1. 초대 링크를 엽니다. 화면에 프로젝트 이름과 「프로젝트에 초대되었습니다.」가 표시됩니다.
2. 「이름」, 「이메일」, 「비밀번호」, 「비밀번호 확인」을 입력합니다. 두 비밀번호가 다르면 「비밀번호가 일치하지 않습니다.」가 표시됩니다.
3. 「가입하고 합류하기」 버튼을 누릅니다.
4. 가입과 동시에 그 프로젝트의 멤버가 됩니다.

이미 계정이 있다면 「이미 계정이 있으신가요?」 옆의 「로그인」을 눌러 로그인한 뒤 「합류하기」를 누르면 됩니다. 이미 로그인된 상태에서 링크를 열었다면 바로 「합류하기」 버튼이 보입니다.

| 메시지 | 의미 |
|---|---|
| 만료되었거나 유효하지 않은 초대 링크입니다. | 링크 기간이 지났거나 잘못된 링크입니다. 초대한 사람에게 새 링크를 요청하세요. |
| 이미 사용 중인 이메일이거나 입력값을 확인해 주세요. | 이미 가입된 이메일입니다. 「로그인」으로 들어가세요. |

초대 링크를 만드는 방법은 [프로젝트 관리](../../projects/projects/)를 참고하세요.

## 비밀번호 바꾸기

1. 로그인한 뒤 「설정」을 엽니다.
2. 「개인설정」 탭의 「비밀번호 변경」 영역으로 갑니다.
3. 「현재 비밀번호」, 「새 비밀번호」(6자 이상), 「새 비밀번호 확인」을 입력합니다.
4. 「비밀번호 변경」 버튼을 누릅니다.

변경하면 「비밀번호가 변경되었습니다. 다른 기기는 다시 로그인해야 합니다.」라고 안내합니다. 현재 기기를 뺀 모든 기기의 로그인이 풀립니다. → [개인설정](../../settings/personal/)

:::caution
비밀번호를 잊어버렸을 때 스스로 초기화하는 기능은 없습니다. 서버 관리자에게 비밀번호 초기화를 요청하세요. 관리자가 새 비밀번호를 정해 주면 그 비밀번호로 로그인한 뒤 곧바로 바꾸는 것이 안전합니다.
:::

## 로그아웃

데스크톱 사이드바 아래쪽의 「로그아웃」을 누릅니다. 공용 PC에서는 사용을 마칠 때 꼭 로그아웃하세요.

로그인이 안 될 때의 점검 항목은 [문제 해결](../../help/troubleshooting/)에 정리해 두었습니다.
