D'Flow는 회의록을 모아 두는 외부 서비스입니다. 또박또박은 완료된 회의록을 버튼 한 번으로 D'Flow에 올릴 수 있고, 같은 회의를 다시 보내면 새 글이 생기지 않고 **기존 글이 갱신**됩니다. 이 페이지에서는 전송하는 방법과 전송 상태를 확인하는 방법을 설명합니다.

:::note
D'Flow 연동은 처음 한 번 **관리자가 설정**해야 합니다. 설정 방법은 [설정의 「연동」 탭](../../settings/integrations/)을 보세요. 연동이 꺼져 있으면 아래의 「D'Flow로 전송」 항목은 보이지 않습니다.
:::

## 전송하기 전에 확인할 것

- 회의가 **완료** 상태여야 합니다. 녹음 중이거나 아직 시작하지 않은 회의에서는 전송 항목이 나타나지 않습니다.
- 내 또박또박 계정과 **같은 이메일**의 계정이 D'Flow에도 있어야 합니다. 없으면 「D'Flow에 동일 이메일 계정이 필요합니다. D'Flow 관리자에게 계정 생성을 요청하세요.」라는 안내가 나옵니다.
- 회의록 본문이 100,000자를 넘으면 전송할 수 없습니다. 이때는 「본문이 100,000자를 넘습니다. (전사 원문은 전송에서 제외됨)」가 표시됩니다. 전사 원문은 애초에 전송되지 않습니다.

## 회의록 전송하기

1. 완료된 회의의 상세 화면을 엽니다.
2. 오른쪽 위의 「내보내기」 버튼을 누릅니다.
3. 열린 창 맨 아래의 「D'Flow로 전송」 항목을 누릅니다. 이미 보낸 적이 있으면 오른쪽에 「전송됨」이, 보낸 뒤 회의록이 수정되었다면 「재전송 필요」가 함께 표시됩니다.
4. 「D'Flow로 전송」 창이 열립니다. 위쪽에 회의 제목이 보이고, 다음 항목을 확인합니다.

   | 항목 | 설명 |
   |---|---|
   | 「전송 사용자」 | 전송하는 사람의 이메일 |
   | 「대상 구분(team)」 | D'Flow에서 어느 팀(구분)에 올릴지. 회의 폴더의 최상위 이름이 D'Flow 구분과 같으면 자동으로 정해집니다. 자동 판정이 안 되면 목록에서 직접 「선택하세요」를 눌러 고릅니다. |
   | 「편철 경로 미리보기」 | D'Flow의 어느 폴더에 저장될지 보여 주는 경로 |
   | 「전송 제목」 | 기본값은 `하위폴더명-원제목` 형태로 자동 조립됩니다. 직접 고칠 수 있습니다(최대 200자). |

5. 필요하면 「회의 연결 (선택)」을 설정합니다(아래 참고).
6. 「전송」 버튼을 누릅니다. 진행 중에는 「전송 중…」이 표시됩니다.
7. 성공하면 「전송됨」과 함께 「D'Flow에서 보기」 링크가 나타납니다. 누르면 D'Flow의 해당 글이 새 창에서 열립니다.

![D'Flow로 전송 창](../../../assets/screens/dflow-send-dialog.png)

### 전송 결과 확인

전송이 끝나면 「편철 결과 경로」에 실제로 저장된 위치가 표시됩니다. 미리보기와 다르게 저장된 경우 배지가 함께 나타납니다.

| 표시 | 의미 |
|---|---|
| 「경로 절단됨」 | 폴더 경로가 D'Flow의 보존 한도(5단)를 넘어 상위 폴더로 조정되어 저장되었습니다. |
| 「상위 폴더까지만」 | 중간 폴더를 만들지 못해 상위 폴더까지만 정리되었습니다. |
| 「미분류」 | 미분류로 들어갔습니다. D'Flow에서 직접 폴더에 정리해야 합니다. |

폴더가 5단보다 깊으면 전송 전에 미리 경고가 표시됩니다. 막지는 않으며, 실제 저장 위치는 전송 후에 확인하세요.

## 회의 연결 (선택)

D'Flow의 **프로젝트 안 회의**에 이 회의록을 붙이고 싶을 때 쓰는 기능입니다. 연결하지 않아도 전송은 됩니다.

1. 「회의 연결 (선택)」에서 「D'Flow 프로젝트」 목록으로 프로젝트를 고릅니다. 연결하지 않으려면 「연결 안 함」을 고릅니다.
2. 프로젝트를 고르면 「D'Flow 회의」 목록이 나타납니다. 목록에는 제목, 날짜, 구분이 표시되고 반복 회의는 「반복」이 붙습니다. 이미 있는 회의를 고르면 그 회의에 연결됩니다.
3. 새 회의를 D'Flow에 함께 만들려면 「➕ 신규 회의 등록」을 고릅니다. 「제목」, 「날짜」, 「구분」을 입력합니다. 구분은 「정례」, 「일반」, 「킥오프」, 「리뷰」, 「보고」, 「외부」 중에서 고릅니다.
4. 「전송」을 누르면 연결이 반영됩니다. 결과 줄에 「회의 연결됨」 또는 「새 회의 등록됨」 배지가 표시됩니다.

이미 연결된 회의라면 「프로젝트 / 회의 제목」이 표시되고 두 버튼이 있습니다.

- 「변경」 — 다른 회의로 연결을 바꿉니다.
- 「연결 해제」 — 「연결 해제 예정 — 전송하면 D'Flow 연결이 해제됩니다.」가 표시되며, 「취소」로 되돌릴 수 있습니다.

D'Flow에 프로젝트가 하나도 없으면 「D'Flow 프로젝트가 없습니다 — 연결 없이 전송해 주세요.」가 표시됩니다. 회의 목록을 불러오지 못하면 「재시도」를 누르세요.

## 수정 후 다시 전송하기

전송한 뒤 회의록을 고치면 회의 화면의 배지가 바뀝니다.

| 배지 | 의미 |
|---|---|
| 「D'Flow ✓」 | D'Flow로 전송된 회의입니다. |
| 「D'Flow 재전송 필요」 | 회의록이 마지막 전송 이후 수정되었습니다. |

다시 전송하면 D'Flow의 기존 글을 덮어씁니다. 창에는 「D'Flow의 "…"(…)을 덮어씁니다.」라는 안내가 나옵니다. 몇 번을 보내도 새 글이 늘어나지 않으니 안심하고 재전송하세요.

## 목록에서 전송 상태 보기

D'Flow 연동이 켜져 있으면 회의 목록에서도 상태를 볼 수 있습니다.

- 회의 카드와 목록 줄에 위의 배지(「D'Flow ✓」, 「D'Flow 재전송 필요」)가 표시됩니다. 아직 보내지 않은 회의에는 배지가 없습니다.
- 목록 위쪽의 「D'Flow 전송 상태」 선택 목록으로 걸러 볼 수 있습니다. 모바일에서는 필터 창 안에 있습니다.

   | 선택 | 보여 주는 회의 |
   |---|---|
   | 「전체」 | 전부 |
   | 「D'Flow 전송됨」 | 전송이 끝난 회의 |
   | 「재전송 필요」 | 전송 뒤 수정된 회의 |
   | 「미전송」 | 아직 보내지 않은 회의 |

「재전송 필요」로 걸러 보면 다시 보내야 할 회의를 한 번에 찾을 수 있습니다. 자세한 목록 사용법은 [회의 목록](../../meetings/list/)을 참고하세요.

## 연결 관리

전송 창 맨 아래의 「연결 관리」를 펼치면 이 회의와 D'Flow 글을 이어 주는 식별자를 관리할 수 있습니다. 보통은 건드릴 필요가 없습니다.

| 항목 | 용도 |
|---|---|
| 식별자(없으면 「미발급」)와 「복사」 | 연결에 쓰이는 고유 값을 확인·복사합니다. |
| 「D'Flow 존재 확인」 | D'Flow에 글이 있는지 보여 줍니다. 「존재함」, 「존재함(보관됨)」, 「존재하지 않음(다음 전송 시 새로 생성됩니다)」, 「알 수 없음」 중 하나입니다. |
| 「수동 입력」 | 이미 알고 있는 식별자를 직접 넣어 연결합니다. |
| 「해제」 | 연결을 끊습니다. 「D'Flow 연결을 해제하시겠습니까? 회의록의 전송 상태가 초기화됩니다.」라고 확인합니다. |
| 「재발급」 | 새 식별자를 받습니다. 다음 전송 때 D'Flow에 새 회의록이 생기고 기존 것은 남습니다. |
| 「D'Flow에서 찾기」 | D'Flow에 손으로 올려 둔 회의록을 찾아 이 회의와 연결합니다. |

### D'Flow에 이미 올려 둔 글과 연결하기

1. 「연결 관리」를 펼치고 「D'Flow에서 찾기」를 누릅니다.
2. 검색 시작일·종료일, 구분(「전체 구분」)을 정하고 필요하면 「미연결만」을 체크한 뒤 「검색」을 누릅니다.
3. 결과에서 찾던 글의 「연결」을 누릅니다.
4. 이후 전송부터는 그 글이 갱신됩니다.

이미 다른 회의에 연결된 글을 고르면 「이미 다른 회의에 연결된 항목입니다.」가 표시됩니다.

## 전송이 안 될 때

| 화면 표시 | 원인과 해결 |
|---|---|
| 「D'Flow에 동일 이메일 계정이 필요합니다…」 | D'Flow에 내 이메일이 없습니다. D'Flow 관리자에게 계정을 요청하세요. |
| 「team을 자동으로 판정할 수 없습니다 — 아래에서 대상 구분을 직접 선택해 주세요.」 | 폴더 최상위 이름이 D'Flow 구분과 달라서입니다. 목록에서 고르세요. 전송 때마다 고르면 됩니다. |
| 「본문이 100,000자를 넘습니다…」 | 회의록이 너무 깁니다. 줄이거나 나누세요. |
| 「D'Flow에서 확인되지 않습니다(초기화·보관·삭제 중 하나)」 | D'Flow의 글이 사라진 상태입니다. 「D'Flow에서 찾기로 재연결」 또는 「새로 전송」 중에서 고르세요. 「새로 전송」은 확인 후 새 회의록으로 만들어집니다. |
| 「D'Flow에서 보관됨 — 재전송은 막힙니다. D'Flow에서 보관 해제 후 다시 시도하세요.」 | D'Flow에서 해당 글을 보관 해제한 뒤 다시 전송하세요. |
| 「전송에 실패했습니다.」 | 잠시 후 다시 시도하고, 계속되면 관리자에게 연동 설정(서버 주소·API 시크릿)을 확인해 달라고 요청하세요. |

:::tip
연동 설정을 바꾼 직후에 「연결 테스트」가 실패하면, 값을 입력만 하고 저장하지 않았을 수 있습니다. 먼저 「저장」한 뒤 테스트하세요.
:::

## 다른 서버로 옮길 때

D'Flow 연결 정보는 [아카이브 내보내기](../archive/)에 함께 담깁니다. 다른 서버에서 가져온 뒤 다시 전송하면 D'Flow의 같은 글이 그대로 갱신됩니다.
