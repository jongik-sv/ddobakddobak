**아카이브**는 회의나 폴더를 전사, AI 회의록, 메모, 화자 정보, 녹음 오디오까지 **통째로 담은 파일 하나**입니다. 다른 서버로 회의를 옮기거나, 백업해 두거나, 다른 프로젝트로 복사할 때 사용합니다. 문서 파일(MD·PDF·DOCX)로 내보내는 방법은 [회의록 내보내기](../export/)를 보세요.

## 파일 종류

| 대상 | 파일 이름 | 담기는 내용 |
|---|---|---|
| 회의 | `.ddobak-meeting.tgz` | 회의 한 건 |
| 폴더 | `.ddobak-folder.tgz` | 폴더와 그 안의 모든 회의 |
| 프로젝트 | `.ddobak` | 프로젝트의 폴더와 회의 전체 (시스템 관리자 전용) |

:::note
파일 이름의 확장자로 종류를 구분합니다. 이름을 바꾸지 말고 그대로 두세요.
:::

## 회의 내보내기

1. 「회의」 목록에서 내보낼 회의 카드(또는 목록의 줄)의 **⋮** 메뉴를 엽니다.
2. 「회의 내보내기」를 선택합니다.
3. 「회의 내보내기」 창에서 「음성 포함」을 정합니다.

   | 선택 | 결과 |
   |---|---|
   | 켬(기본) | 녹음 오디오까지 담습니다. 파일이 커지고 시간이 오래 걸립니다. |
   | 끔 | 「회의록·요약 등 메타데이터만 내보냅니다(파일 크기 작음).」 |

4. 「내보내기」를 누릅니다. 진행 중에는 「내보내는 중…」이 표시됩니다.
5. 완료되면 창이 닫히고 파일이 저장됩니다. 실패하면 「내보내기에 실패했습니다.」가 나타납니다.

![회의 내보내기 창](../../../assets/screens/archive-export-meeting.png)

## 폴더 내보내기

1. 왼쪽 사이드바에서 폴더의 **⋮** 메뉴를 엽니다.
2. 「내보내기(.tgz)」를 선택합니다.
3. 「폴더 내보내기」 창에서 「음성 포함」을 정하고 「내보내기」를 누릅니다.

폴더 안의 하위 폴더와 회의가 모두 함께 담깁니다. 오디오를 포함하면 용량이 매우 커질 수 있으니, 보관만 하려면 「음성 포함」을 끄는 것도 방법입니다.

## 프로젝트 내보내기

프로젝트 전체를 내보내는 기능은 **시스템 관리자**에게만 보입니다.

1. 「프로젝트」 화면에서 프로젝트 카드의 **⋮** 메뉴를 엽니다.
2. 「내보내기」를 선택합니다.
3. 「프로젝트 내보내기」 창에서 「음성 포함」을 정하고 내보냅니다.

## 가져오기

가져오기는 회의·폴더와 프로젝트가 서로 다른 곳에 있습니다.

### 회의·폴더 가져오기

1. 「회의」 화면을 엽니다. 가져온 항목은 **현재 프로젝트**에 만들어집니다. 폴더를 선택한 상태라면 그 폴더 안으로 들어갑니다.
2. 목록 위쪽의 「가져오기(.tgz)」 버튼을 누릅니다.
3. 내보내기로 받은 `.ddobak-meeting.tgz` 또는 `.ddobak-folder.tgz` 파일을 고릅니다.
4. 진행 중에는 「가져오는 중…」이 표시되고, 끝나면 목록에 회의나 폴더가 나타납니다.

| 가져오는 파일 | 만들어지는 위치 |
|---|---|
| `.ddobak-meeting.tgz` | 현재 선택한 폴더(없으면 미분류) |
| `.ddobak-folder.tgz` | 현재 선택한 폴더 아래(없으면 최상위) |

### 프로젝트 가져오기

시스템 관리자는 「프로젝트」 화면 위쪽의 「가져오기」 버튼으로 `.ddobak` 파일을 올릴 수 있습니다. 완료되면 가져온 프로젝트로 바로 이동합니다.

### 경고와 실패

- 가져오기는 되었지만 일부를 복원하지 못한 경우, 버튼 아래에 주황색 경고가 표시됩니다. 예를 들어 D'Flow 연결 식별자가 이미 다른 회의에서 쓰이고 있으면 연결이 해제된 채로 복원되며, 필요하면 [D'Flow 전송](../dflow/)의 「연결 관리」에서 다시 설정합니다.
- 「가져오기에 실패했습니다. 올바른 내보내기 파일인지 확인해 주세요.」가 나타나면 파일이 손상되었거나 또박또박에서 내보낸 파일이 아닌 경우입니다. 압축을 풀지 말고 받은 그대로 올려야 합니다.

:::caution
오디오가 포함된 아카이브는 크기가 클 수 있습니다. 가져오는 동안에는 창을 닫지 말고 끝날 때까지 기다리세요.
:::

## 이럴 때 사용하세요

| 하고 싶은 일 | 방법 |
|---|---|
| 서버를 옮겼는데 기존 회의를 가져오고 싶다 | 이전 서버에서 폴더나 프로젝트를 내보내고, 새 서버에서 가져오기 |
| 다른 프로젝트로 회의를 복사하고 싶다 | 회의를 내보낸 뒤 대상 프로젝트에서 가져오기 (원본은 그대로 남음) |
| 중요한 회의를 백업하고 싶다 | 「음성 포함」을 켜고 내보내 안전한 곳에 보관 |
| 읽기만 할 문서가 필요하다 | [회의록 내보내기](../export/)의 MD·PDF·DOCX 사용 |

회의를 같은 서버 안에서 다른 프로젝트나 폴더로 옮기기만 한다면 아카이브보다 **「프로젝트 이동」·「폴더로 이동」** 메뉴가 더 간단합니다. 자세한 내용은 [사이드바와 폴더](../../projects/sidebar-folders/)를 참고하세요.
