완성된 회의록은 문서 파일로 내려받거나, 다른 AI에 붙여 넣을 프롬프트로, 한 장짜리 화이트보드로 만들 수 있습니다. 여러 회의의 요약을 한꺼번에 받고 싶다면 폴더·프로젝트 단위 zip을 쓰면 됩니다. 이 페이지에서는 그 방법을 모두 설명합니다.

:::note
회의 전체를 다른 서버로 옮기거나 백업하려면 이 페이지가 아니라 [아카이브 내보내기·가져오기](../archive/)를 보세요.
:::

## 내보내기 창 열기

1. 내보낼 회의의 상세 화면을 엽니다.
2. 화면 상단 오른쪽 도구 모음의 「내보내기」 버튼을 누릅니다. 화면이 좁으면 아이콘만 보입니다.
3. 「회의록 내보내기」 창이 열립니다. 창 밖을 누르면 닫힙니다.

![회의록 내보내기 창](../../../assets/screens/export-panel.png)

창에는 형식을 고르는 두 줄이 있습니다.

| 줄 | 선택지 |
|---|---|
| 「파일」 | 「.md」, 「.pdf」, 「.docx」 |
| 「AI 생성」 | 「화이트보드」, 「프롬프트」 |

## 문서 파일로 내보내기(MD·PDF·DOCX)

1. 「파일」 줄에서 「.md」, 「.pdf」, 「.docx」 중 하나를 고릅니다.
2. 포함할 내용을 체크합니다.

   | 항목 | 설명 | 기본값 |
   |---|---|---|
   | 「AI 요약 포함」 | AI 회의록 | 켜짐 |
   | 「메모 포함」 | 회의 중 작성한 메모 | 켜짐 |
   | 「원본 텍스트 포함」 | 전사 원문 전체 | 꺼짐 |

3. 「다운로드 .md」(고른 형식에 따라 확장자가 바뀝니다) 버튼을 누릅니다.
4. 파일이 `회의제목_날짜.확장자` 형태로 저장됩니다. 파일 이름에 쓸 수 없는 문자는 자동으로 빼고, 공백은 밑줄로 바뀝니다.

내려받는 동안 버튼에 「다운로드 중...」이 표시됩니다. 실패하면 「내보내기에 실패했습니다. 다시 시도해 주세요.」가 나타나니 다시 눌러 보세요.

:::tip
회의록을 다른 문서에 붙여 쓸 때는 「.md」, 사람에게 전달하거나 인쇄할 때는 「.pdf」, 문장을 더 고쳐 쓸 때는 「.docx」가 편합니다.
:::

## 프롬프트로 내보내기

「프롬프트」는 회의록을 **다른 AI 서비스에 붙여 넣어 다시 만들 수 있게** 하는 텍스트 파일입니다. 시스템 프롬프트와 전사 데이터가 함께 담겨 있어, ChatGPT나 Claude 같은 곳에 그대로 붙여 넣으면 회의록을 생성할 수 있습니다.

1. 「AI 생성」 줄에서 「프롬프트」를 고릅니다.
2. 「다운로드 .txt」를 누릅니다.

프롬프트에는 AI 요약·메모·원본 텍스트 선택 항목이 나타나지 않습니다. 필요한 내용이 정해진 형태로 모두 담기기 때문입니다.

## 화이트보드로 내보내기

「화이트보드」는 AI 회의록을 한눈에 볼 수 있는 **한 장의 HTML 화면(.html)** 으로 만들어 줍니다. 만드는 곳은 환경에 따라 다릅니다.

| 환경 | 버튼 아래 표시 | 동작 |
|---|---|---|
| 데스크톱 앱 + 이 PC에 Claude Code 설치 | 「이 PC의 Claude Code」 | 내 PC의 Claude Code로 만듭니다. |
| 이 PC의 Claude Code를 쓸 수 없고(웹이거나, 데스크톱 앱에 Claude Code가 없음), 서버에서 화이트보드 사용이 켜져 있으며 서버에 Claude Code가 있음 | 「서버의 Claude Code」 | 서버에 설치된 Claude Code로 만듭니다. |
| 위 둘 다 불가능하거나 서버 설정이 꺼짐 | 「지시문 내려받기 · 내 Claude에서」 | 작성 지시문을 .txt 파일로 내려받아 직접 Claude에 붙여 넣습니다. |

AI 회의록이 아직 없는 회의에서는 버튼이 흐리게 표시되고 「AI 회의록이 필요합니다」라고 안내됩니다.

### Claude Code로 바로 만들기

1. 「AI 생성」 줄에서 「화이트보드」를 고릅니다.
2. 「화이트보드 만들기」를 누릅니다. AI 회의록만 읽어서 만들며, 메모와 원본 텍스트는 들어가지 않습니다.
3. 만드는 동안 진행 표시가 나타납니다. 내 PC에서 만들 때는 보통 1분 안에 끝납니다. 창을 닫거나 다른 화면으로 가도 계속 만들고, 끝나면 알림이 나타납니다.
4. 「화이트보드를 만들었습니다. 저장할 위치를 골라 주세요.」가 나오면 「저장」을 눌러 위치를 정합니다.

회의록을 다시 요약하는 등 내용이 바뀌면 「회의록이 바뀌었습니다. 다시 만들어 주세요.」가 나타납니다. 이때 「다시 만들기」로 새로 만들 수 있습니다. 실패하면 「다시 시도」를 누르세요.

:::caution
서버의 Claude Code로 만드는 경우 서버에 로그인된 계정의 사용량이 쓰입니다. 사용 여부는 서버 관리자가 정합니다.
:::

### 지시문을 내려받아 직접 만들기

Claude Code를 쓸 수 없는 환경에서는 다음 안내가 나타납니다.

- 서버 설정이 꺼진 경우: 「Claude 화이트보드가 꺼져 있습니다. 대신 화이트보드 작성 지시문을 .txt 파일로 내려받아, 내 Claude Code나 claude.ai에 붙여 넣어 만들 수 있습니다.」
- 서버에 Claude Code가 없는 경우: 「서버에서 Claude Code를 찾을 수 없어 화이트보드를 바로 만들 수 없습니다. 대신 지시문을 .txt 파일로 내려받아 주세요.」

1. 「지시문 내려받기 (.txt)」를 누릅니다. 지시문이 `.txt` 파일로 저장됩니다.
2. 파일 내용을 Claude Code나 claude.ai에 붙여 넣으면 화이트보드가 만들어집니다.
3. 파일 대신 클립보드로 쓰려면 「복사」를 누릅니다. 자동 복사가 막혀 있으면 지시문이 상자에 표시되니 직접 선택해 복사하세요.

:::caution
claude.ai에 붙여 넣으면 **회의 내용이 내 claude.ai 계정으로 전달됩니다.** 기밀 회의라면 사내 규정을 먼저 확인하세요.
:::

## 요약 zip으로 한꺼번에 내보내기

여러 회의의 AI 회의록을 **폴더 구조 그대로** 모아서 zip 파일로 받습니다. 해당 프로젝트의 멤버라면 누구나 쓸 수 있습니다. 확인 창 없이 바로 시작됩니다.

### 폴더의 요약 내보내기

1. 왼쪽 사이드바에서 폴더의 **⋮** 메뉴를 엽니다.
2. 「요약 내보내기(zip)」를 선택합니다. 진행 중에는 「내보내는 중…」이 표시됩니다.
3. 폴더와 그 하위 폴더의 모든 회의 요약이 담긴 zip이 저장됩니다.

### 프로젝트의 요약 내보내기

1. 「프로젝트」 화면에서 프로젝트 카드의 **⋮** 메뉴를 엽니다.
2. 「요약 내보내기(zip)」를 선택합니다.
3. 프로젝트 전체 회의(폴더에 속하지 않은 회의 포함)의 요약이 담긴 zip이 저장됩니다.

요약이 있는 회의가 하나도 없으면 「내보낼 요약이 없습니다」라고 표시됩니다. 그 밖의 실패는 「내보내기에 실패했습니다」(프로젝트는 「요약 내보내기에 실패했습니다」)로 나타납니다.

## 문제가 생겼을 때

- **「내보내기」 버튼이 보이지 않습니다.** 모바일이나 좁은 화면에서는 글자 없이 아이콘만 보일 수 있습니다.
- **PDF나 DOCX가 만들어지지 않습니다.** 잠시 후 다시 시도하세요. 회의록이 너무 길면 시간이 걸립니다.
- **내용이 일부만 담겼습니다.** 「AI 요약 포함」, 「메모 포함」, 「원본 텍스트 포함」 체크를 확인하세요.

D'Flow로 보내는 방법은 [D'Flow 전송](../dflow/)에서 설명합니다. 회의록을 만들고 고치는 방법은 [AI 회의록](../../minutes/ai-summary/)을 참고하세요.
