프로젝트는 회의와 폴더를 담는 가장 큰 단위입니다. 팀이 함께 쓰는 프로젝트가 있고, 나만 쓰는 개인 프로젝트가 있습니다. 이 쪽에서는 프로젝트 화면, 프로젝트 만들기와 고치기, 멤버와 초대 링크, 즐겨찾기를 설명합니다.

## 프로젝트 화면 열기

프로젝트 화면은 사이드바 맨 위의 프로젝트 전환 단추에서 「전체 프로젝트…」를 눌러 엽니다. 전환 단추는 현재 프로젝트의 아이콘과 이름을 보여 줍니다. 처음 앱을 열었을 때의 프로젝트 선택 화면은 [프로젝트 선택](../../start/project-select/)을 보세요.

![프로젝트 화면](../../../assets/screens/projects-list.png)

1. 제목 줄: 「프로젝트」 제목이 있습니다. 가져오기 권한이 있으면 오른쪽에 「가져오기」 단추가 나옵니다.
2. 프로젝트 카드: 프로젝트마다 카드가 하나씩 있습니다. 카드에는 아이콘, 이름, 「멤버 3 · 회의 12」 같은 인원·회의 수, 설명(두 줄까지)이 보입니다.
3. 별 단추: 카드 오른쪽 위의 별 모양 단추입니다. 즐겨찾기를 켜고 끕니다.
4. 점 세 개 단추(「프로젝트 메뉴」): 편집, 멤버 관리, 내보내기, 휴지통 같은 작업이 들어 있습니다.
5. 「새 프로젝트」 카드: 점선 테두리의 카드입니다. 프로젝트를 만들 권한이 있을 때만 보입니다.

카드를 누르면 그 프로젝트가 현재 프로젝트가 되고 회의 목록 화면으로 이동합니다. 이때 폴더 선택은 「전체 회의」로 초기화됩니다.

별 표시한 프로젝트는 화면 맨 앞에 모아서 보여 줍니다.

## 팀 프로젝트와 개인 프로젝트

| 종류 | 설명 |
|---|---|
| 팀 프로젝트 | 여러 사람이 멤버로 들어와 회의를 함께 보는 프로젝트입니다. |
| 개인 프로젝트 | 내 회의를 담는 프로젝트입니다. 이름이 항상 「내 회의」로 보입니다. 다른 사람의 개인 프로젝트는 목록에 나오지 않습니다. |

:::note
개인 프로젝트는 휴지통으로 보낼 수 없습니다. 「휴지통」 메뉴는 팀 프로젝트에서만 나옵니다.
:::

## 프로젝트 만들기

프로젝트는 관리자와 매니저 권한이 있는 사용자만 만들 수 있습니다. 데스크톱 앱을 로컬 모드로 혼자 쓸 때는 누구나 만들 수 있습니다. 권한이 없으면 「새 프로젝트」 카드가 보이지 않습니다.

1. 프로젝트 화면에서 「새 프로젝트」 카드를 누릅니다. 사이드바의 프로젝트 전환 단추에서 「새 프로젝트」를 골라도 같은 창이 바로 열립니다.
2. 「새 프로젝트」 창이 뜨면 「이름」을 입력합니다. 최대 100자입니다. 이름을 입력하면 왼쪽의 아이콘 미리보기에 바로 반영됩니다.
3. 필요하면 「설명 (선택)」을 적습니다.
4. 「아이콘」에서 모양을 고릅니다. 위쪽 탭은 「아이콘」, 「이모지」, 「업로드」 세 가지입니다. 색상도 고를 수 있고, 「업로드」에서는 이미지를 끌어다 놓거나 「이미지 선택」으로 고릅니다.
5. 「생성」을 누릅니다. 이름이 비어 있으면 눌러지지 않습니다. 저장에 실패하면 「저장에 실패했습니다.」가 나옵니다.

## 프로젝트 고치기

카드의 점 세 개 단추에서 「편집」을 고르면 「프로젝트 편집」 창이 열립니다. 이름, 설명, 아이콘을 고치고 「저장」을 누릅니다.

고치는 창에는 「도메인 파일」 영역이 더 있습니다. 여기서 고른 도메인 파일은 이 프로젝트의 모든 폴더와 회의에 자동으로 적용됩니다. 폴더나 회의에서 따로 지정하지 않아도 이어받습니다.

## 프로젝트 메뉴

점 세 개 단추를 누르면 나오는 메뉴입니다.

| 메뉴 | 하는 일 | 누가 보나 |
|---|---|---|
| 편집 | 이름·설명·아이콘·도메인 파일을 고칩니다. | 모두 |
| 멤버 관리 | 멤버와 초대 링크를 관리합니다. | 모두(읽기만 할 수도 있음) |
| 요약 내보내기(zip) | 프로젝트의 회의 요약을 zip 파일로 받습니다. | 모두 |
| 내보내기 | 프로젝트 전체를 파일로 내보냅니다. | 시스템 관리자 |
| 휴지통 | 프로젝트를 휴지통으로 보냅니다. | 팀 프로젝트의 관리자 또는 시스템 관리자 |

「요약 내보내기(zip)」를 누르면 잠시 「내보내는 중…」이 보이고 파일이 내려받아집니다. 내보낼 요약이 없으면 「내보낼 요약이 없습니다」가 나옵니다. 요약 zip에 대한 자세한 내용은 [내보내기](../../share/export/)를 보세요.

「휴지통」을 누르면 「'프로젝트 이름' 프로젝트를 휴지통으로 이동합니다. 계속할까요?」라고 한 번 더 묻습니다. 회의가 남아 있는 프로젝트는 지울 수 없고 「회의가 남아 있는 프로젝트는 삭제할 수 없습니다.」가 나옵니다. 먼저 회의를 다른 곳으로 옮기거나 지워야 합니다. 지운 프로젝트의 복구는 [휴지통](../../trash/trash/)에서 다룹니다.

### 프로젝트 내보내기와 가져오기

시스템 관리자(또는 로컬 모드 사용자)는 프로젝트 전체를 파일로 옮길 수 있습니다.

1. 점 세 개 메뉴에서 「내보내기」를 고르면 「프로젝트 내보내기」 창이 뜹니다.
2. 「음성 포함」을 끄면 회의록·요약 같은 글 정보만 내보내서 파일이 작아집니다.
3. 「내보내기」를 누릅니다.

반대로 프로젝트 화면 오른쪽 위의 「가져오기」를 누르고 내보낸 파일을 고르면 새 프로젝트로 들어옵니다. 올바른 내보내기 파일이 아니면 「가져오기에 실패했습니다. 올바른 내보내기 파일인지 확인해 주세요.」가 나옵니다. 가져오기가 끝나면 새 프로젝트로 바로 이동합니다.

## 멤버 관리

점 세 개 메뉴의 「멤버 관리」를 누르면 「프로젝트 이름 · 멤버 관리」 창이 열립니다.

멤버를 추가하고 역할을 바꿀 수 있는 사람은 시스템 관리자, 그리고 그 프로젝트의 관리자인 매니저입니다. 그 밖의 사용자는 멤버 목록을 읽기만 합니다.

### 멤버 목록

「멤버 (3)」처럼 인원이 함께 보입니다. 멤버마다 이름, 이메일, 역할이 있습니다. 역할은 두 가지입니다.

| 역할 | 설명 |
|---|---|
| 관리자 | 프로젝트의 멤버와 초대를 관리합니다. |
| 멤버 | 프로젝트의 회의를 함께 보고 씁니다. |

권한이 있으면 멤버 옆에 「관리자로 위임」 또는 「멤버로 변경」 단추와 「멤버 제거」 단추가 나옵니다. 자기 자신의 관리자 권한을 풀려고 하면 「본인의 관리자 권한을 해제합니다. 계속할까요?」라고 먼저 확인합니다.

### 이름이나 이메일로 멤버 추가

1. 「이름 또는 이메일로 멤버 추가」 칸에 이름이나 이메일을 입력합니다.
2. 옆의 역할 상자에서 「멤버로 추가」나 「관리자로 추가」를 고릅니다.
3. 「추가」를 누릅니다.

같은 이름의 사용자가 여럿이면 「동명이인 — 추가할 사람을 선택하세요」와 함께 이메일이 달린 후보가 나옵니다. 맞는 사람 옆의 「추가」를 누릅니다. 찾는 사용자가 없으면 「해당 사용자를 찾을 수 없습니다.」가 나옵니다.

### 초대 링크

아직 계정이 없는 사람이나 링크로 편하게 부르고 싶은 사람은 초대 링크로 맞이합니다.

1. 「초대 링크」 영역에서 필요하면 「만료 (선택)」 일시와 「최대 사용 (선택)」 횟수를 정합니다. 최대 사용 칸을 비워 두면 「무제한」입니다.
2. 「링크 생성」을 누릅니다.
3. 목록에 새 링크가 생깁니다. 링크 오른쪽의 「링크 복사」 단추로 복사해서 메신저나 메일로 전합니다.

목록의 각 링크에는 사용 횟수가 「2/5회 사용」처럼 보이고, 기한이 지났거나 다 쓴 링크에는 「만료됨」이 붙습니다. 더 이상 쓰지 않는 링크는 「초대 취소」 단추로 없앱니다. 활성 링크가 없으면 「활성 초대 링크가 없습니다.」가 보입니다.

:::caution
초대 링크를 가진 사람은 누구나 프로젝트에 들어올 수 있습니다. 링크는 필요한 사람에게만 전하고, 사용이 끝나면 「초대 취소」로 정리하세요. 만료 일시와 최대 사용 횟수를 함께 정해 두면 안전합니다.
:::

## 초대 링크로 들어오기

초대 링크를 받은 사람은 링크를 열어 프로젝트에 합류합니다.

![초대 링크 합류 화면](../../../assets/screens/invite-redeem.png)

1. 링크를 열면 프로젝트의 아이콘과 이름, 「프로젝트에 초대되었습니다.」가 보입니다.
2. 이미 로그인한 상태라면 「합류하기」를 누릅니다.
3. 계정이 없으면 「이름」, 「이메일」, 「비밀번호」, 「비밀번호 확인」을 입력하고 「가입하고 합류하기」를 누릅니다.
4. 계정이 있지만 로그인하지 않았다면 「이미 계정이 있으신가요?」 옆의 「로그인」을 눌러 이메일과 비밀번호를 입력하고 「로그인하고 합류하기」를 누릅니다.

합류가 끝나면 그 프로젝트의 회의 목록으로 이동합니다. 링크가 만료됐거나 잘못된 경우 「만료되었거나 유효하지 않은 초대 링크입니다.」가 나오고, 「홈으로」 단추로 돌아갑니다. 비밀번호가 서로 다르면 「비밀번호가 일치하지 않습니다.」, 이미 쓰는 이메일이면 「이미 사용 중인 이메일이거나 입력값을 확인해 주세요.」라고 알려 줍니다.

:::tip
링크를 받았는데 만료됐다면 프로젝트 관리자에게 새 링크를 부탁하세요.
:::

## 즐겨찾기

자주 쓰는 프로젝트에는 별을 달아 둡니다.

1. 프로젝트 카드에 마우스를 올리면 오른쪽 위에 별 단추가 나타납니다. 「즐겨찾기 추가」를 누르면 별이 노랗게 채워집니다. 이미 즐겨찾기한 프로젝트의 별은 항상 보이고, 누르면 「즐겨찾기 해제」됩니다.
2. 즐겨찾기한 프로젝트는 프로젝트 화면의 맨 앞에 모입니다.
3. 사이드바의 프로젝트 전환 목록에도 즐겨찾기한 프로젝트만 나옵니다. 현재 프로젝트는 즐겨찾기가 아니어도 맨 위에 함께 보입니다.

:::note
즐겨찾기한 프로젝트가 하나도 없으면 전환 목록에는 모든 프로젝트가 나옵니다. 즐겨찾기에 들어 있지 않은 프로젝트로 옮기려면 전환 목록 아래의 「전체 프로젝트…」를 눌러 프로젝트 화면에서 고릅니다.
:::

## 프로젝트 사이 이동

회의나 폴더는 다른 프로젝트로 옮길 수 있습니다. 회의 카드의 메뉴 또는 폴더 메뉴에서 「프로젝트 이동」을 고르면 같은 이름의 창이 열리고, 옮길 프로젝트를 골라 「이동」을 누릅니다. 내가 멤버로 들어 있는 다른 프로젝트만 후보에 나오며, 후보가 없으면 「이동할 다른 프로젝트가 없습니다.」가 보입니다. 자세한 내용은 [폴더와 사이드바](../sidebar-folders/)와 [회의 목록](../../meetings/list/)을 보세요.
