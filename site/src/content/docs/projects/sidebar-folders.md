사이드바는 앱 왼쪽에 늘 떠 있는 길잡이입니다. 프로젝트를 바꾸고, 대시보드·검색·회의 목록으로 이동하고, 폴더로 회의를 정리하는 일이 모두 여기서 시작됩니다.

## 사이드바 구성

![사이드바](../../../assets/screens/sidebar.png)

위에서 아래로 다음과 같이 구성됩니다.

1. 프로젝트 전환 단추: 현재 프로젝트의 아이콘과 이름이 보입니다. 누르면 프로젝트 목록이 펼쳐집니다. 자세한 내용은 [프로젝트 관리](../projects/)를 보세요. 옆의 「사이드바 닫기」 단추로 사이드바를 접습니다.
2. 「대시보드」: 회의 현황 화면으로 이동합니다. [대시보드](../../meetings/dashboard/)를 보세요.
3. 「검색」: 전역 검색 화면으로 이동합니다. [전역 검색](../../ai/search/)을 보세요.
4. 「회의 목록」: 현재 프로젝트의 모든 회의를 봅니다. [회의 목록](../../meetings/list/)을 보세요.
5. 폴더 트리: 「폴더」 아래에 폴더가 계층으로 나열됩니다.
6. 「오프라인 회의」: Android 앱에서만 나오는 항목입니다. [오프라인 녹음](../../recording/offline/)을 보세요.
7. 아래쪽 영역: 테마 전환 단추, 「휴지통」, 「또박또박 소개」, 「설정」이 있습니다. 관리자에게는 「사용자 관리」가 더 보입니다. 서버에 로그인해 쓰는 경우 내 이름과 「로그아웃」도 나옵니다.

테마 단추는 누를 때마다 「라이트」, 「다크」, 「시스템」 순으로 바뀝니다. 「시스템」은 컴퓨터의 설정을 따릅니다.

### 사이드바 접기와 폭 조절

- 「사이드바 닫기」 단추를 누르면 사이드바가 접히고 왼쪽에 좁은 줄만 남습니다. 그 줄의 「사이드바 열기」 단추로 다시 펼칩니다.
- 사이드바 오른쪽 가장자리를 끌면 폭을 조절할 수 있습니다. 가장자리에 마우스를 올리면 「드래그하여 사이드바 폭 조절」이라는 안내가 나옵니다.

### 모바일에서

화면이 좁은 기기에서는 사이드바가 항상 떠 있지 않습니다. 상단 막대의 「메뉴 열기」 단추를 누르면 사이드바가 화면 위에 겹쳐서 열리고, 항목을 고르면 자동으로 닫힙니다. 하단에는 「홈」, 「회의」, 「검색」, 「설정」 탭이 있는 내비게이션 줄이 있습니다.

## 폴더 트리

폴더는 회의를 주제나 시기별로 묶어 두는 서랍입니다. 폴더 안에 폴더를 둘 수 있어 계층 구조로 정리할 수 있습니다.

트리의 맨 위 「폴더」 줄은 폴더에 넣지 않은 회의(「미분류」)를 보여 줍니다. 이 줄의 화살표로 트리 전체를 펼치고 접으며, 오른쪽 숫자는 폴더의 총 개수입니다.

각 폴더 줄에는 다음이 보입니다.

| 표시 | 뜻 |
|---|---|
| 폴더 아이콘 | 펼쳐져 있으면 열린 폴더, 접혀 있으면 닫힌 폴더로 보입니다. |
| 별 아이콘(「중요 폴더」) | 중요 표시한 폴더입니다. |
| 자물쇠 아이콘(「비공개 폴더」) | 비공개 폴더입니다. 작성자와 관리자만 볼 수 있습니다. |
| 오른쪽 숫자 | 그 폴더의 회의 수입니다. |
| 점 세 개 단추(「메뉴」) | 마우스를 올리면 숫자 대신 나타납니다. 폴더 메뉴를 엽니다. |

폴더를 누르면 오른쪽 화면에 그 폴더의 회의가 나옵니다. 하위 폴더가 있으면 같이 펼쳐지고, 목록 화면에는 하위 폴더 카드도 함께 나옵니다.

## 폴더 만들기

1. 사이드바의 「폴더」 줄에 마우스를 올립니다. 숫자 자리에 더하기 단추가 나타납니다.
2. 더하기 단추를 누르면 「새 폴더」 창이 뜹니다.
3. 「폴더 이름」 칸에 이름을 입력하고 「확인」을 누릅니다. 닫으려면 「취소」를 누릅니다.

하위 폴더는 부모 폴더의 메뉴에서 「하위 폴더」를 골라 만듭니다. 창 이름은 「하위 폴더 만들기」이고, 만든 뒤 부모 폴더가 자동으로 펼쳐집니다.

## 폴더 메뉴

폴더 줄의 점 세 개 단추를 누르면 메뉴가 나옵니다.

| 메뉴 | 하는 일 |
|---|---|
| 이름 변경 | 「폴더 이름 변경」 창에서 이름을 바꿉니다. |
| 하위 폴더 | 이 폴더 안에 새 폴더를 만듭니다. |
| 비공개로 전환 / 모든 사용자에게 공유 | 폴더 공개 범위를 바꿉니다. 지금 상태와 반대 항목이 보입니다. |
| 중요 표시 / 중요 해제 | 폴더에 중요 표시를 달거나 뗍니다. |
| 오타 사전 | 이 폴더의 모든 회의에 적용되는 오타 사전을 관리합니다. |
| 도메인 파일 | 이 폴더의 모든 회의에 자동 적용되는 도메인 파일을 관리합니다. |
| 협업자 관리 | 이 폴더의 협업자를 관리합니다. |
| 프로젝트 이동 | 폴더를 다른 프로젝트로 옮깁니다. |
| 내보내기(.tgz) | 폴더를 파일로 내보냅니다. |
| 요약 내보내기(zip) | 폴더 안 회의의 요약을 zip으로 받습니다. |
| 휴지통 | 폴더를 휴지통으로 보냅니다. |

메뉴 항목 가운데 서버가 허용하지 않는 작업은 눌러도 실행되지 않습니다. 폴더를 만든 사람이나 관리자가 아니라면 수정이 되지 않을 수 있습니다.

:::caution
폴더를 「휴지통」으로 보내면 「'폴더 이름' 폴더를 휴지통으로 이동합니다. 폴더 안의 회의·하위폴더도 함께 이동합니다. 계속할까요?」라고 확인합니다. 폴더 안의 회의와 하위 폴더도 함께 휴지통으로 가므로 신중하게 고르세요. 복구는 [휴지통](../../trash/trash/)에서 합니다.
:::

### 오타 사전, 도메인 파일, 협업자

세 메뉴는 폴더 단위로 설정하면 그 폴더 아래의 모든 회의에 이어집니다.

- 「오타 사전」: 「잘못된 용어」와 「올바른 용어」를 짝지어 추가합니다. 방식은 「리터럴」(글자 그대로)과 「정규식」 중에서 고릅니다. 항목마다 「사용」 체크로 켜고 끌 수 있습니다. 전사 편집에서 쓰는 오타 사전은 [전사 편집](../../minutes/transcript/)을 보세요.
- 「도메인 파일」: 용어집 같은 도메인 파일을 연결합니다. 폴더에 연결한 파일은 하위의 모든 회의에 자동으로 적용(상속)됩니다.
- 「협업자 관리」: 이 폴더의 협업자는 하위 모든 회의에 실시간으로 이어집니다. 자세한 권한은 [협업자 권한](../../share/collaborators/)을 보세요.

### 폴더 공개 범위

공유 중인 폴더에서 「비공개로 전환」을 고르면 폴더 줄에 자물쇠가 붙고, 그 폴더의 회의는 작성자와 관리자만 볼 수 있게 됩니다. 다시 「모든 사용자에게 공유」를 고르면 풀립니다.

## 폴더와 회의 옮기기

### 끌어서 옮기기

폴더와 회의는 끌어다 놓아서 옮길 수 있습니다.

1. 옮길 폴더 줄(사이드바) 또는 회의 카드·목록 줄을 마우스로 누른 채 조금 끕니다.
2. 놓을 폴더 위에 올립니다. 대상 폴더가 강조되어 보입니다. 접힌 폴더 위에 잠시 머무르면 자동으로 펼쳐집니다.
3. 마우스를 놓으면 이동합니다.

- 사이드바의 맨 위 「폴더」 줄에 놓으면 폴더에서 빼서 최상위(미분류)로 옮깁니다.
- 폴더를 자기 자신이나 자기 하위 폴더 안으로는 옮길 수 없습니다.

### 메뉴로 옮기기

끌어 옮기기가 불편하면 회의 카드의 메뉴에서 「폴더로 이동」을 고릅니다. 「폴더로 이동」 창에 회의 제목이 보이고, 「미분류」와 폴더 트리 중에서 목적지를 고릅니다. 현재 위치와 다른 곳을 골라야 「이동」 단추가 눌러집니다.

다른 프로젝트로 옮길 때는 폴더 메뉴나 회의 메뉴의 「프로젝트 이동」을 씁니다. 폴더를 옮기면 폴더 안의 회의도 함께 옮겨집니다.

## 폴더 경로(브레드크럼)

회의 목록 화면 위쪽에는 지금 보고 있는 폴더의 경로가 한 줄로 나옵니다.

- 맨 앞의 「전체 회의」를 누르면 프로젝트의 모든 회의로 돌아갑니다.
- 폴더에 넣지 않은 회의를 보고 있으면 「전체 회의 › 미분류」로 보입니다.
- 폴더 안에 있으면 「전체 회의 › 개발 › 주간회의」처럼 부모 폴더들이 이어지고, 마지막 폴더는 굵은 글씨입니다. 중간 폴더를 누르면 그 폴더로 올라갑니다.

폴더를 고를 때마다 주소가 바뀌므로 브라우저의 뒤로 가기 단추를 누르면 바로 앞에 보던 폴더(부모 폴더)로 돌아갑니다.

## 중요 표시

중요 표시는 폴더와 회의 모두에 달 수 있고, 회의 목록을 정리하는 기준이 됩니다.

- 회의에 달기: 회의 카드·목록 줄의 별 단추를 누릅니다. 별 단추의 안내 문구는 「중요 표시」, 달려 있으면 「중요 해제」입니다. 잠긴 회의에서는 눌러지지 않고 「잠긴 회의입니다」라고 안내합니다.
- 폴더에 달기: 폴더 메뉴의 「중요 표시」를 고릅니다. 중요 폴더에 새로 만든 회의는 처음부터 중요 회의가 됩니다.

회의 목록은 기본으로 중요 표시된 회의와 아직 끝나지 않은 회의(예약·녹음 중·대기)를 보여 주고, 중요하지 않은 완료 회의는 숨깁니다. 모두 보려면 목록 화면의 「전체 보기」를 켭니다. 자세한 내용은 [회의 목록](../../meetings/list/)을 보세요.

:::tip
오래 두고 찾아볼 회의록에는 별을 달고, 가벼운 확인용 회의는 별 없이 두면 목록이 깔끔합니다.
:::

## 태그

태그는 폴더와 별개로 회의에 붙이는 색깔 이름표입니다. 하나의 회의에 여러 태그를 붙일 수 있고, 회의 카드와 회의 상세 화면에서 색이 입혀진 이름표로 보입니다.

1. 회의 카드의 점 세 개 메뉴에서 「정보 수정」을 고릅니다.
2. 「회의 정보 수정」 창의 「태그」 영역에서 붙일 태그를 누릅니다. 선택된 태그는 색이 채워집니다. 다시 누르면 뗍니다.
3. 새 태그가 필요하면 「새 태그」를 누르고 「태그 이름」(최대 30자)을 입력한 뒤 「추가」를 누릅니다. 입력 칸에서 Enter 키를 눌러도 됩니다.
4. 「저장」을 누릅니다.

「정보 수정」 창에서는 태그 외에도 제목, 요약, 회의 유형, 이전 회의 참고, 도메인 파일, 협업자, 공유 설정을 고칠 수 있습니다.
