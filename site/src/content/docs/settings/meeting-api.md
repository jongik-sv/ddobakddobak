회의 API는 또박또박에 쌓인 회의 전사, 요약, 회의록을 외부 도구나 AI 에이전트가 읽고 검색하고 기록할 수 있게 해 주는 기능입니다. 예를 들어 Claude Code에게 "지난주 예산 회의에서 뭐가 결정됐지?"라고 물으면, 에이전트가 또박또박의 회의를 찾아 읽고 답할 수 있습니다.

이 기능은 세 가지로 이루어져 있습니다.

| 구성 | 설명 |
|---|---|
| 회의 API | 회의 목록, 전사, 요약 조회와 검색, 회의 등록, 메모 작성을 제공하는 인터페이스입니다. |
| API 토큰 | 외부 도구가 내 계정으로 접근할 때 내미는 개인용 열쇠입니다. 「개인설정」 탭에서 발급합니다. |
| LLM 스킬 패키지 | AI 에이전트가 회의 API를 쉽게 쓰도록 만든 설치 파일(zip)입니다. 「개인설정」 탭에서 내려받습니다. |

:::note
토큰으로 접근할 수 있는 범위는 항상 **내 계정이 볼 수 있는 회의**로 제한됩니다. 내가 만든 회의, 협업자로 초대된 회의, 프로젝트에서 공유된 회의입니다. 기밀 구간을 잘라 낸 회의는 잘라 낸 뒤의 내용만 제공됩니다.
:::

## API 토큰 화면

「설정」 창의 「개인설정」 탭에서 「API 토큰」 카드를 찾습니다. 이 카드는 관리자가 아닌 일반 사용자에게도 보입니다.

1. 제목 「API 토큰」과 설명 「외부 도구·에이전트가 내 회의 데이터에 접근할 때 쓸 개인 액세스 토큰을 발급·관리합니다.」
2. 「LLM 스킬 다운로드」 단추
3. 「토큰 발급」 단추
4. 발급된 토큰 목록 표

발급된 토큰이 없으면 「발급된 토큰이 없습니다.」가 나타납니다. 목록 표의 열은 다음과 같습니다.

| 열 | 내용 |
|---|---|
| 이름 | 발급할 때 붙인 이름 |
| 토큰 | 앞부분만 보이고 나머지는 가려집니다(예: `ddbk_xxxx••••••••`). |
| 스코프 | 이 토큰이 할 수 있는 일 |
| 만료일 | 토큰이 효력을 잃는 날. 없으면 「없음」 |
| 마지막 사용 | 마지막으로 쓰인 날. 한 번도 안 쓰였으면 「사용 안 함」 |
| 상태 | 「활성」 또는 「폐기됨」 |

## 1단계: 토큰 발급

1. 「개인설정」 탭의 「API 토큰」 카드에서 「토큰 발급」을 누릅니다. 「API 토큰 발급」 창이 열립니다.
2. 「이름」을 입력합니다. 어디에 쓰는 토큰인지 알아볼 수 있게 적으세요(예: `Claude Code 연동`).
3. 「스코프」에서 허용할 일을 고릅니다. 아래 표를 참고하세요.
4. 「만료일」을 정합니다. 기본값은 오늘부터 90일 뒤입니다.
5. 「발급」을 누릅니다. 이름이 비어 있거나 스코프가 하나도 선택되지 않으면 누를 수 없습니다.

### 스코프

스코프는 토큰이 할 수 있는 일의 범위입니다. 처음에는 읽기 4개가 켜져 있고 쓰기는 꺼져 있습니다.

| 스코프 | 이름 | 할 수 있는 일 |
|---|---|---|
| `meetings:read` | 회의 조회 | 프로젝트, 폴더, 회의 목록과 상세, 에이전트 노트 조회 |
| `transcripts:read` | 전사 조회 | 회의 전사 전체(화자, 시간 포함) 조회 |
| `summaries:read` | 요약 조회 | 최종 요약(핵심 논의, 결정 사항, 회의록) 조회 |
| `search:read` | 검색 | 전사와 요약을 대상으로 한 검색 |
| `meetings:write` | 회의 쓰기 | 회의 등록(텍스트 전사, 오디오), 에이전트 노트 추가, 요약 다시 만들기 |

:::tip
필요한 스코프만 켜세요. 조회만 하는 도구라면 읽기 스코프만 있으면 충분합니다. 쓰기 스코프는 실제로 회의를 등록하거나 메모를 남길 도구에만 주세요.
:::

### 발급 직후 화면

발급하면 「토큰이 발급되었습니다」 화면이 나타납니다.

1. 토큰 값: `ddbk_`로 시작하는 긴 문자열이 나타납니다. 「복사」 단추로 복사합니다.
2. 「설정 파일(.env.ddobak) 다운로드」: 서버 주소와 토큰이 미리 채워진 설정 파일을 받습니다.
3. 설치 프롬프트: 설정 파일을 받은 뒤 Claude Code 같은 에이전트에 붙여 넣을 안내문입니다. 「프롬프트 복사」로 복사합니다.
4. 「닫기」

:::caution
토큰 값은 이 화면에서 **딱 한 번만** 보입니다. 닫으려고 하면 「닫으면 이 토큰 값을 다시 볼 수 없습니다. 안전한 곳에 복사해 두셨나요?」라고 확인합니다. 잃어버리면 다시 볼 수 없으므로 폐기하고 새로 발급해야 합니다. 토큰은 비밀번호와 같으니 다른 사람에게 보내거나 메신저, 문서, 소스 코드에 그대로 적어 두지 마세요.
:::

### 토큰 폐기

유출이 의심되거나 더 이상 쓰지 않는 토큰은 즉시 폐기하세요.

1. 목록에서 해당 토큰 줄 오른쪽 끝의 휴지통 단추(「토큰 폐기」)를 누릅니다.
2. 「'이름' 토큰을 폐기할까요? 이 토큰을 쓰는 연동은 즉시 인증에 실패합니다.」라고 묻습니다. 확인을 누릅니다.
3. 상태가 「폐기됨」으로 바뀝니다.

폐기한 토큰은 되살릴 수 없습니다. 이미 폐기된 줄에는 폐기 단추가 보이지 않습니다.

## 2단계: LLM 스킬 설치

스킬은 AI 에이전트에게 "또박또박 회의는 이렇게 조회하면 된다"를 알려 주는 설치 파일입니다. Claude Code용 스킬과, 다른 에이전트를 위한 설명서(`AGENT.md`)가 들어 있습니다. 내려받는 파일은 `ddobak-skill.zip`입니다.

### 스킬 내려받기

1. 「API 토큰」 카드에서 「LLM 스킬 다운로드」를 누릅니다. 받는 동안 단추는 「내려받는 중...」으로 바뀝니다.
2. 파일이 내려오면 카드 안에 설치 안내가 나타납니다. 「받은 zip을 직접 풀 필요 없이, 아래 프롬프트를 Claude Code 같은 에이전트에 붙여넣으면 설치까지 알아서 해줍니다.」
3. 「프롬프트 복사」를 눌러 복사합니다. 복사되면 단추 글자가 「복사됨」으로 바뀝니다.
4. Claude Code 같은 에이전트에 붙여 넣고 실행합니다. 에이전트가 zip을 스킬 폴더에 풀고 연결을 확인합니다.

안내를 닫으려면 오른쪽 위의 X 단추(「설치 안내 닫기」)를 누릅니다.

### 설정 파일 설치

스킬이 내 계정으로 접속하려면 서버 주소와 토큰이 담긴 설정 파일이 필요합니다.

1. 1단계에서 토큰을 발급한 직후 화면에서 「설정 파일(.env.ddobak) 다운로드」를 누릅니다.
2. 같은 화면의 설치 프롬프트를 복사해 에이전트에 붙여 넣습니다.
3. 에이전트가 파일을 스킬 폴더에 옮기고 연결을 확인한 뒤, 토큰이 평문으로 들어 있는 다운로드 원본 파일을 삭제해 줍니다.

브라우저에 따라 파일 이름이 `env.ddobak`(맨 앞의 점 없음)으로 저장될 수 있습니다. 그대로 두어도 동작합니다.

:::caution
`.env.ddobak` 파일에는 토큰이 그대로 들어 있습니다. 공유하거나 저장소에 올리지 마세요. 스킬 zip 자체에는 토큰이 들어 있지 않습니다.
:::

### 직접 설치하고 싶다면

에이전트에게 맡기지 않고 직접 설치할 수도 있습니다.

1. 내려받은 zip을 스킬 폴더에 풉니다. macOS와 Linux에서는 `~/.claude/skills/ddobak-meetings/`, Windows에서는 `%USERPROFILE%\.claude\skills\ddobak-meetings\`입니다.
2. 받은 `.env.ddobak`을 스킬 폴더의 맨 위(`SKILL.md`와 같은 위치)에 넣습니다.
3. 에이전트(Claude Code)를 다시 시작합니다.

폴더 이름은 `ddobak-meetings`여야 합니다. 서버 주소와 토큰은 파일 대신 환경변수 `DDOBAK_API_URL`, `DDOBAK_API_TOKEN`으로 줄 수도 있으며, 환경변수가 있으면 파일보다 우선합니다.

## 3단계: 에이전트에게 시키기

설치가 끝나면 명령어를 외울 필요가 없습니다. 평소처럼 자연어로 요청하면 회의와 관련된 요청에서 스킬이 알아서 동작합니다.

| 하고 싶은 일 | 이렇게 말해 보세요 | 필요한 스코프 |
|---|---|---|
| 지난 회의 내용 찾기 | "지난주 예산 회의에서 뭐가 결정됐지?" | 검색, 전사 조회 |
| 회의 목록 보기 | "물류 폴더에 있는 회의 목록 보여줘" | 회의 조회 |
| 요약 보기 | "307번 회의 요약해줘" | 요약 조회 |
| 문서로 만들기 | "171번 회의 내용으로 보고서 초안을 만들어줘" | 읽기 계열 |
| 파일로 저장 | "307번 회의를 마크다운으로 저장해줘" | 읽기 계열 |
| 메모 남기기 | "307번 회의에 메모 남겨줘: 다음 주까지 견적 재요청" | 회의 쓰기 |
| 녹음 올리기 | "이 녹음 파일을 물류 폴더에 회의로 올려줘" | 회의 쓰기 |

여러 회의를 묶는 요청("이번 달 물류 회의들을 훑어서 반품 이슈 진행 상황을 정리해줘")도 됩니다.

### 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 스킬이 반응하지 않는다 | 에이전트를 다시 시작했는지, 스킬 폴더 이름이 `ddobak-meetings`인지 확인합니다. 그래도 안 되면 "또박또박 회의 스킬로 …"처럼 스킬을 직접 언급해 보세요. |
| 권한이 없다는 오류(403) | 요청한 일에 필요한 스코프가 토큰에 없는 것입니다. "또박또박 토큰 정보 확인해줘"라고 시켜 켜진 스코프를 확인하고, 모자라면 토큰을 새로 발급하세요. |
| 인증 실패(401) | 토큰이 틀렸거나 만료되었거나 폐기된 경우입니다. 만료일과 상태를 확인하고 필요하면 재발급합니다. |
| 회의를 찾을 수 없다(404) | 회의 번호가 맞는지, 내 계정이 볼 수 있는 회의인지 확인합니다. |
| 잠시 뒤 다시 시도하라는 오류(429) | 짧은 시간에 요청이 너무 많았습니다. 안내된 시간만큼 기다린 뒤 다시 시도합니다. |

## 다른 AI 에이전트와 연동

Claude Code가 아닌 에이전트(Codex, Gemini CLI, 직접 만든 에이전트 등)도 쓸 수 있습니다. 스킬 zip 안의 `AGENT.md`를 에이전트에게 읽히면 됩니다. 이 문서에 회의 API의 사용법이 정리되어 있어, 별도의 도구 없이 HTTP 호출만으로 같은 일을 할 수 있습니다.

:::note
웹 브라우저 안에서 동작하는 Claude 앱(claude.ai)처럼 외부 인터넷에서 실행되는 서비스는 내 서버에 접근할 수 없는 경우가 많습니다. 이런 서비스에서 쓸 수 있는지는 서버가 인터넷에 공개되어 있는지에 따라 다릅니다.
:::

## 개발자를 위한 자세한 안내

엔드포인트 목록, 요청과 응답 예시, 오류 코드, 사용 제한 같은 개발자용 상세 설명은 [회의 API 가이드](../../ddobak-api-guide.html)에 따로 정리되어 있습니다.

## 보안 수칙

- 스코프는 최소로 켭니다. 조회만 하면 읽기 스코프만 줍니다.
- 토큰은 `.env.ddobak` 파일이나 환경변수로만 보관합니다. 코드, 문서, 대화 기록에 평문으로 남기지 마세요.
- 유출이 의심되면 바로 폐기합니다. 폐기한 순간부터 그 토큰의 모든 요청이 거부됩니다.
- 토큰은 내 권한을 넘지 못합니다. 협업자로 초대되지 않은 회의나 공유되지 않은 다른 프로젝트의 회의는 토큰으로도 볼 수 없습니다.
- 만료일을 너무 길게 잡지 마세요. 기본 90일은 대부분의 경우 충분합니다.
