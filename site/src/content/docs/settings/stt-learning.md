「STT 용어 학습」은 음성 인식이 자주 틀리는 용어를 또박또박이 스스로 배우게 하는 기능입니다. 이 탭은 **관리자 전용**입니다. 서버에 연결해 쓰는 경우 관리자 계정에만 보이고, 이 PC에서 혼자 쓰는 로컬 모드에서도 보입니다. 사이드바 아래쪽의 「설정」 단추를 누른 뒤 「STT 용어 학습」 탭을 고릅니다.

## 어떻게 동작하나요

AI 회의록을 사람이 고치면, 또박또박은 AI가 처음 만든 원본과 사람이 고친 최종본을 비교해 "잘못 받아 적은 표기 → 올바른 용어" 쌍을 찾아냅니다.

1. 회의록을 마지막으로 고친 뒤 정해진 시간(기본 30분)이 지나면 학습이 실행됩니다. 그 사이 다시 고치면 대기 시간이 처음부터 다시 시작됩니다.
2. AI가 원본과 최종본의 차이에서 오인식 후보를 고릅니다. 표현을 다듬거나 내용을 보충한 부분은 제외하고, 잘못 받아 적은 표기가 실제 전사에 있는 경우만 남깁니다.
3. 같은 용어가 회의 폴더 → 상위 폴더 → 프로젝트 → 전역 순으로 이미 등록되어 있으면 그 줄에 오인식 표기만 더합니다. 어디에도 없으면 회의에서 가장 가까운 폴더(폴더가 없으면 프로젝트)의 "STT 오인식(자동)" 도메인 파일에 새로 등록합니다.
4. 등록된 용어는 그 레벨 아래의 회의에서 다음 요약부터 교정 힌트로 쓰입니다. 같은 오인식이 다시 나와도 AI 회의록에는 올바른 용어로 정리됩니다.

탭 안의 「등록 흐름」 하위 탭에서 이 순서를 그림으로 볼 수 있습니다. 도메인 파일 자체는 [사이드바와 폴더](../../projects/sidebar-folders/)와 [프로젝트](../../projects/projects/)에서 연결합니다.

:::note
회의록을 고치지 않았거나 AI 원본과 차이가 없으면 아무것도 등록하지 않습니다. 후보를 고를 때는 회의를 만든 사람의 요약 LLM 설정을 따르며, 회의 1건당 한 번만 호출합니다.
:::

## 화면 구성

탭 위쪽에 여섯 개의 하위 탭이 있습니다.

| 하위 탭 | 하는 일 |
|---|---|
| 「레벨별 용어」 | 전역·프로젝트·폴더 레벨마다 등록된 용어를 보고, 다른 레벨로 옮기거나 지웁니다. |
| 「처리 내역」 | 회의별 학습 결과를 보고, 다시 분석하거나 되돌립니다. |
| 「설정」 | 자동 학습을 켜고 끄며, 실행 시점과 기준값을 정합니다. |
| 「오인식 기록」 | 잘못 받아 적은 표기를 모아 보고 확정·미정·제외로 정리합니다. |
| 「등록 흐름」 | 자동 등록이 어떤 순서로 이루어지는지 안내합니다. |
| 「전체 용어」 | 모든 레벨의 용어를 한 표에서 검색하고 레벨을 한꺼번에 바꿉니다. |

## 레벨별 용어

왼쪽은 레벨 트리입니다. 맨 위가 「전역(공용)」이고, 그 아래로 프로젝트와 폴더가 이어집니다. 레벨을 고르면 오른쪽에 그 레벨의 용어 표가 나옵니다.

1. 레벨 이름과 「용어 N」, 새로 등록된 것이 있으면 「새로 등록 N」 표시
2. 「상위로 올릴 후보」: 여러 하위 폴더에 같은 용어가 따로 등록되어 있으면 알려 줍니다. 자동으로 합치지는 않으니 직접 옮겨 합치세요.
3. 「하위 포함」: 켜면 아래 레벨의 용어까지 함께 보여 줍니다.
4. 용어 표: 「오인식 → 용어」, 「출처」, 「도메인 파일」, 「레벨 이동」 열. 출처는 「자동」, 「교정 입력」, 「사람 작성」, 「사람 작성+자동」 중 하나입니다.

### 용어를 다른 레벨로 옮기기

- 한 단계 위로: 줄 끝의 위쪽 화살표(「상위 레벨로」)를 누릅니다. 전역으로 올리거나 사람이 쓴 도메인 파일의 용어를 옮길 때는 확인 창이 먼저 뜹니다.
- 원하는 레벨로: 용어를 골라 「레벨 이동…」을 누르면 「레벨 이동」 창이 열립니다. 트리에서 대상 레벨을 고르면 「적용 회의 N건 → M건」처럼 영향을 받는 회의 수가 보이고, 대상의 "STT 오인식(자동)" 파일로 옮겨집니다(없으면 새로 만들어 연결합니다). 대상에 같은 용어가 있으면 오인식 표기를 합칩니다.
- 창 아래의 「원래 레벨에도 남겨 두기(복사)」를 켜면 옮기지 않고 복사합니다. 위 레벨로 올릴 때는 「하위 폴더에 있는 같은 용어도 함께 올려 합치기」도 고를 수 있습니다.
- 지우려면 용어를 골라 「삭제」를 누릅니다.

:::caution
전역으로 올린 용어는 모든 프로젝트의 회의 요약에 들어갑니다. 특정 프로젝트에서만 쓰는 용어는 그 프로젝트나 폴더에 두세요.
:::

## 처리 내역

회의마다 학습이 언제, 어떻게 처리됐는지 보여 줍니다.

- 아직 실행 전인 회의는 「대기 · N분 후」로 보입니다.
- 끝난 회의는 「등록 N · 제외 N」 또는 「변경 없음」, 실패한 회의는 「실패」와 사유가 보입니다. 실패한 회의는 「다시 실행」을 눌러 다시 돌릴 수 있습니다.
- 회의 이름을 누르면 상세가 열립니다. 「쌍」, 「판정」, 「근거」, 「등록 위치」 표에서 후보마다 「새 줄 등록」, 「기존 줄에 병합」, 「이미 등록됨」, 「제외(낮은 확신)」 같은 판정을 확인할 수 있습니다.
- 제외된 후보 중 등록할 만한 것은 줄 끝의 「등록」으로 직접 등록합니다.
- 「지금 다시 분석」은 대기 시간을 기다리지 않고 그 회의를 바로 다시 분석합니다.
- 「이 회의 등록 전부 되돌리기」는 그 회의에서 등록된 항목을 모두 되돌립니다. 등록 뒤에 내용이 바뀐 항목은 되돌리지 않고 「변경되어 건너뜀」으로 표시합니다.

## 오인식 기록

STT가 잘못 받아 적은 표기를 등록 여부와 상관없이 모아 둔 목록입니다. 위쪽의 「전체」, 「확정」, 「미정」, 「제외됨」으로 거르고, 「표기·용어 검색」 칸으로 찾습니다. 표에는 「오인식 표기」, 「올바른 용어」, 「상태」, 「나온 횟수」, 「회의」, 「등록 위치」, 「마지막」 열이 있습니다.

| 단추 | 결과 |
|---|---|
| 「확정」 | 올바른 용어로 등록합니다. |
| 「미정」 | 올바른 용어가 확실하지 않은 상태로 둡니다. 확신이 낮거나 다른 용어와 겹친 후보가 여기에 모입니다. |
| 「제외」 | 오인식이 아니라고 표시합니다. 이미 등록되어 있던 표기는 등록 위치에서 빠지고, 다음 학습에서도 다시 등록하지 않습니다. |

## 설정

| 항목 | 설명 |
|---|---|
| 「자동 추출·등록 사용」 | 끄면 AI 원본만 보관하고 학습은 하지 않습니다. |
| 「실행 시점 (마지막 사람 수정 후 대기 분)」 | 5~1440분. 회의록을 마지막으로 고친 뒤 이만큼 지나면 학습합니다. |
| 「최소 confidence」 | 0.0~1.0. AI가 판단한 확신이 이 값보다 낮은 후보는 등록하지 않습니다. |

값을 바꾼 뒤 「저장」을 누릅니다. 기본값은 켜짐, 30분, 0.6입니다. 서버 관리자가 기본값을 바꿨다면 다를 수 있습니다.

## 전체 용어

모든 레벨의 용어를 한 표에서 봅니다. 「용어·오인식 검색」, 프로젝트 필터, 출처 필터(「전체」, 「자동」, 「사람 작성」), 「중복만」, 「올릴 후보만」으로 좁힐 수 있습니다.

1. 「레벨 (바꾸려면 클릭)」 칸을 누르면 트리가 펼쳐져 위·아래 어느 레벨이든 고를 수 있습니다.
2. 고른 변경은 바로 반영되지 않고 「변경 예정」으로 모입니다. 같은 용어가 여러 레벨에 있으면 「중복」으로 표시되고, 공통 상위 레벨로 합치기를 제안합니다.
3. 아래쪽의 「변경 적용」으로 한 번에 반영하거나, 「모두 취소」로 되돌립니다.
