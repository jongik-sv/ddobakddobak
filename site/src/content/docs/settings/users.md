「사용자 관리」는 또박또박을 함께 쓰는 사람들의 계정을 만들고 고치고 지우는 **관리자 전용** 창입니다. 서버에 연결해 쓰는 경우 관리자 계정에만 보이고, 이 PC에서 혼자 쓰는 로컬 모드에서도 보입니다. 일반 사용자와 모바일 화면에서는 보이지 않습니다.

## 창 열기

1. 데스크톱 화면에서 사이드바 아래쪽의 「사용자 관리」 단추를 누릅니다. 「설정」 단추 바로 아래에 있습니다.
2. 「사용자 관리」 창이 열립니다. 창 오른쪽 위의 X 단추나 Esc 키로 닫습니다.

:::note
사이드바에 「사용자 관리」 단추가 없다면 관리자 계정으로 로그인한 상태인지 확인하세요. 계정의 역할은 이 창에서 다른 관리자가 바꿔 줄 수 있습니다.
:::

## 화면 구성

창 안에는 「사용자 관리」 카드가 하나 있고, 설명은 「시스템 사용자를 추가, 수정, 삭제합니다.」입니다.

1. 오른쪽 위의 「사용자 추가」 단추
2. 사용자 목록 표: 「이름」, 「이메일」, 「역할」, 「생성일」 열과 마지막의 작업 단추 열
3. 목록이 비었을 때의 안내 「등록된 사용자가 없습니다.」

내 계정 줄에는 이름 옆에 「(나)」가 붙습니다. 이 PC 전용 관리자 계정(이메일이 `@local`로 끝나는 계정)은 시스템 계정이라 역할 변경, 수정, 비밀번호 초기화, 삭제를 할 수 없습니다.

## 역할

사용자마다 세 가지 역할 중 하나가 있습니다. 목록의 「역할」 열에 이름표로 표시됩니다.

| 역할 | 표시 | 설명 |
|---|---|---|
| 관리자 | 보라색 | 사용자 관리, 서버 전체 설정 같은 관리 기능을 쓸 수 있습니다. |
| 매니저 | 파란색 | 프로젝트를 만들 수 있고, 자기가 프로젝트 관리자로 있는 팀 프로젝트의 멤버·초대 링크를 관리할 수 있습니다. 사용자 관리와 서버 전체 설정은 쓸 수 없습니다. |
| 멤버 | 회색 | 일반 사용자입니다. |

프로젝트 안에서의 멤버 권한(소유자, 협업자 등)은 이 역할과 별개입니다. 프로젝트 단위의 권한은 [프로젝트](../../projects/projects/)와 [협업자 권한](../../share/collaborators/)을 보세요.

## 사용자 추가

1. 「사용자 추가」를 누릅니다. 「사용자 추가」 창이 열립니다.
2. 「이메일」을 입력합니다(예: `user@example.com`). 로그인할 때 쓰는 계정 이름입니다.
3. 「이름」을 입력합니다.
4. 「비밀번호」를 입력합니다. 6자 이상이어야 합니다.
5. 「역할」을 고릅니다. 선택지는 Member, Manager, Admin이고 기본값은 Member입니다.
6. 「생성」을 누릅니다. 목록 맨 위에 새 사용자가 추가됩니다. 그만두려면 「취소」를 누릅니다.

실패하면 서버가 알려 주는 이유(예: 이미 쓰는 이메일)나 「사용자 생성에 실패했습니다.」가 창 안에 나타납니다.

:::tip
관리자가 정해 준 비밀번호는 임시로만 쓰게 하세요. 새 사용자가 처음 로그인한 뒤 [개인설정](../personal/)의 「비밀번호 변경」에서 스스로 바꾸도록 안내하면 좋습니다.
:::

## 역할 바꾸기

역할 이름표 자체가 단추입니다. 누를 때마다 관리자, 매니저, 멤버 순서로 돌아가며 바뀝니다. 이름표에 마우스를 올리면 「클릭하여 매니저로 변경」처럼 다음 역할이 안내됩니다. 바뀌는 동안은 이름표가 「...」로 보입니다.

| 상황 | 동작 |
|---|---|
| 내 계정 | 바꿀 수 없습니다. 이름표에 「자신의 역할은 변경할 수 없습니다」가 안내됩니다. |
| 이 PC 전용 관리자 계정 | 바꿀 수 없습니다. 「관리자 계정의 역할은 변경할 수 없습니다」가 안내됩니다. |

실패하면 목록 위에 「역할 변경에 실패했습니다.」가 나타납니다.

:::caution
이름표를 한 번 누르면 곧바로 역할이 바뀌고 확인 창은 없습니다. 멤버에서 한 번 더 누르면 관리자가 되므로 실수로 누르지 않도록 주의하세요.
:::

## 이름·이메일 수정

1. 목록에서 해당 사용자 줄 오른쪽 끝의 연필 단추(「이름/이메일 수정」)를 누릅니다.
2. 「사용자 수정」 창에서 「이름」과 「이메일」을 고칩니다.
3. 「저장」을 누릅니다. 그만두려면 「취소」를 누릅니다.

실패하면 서버가 알려 주는 이유나 「수정에 실패했습니다.」가 나타납니다.

## 비밀번호 초기화

사용자가 비밀번호를 잊었을 때 관리자가 임시 비밀번호를 발급합니다.

1. 해당 사용자 줄의 열쇠 모양 단추(「비밀번호 초기화」)를 누릅니다.
2. 「비밀번호 초기화」 창에서 대상 사용자를 확인합니다. 안내는 「…의 비밀번호를 임시 비밀번호로 재설정합니다. 해당 사용자의 모든 세션이 만료됩니다.」입니다.
3. 「초기화」를 누릅니다.
4. 임시 비밀번호가 화면에 나타납니다. 「복사」 단추로 복사해 그 사용자에게 안전한 방법으로 전달합니다.
5. 「닫기」를 누릅니다.

:::caution
임시 비밀번호는 이 창을 닫으면 다시 볼 수 없습니다. 「이 창을 닫으면 다시 볼 수 없으니 사용자에게 전달하세요.」라고 안내되며, 놓쳤다면 초기화를 다시 해야 합니다. 초기화하는 순간 그 사용자는 모든 기기에서 로그아웃됩니다.
:::

## 사용자 삭제

1. 해당 사용자 줄의 휴지통 단추(「사용자 삭제」)를 누릅니다. 내 계정 줄에는 이 단추가 없습니다.
2. 「사용자 삭제」 확인 창이 나타납니다. 안내는 「이 사용자를 삭제하시겠습니까? 이 작업은 되돌릴 수 없습니다.」입니다.
3. 「삭제」를 누릅니다. 취소하려면 「취소」를 누릅니다.

삭제된 사용자가 갖고 있던 자료는 다음과 같이 정리됩니다.

- 그 사용자의 회의: 각 프로젝트의 관리자에게 넘어갑니다.
- 그 사용자의 프로젝트: 시스템 관리자 계정으로 넘어갑니다.
- 그 사용자의 개인 프로젝트: 휴지통으로 이동합니다. 휴지통에서 되살리는 방법은 [휴지통](../../trash/trash/)을 보세요.

삭제에 실패하면 서버가 알려 주는 이유나 「사용자 삭제에 실패했습니다.」가 나타납니다.

:::caution
계정 삭제는 되돌릴 수 없습니다. 삭제 전에 그 사용자의 회의가 누구에게 넘어가는지 위 내용을 꼭 확인하세요.
:::
