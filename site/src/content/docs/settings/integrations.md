「연동」 탭에서는 또박또박을 다른 서비스와 이어 줍니다. 현재 이 탭에는 회의록을 D'Flow(회의록 아카이브)로 전송하는 「D'Flow 연동」 카드가 있습니다. 이 탭은 **관리자 전용**입니다. 서버에 연결해 쓰는 경우 관리자 계정에만 보이고, 이 PC에서 혼자 쓰는 로컬 모드에서는 모두에게 보입니다.

:::note
외부 AI 도구가 내 회의를 읽도록 하는 「API 토큰」은 이 탭이 아니라 [개인설정](../personal/) 탭에 있습니다. 설명은 [회의 API](../meeting-api/)를 보세요.
:::

## D'Flow 연동 카드

카드 설명은 「회의록을 D'Flow(회의록 아카이브)로 전송하는 연동 설정입니다.」입니다. 이 설정을 마쳐야 회의록 화면에서 D'Flow로 전송할 수 있습니다. 전송하는 방법과 전송 후 상태는 [D'Flow 전송](../../share/dflow/)에서 설명합니다.

### 화면 구성

1. 「D'Flow 연동 사용」 스위치: 「켜면 회의록 화면에서 D'Flow로 전송할 수 있습니다.」
2. 「서버 주소」 입력 칸
3. 「API 시크릿」 입력 칸
4. 안내 문구
5. 「연결 테스트」와 「저장」 단추
6. 결과 메시지 줄

### 설정하는 순서

1. 설정 창에서 「연동」 탭을 엽니다.
2. 「서버 주소」에 D'Flow 서버의 주소를 입력합니다. 입력 칸 안의 예시는 `https://dflow.example.com`처럼 `https://`로 시작하는 형태입니다. 실제 주소는 D'Flow 관리자에게 받으세요.
3. 「API 시크릿」에 D'Flow에서 발급받은 비밀 값을 입력합니다. 눈 모양 단추로 입력한 값을 보이거나 숨길 수 있습니다.
4. 「D'Flow 연동 사용」 스위치를 켭니다.
5. 「연결 테스트」를 눌러 확인합니다.
6. 「저장」을 누릅니다. 「D'Flow 설정이 저장되었습니다.」가 나타나면 끝입니다.

저장하지 않고 탭을 옮기면 입력한 내용이 사라질 수 있으니, 입력을 마치면 먼저 「저장」을 누르세요.

:::tip
이미 시크릿이 저장되어 있으면 입력 칸에 가려진 값이 보이고, 그 아래에 「현재: …」가 표시됩니다. 시크릿을 바꾸지 않을 때는 칸을 비워 둔 채 저장하면 기존 값이 유지됩니다. 시크릿이 바뀐 경우에만 새 값을 입력하세요.
:::

### 연결 테스트 결과

「연결 테스트」는 입력한 내용으로 D'Flow 서버에 실제로 연결해 봅니다. 테스트하는 동안 단추는 「테스트 중...」으로 바뀝니다.

| 결과 | 뜻과 대처 |
|---|---|
| 「연결 성공」 | 연결되었습니다. 아래에 D'Flow에서 읽어 온 「구분: …」과 「프로젝트: …」 목록이 함께 나타납니다. |
| 「연결 실패: 시크릿 불일치 또는 미개통/URL 오류」 | 시크릿이 틀렸거나, 아직 D'Flow 쪽에서 연동이 열리지 않았거나, 서버 주소가 잘못된 것입니다. 세 가지를 차례로 확인하세요. |
| 「연결 실패: D'Flow 서버에 연결할 수 없습니다.」 | 서버에 닿지 않습니다. 주소의 오타나 네트워크 연결을 확인하세요. |
| 「연결 실패: 연결 테스트에 실패했습니다.」 | 그 밖의 이유로 실패했습니다. 잠시 뒤 다시 시도하세요. |

:::caution
「연결 테스트」는 현재 서버에 **저장된** 설정으로 연결을 확인합니다. 주소나 시크릿을 새로 입력했다면 먼저 「저장」을 누른 다음에 테스트하세요.
:::

### 구분과 제목 규칙

카드 아래의 안내 문구는 다음과 같습니다. 「최상위 폴더명이 D'Flow 구분과 일치하면 자동 선택됩니다. 전송 제목은 <하위폴더명>-<원제목>으로 자동 조립됩니다.」

- 회의가 들어 있는 최상위 폴더의 이름이 D'Flow의 구분 이름과 같으면, 전송할 때 그 구분이 자동으로 골라집니다.
- 전송되는 제목은 하위 폴더 이름과 원래 제목을 붙여 「하위폴더명-원제목」으로 만들어집니다.

폴더를 만들고 정리하는 방법은 [사이드바와 폴더](../../projects/sidebar-folders/)를 보세요.

### 저장·불러오기 오류

| 메시지 | 뜻 |
|---|---|
| 「설정을 불러오지 못했습니다.」 | 현재 설정을 읽지 못했습니다. 탭을 다시 열어 보세요. |
| 「D'Flow 설정 저장에 실패했습니다.」 | 저장에 실패했습니다. 입력값과 네트워크를 확인하고 다시 시도하세요. |

## 일반 사용자에게는

이 탭이 보이지 않는 일반 사용자는 D'Flow 연동을 직접 설정할 수 없습니다. 관리자가 연동을 켜 두면 회의록 화면에서 전송 기능을 쓸 수 있습니다. 전송이 안 된다면 관리자에게 이 탭의 「D'Flow 연동 사용」이 켜져 있는지 확인해 달라고 요청하세요.
