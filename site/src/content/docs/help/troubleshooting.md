증상별로 확인할 것을 정리했습니다. 화면에 나온 안내 문구를 그대로 찾아보세요. 이 페이지로 해결되지 않으면 마지막의 「문의할 때 알려 주세요」를 참고합니다.

## 연결과 첫 실행

### 「서버에 연결할 수 없습니다. URL을 확인해주세요.」

서버 연결 방식에서 「연결 확인」을 눌렀을 때 나오는 메시지입니다. 순서대로 점검하세요.

1. 주소를 다시 확인합니다. 마지막에 불필요한 글자가 붙지 않았는지, 포트 번호가 맞는지 봅니다.
2. 내 기기가 서버와 같은 네트워크(사내 Wi-Fi 등)에 있는지 확인합니다. 외부 네트워크에서는 접속이 막힌 서버일 수 있습니다. VPN이 필요한 서버라면 VPN을 켭니다.
3. 웹 브라우저로 같은 주소를 열어 보고 로그인 화면이 열리는지 확인합니다.
4. 열리지 않으면 서버가 꺼져 있거나 점검 중일 수 있으니 서버 관리자에게 문의하세요.

| 메시지 | 의미 |
|---|---|
| 서버 응답 시간이 초과되었습니다 (5초) | 서버가 응답하지 않습니다. 잠시 뒤 다시 시도하거나 관리자에게 문의하세요. |
| 서버 응답 오류 (HTTP …) | 서버에는 닿았지만 정상 상태가 아닙니다. 관리자에게 알려 주세요. |

→ [첫 실행](../../start/first-run/)

### 「같은 Wi-Fi에서 서버를 찾지 못했어요」

서버가 다른 네트워크에 있거나, 네트워크 설정이 서버 검색을 막고 있습니다. 「서버 URL」에 주소를 직접 입력하고 「연결 확인」을 누르세요.

### 앱을 켤 때마다 실행 방식 선택 화면이 나옵니다

서버 연결 방식으로 정했는데 서버 주소가 비어 있는 상태입니다. 주소를 입력하고 「연결 확인」으로 성공을 확인한 뒤 「시작하기」를 누르세요.

### 로컬 실행에서 「필수 도구가 설치되지 않았습니다」

로컬 실행에는 Ruby, uv(Python), ffmpeg 세 가지 도구가 필요합니다. 「자동 설치」를 누르면 알아서 설치합니다. 직접 설치했다면 「다시 확인」을 누르세요. 자동 설치가 실패하면 화면에 적힌 명령으로 터미널에서 설치한 뒤 「다시 확인」을 누릅니다.

### 초기 셋업에서 「오류가 발생했습니다」

「다시 시도」를 한 번 더 눌러 보세요. 그래도 같은 오류가 나오면 오류 내용을 복사해 두고 서버 연결 방식으로 전환해 사용하거나 관리자에게 문의합니다. 인터넷 연결이 끊겨 구성요소를 내려받지 못했을 수도 있습니다.

## 로그인

### 「이메일 또는 비밀번호가 올바르지 않습니다.」

1. 이메일 철자와 비밀번호의 대소문자, 한/영 상태를 확인합니다. 비밀번호 입력칸의 눈 아이콘으로 입력 내용을 볼 수 있습니다.
2. 접속 중인 서버가 맞는지 로그인 화면 위쪽의 「서버: …」를 확인합니다. 다른 서버라면 「서버 주소 변경」으로 바꿉니다.
3. 비밀번호가 기억나지 않으면 서버 관리자에게 비밀번호 초기화를 요청하세요. 직접 초기화하는 기능은 없습니다.

### 로그인 화면이 자꾸 다시 나옵니다

다른 기기에서 비밀번호를 바꾸면 이 기기의 로그인은 풀립니다. 새 비밀번호로 다시 로그인하세요. 관리자가 비밀번호를 초기화한 경우에도 같습니다.

### 초대 링크가 「만료되었거나 유효하지 않은 초대 링크입니다.」라고 합니다

링크의 사용 기간이 지났거나 잘못 복사된 링크입니다. 초대한 사람에게 새 링크를 요청하세요. → [프로젝트 관리](../../projects/projects/)

## 녹음

### 마이크가 동작하지 않습니다

1. 운영체제의 마이크 권한을 확인합니다.
   - macOS: 「시스템 설정」 → 「개인정보 보호 및 보안」 → 「마이크」에서 또박또박을 켭니다.
   - Windows: 「설정」 → 「개인 정보 및 보안」 → 「마이크」에서 마이크 접근과 데스크톱 앱 접근을 켭니다.
   - Android: 「설정」 → 「앱」 → 또박또박 → 「권한」 → 「마이크」를 허용합니다.
2. 웹 브라우저라면 주소창 왼쪽의 자물쇠 아이콘에서 마이크를 「허용」으로 바꾸고 페이지를 새로 엽니다. 주소가 보안 연결(`https://`)이 아니면 브라우저가 마이크를 막는 경우가 있으니 서버 관리자에게 확인하세요.
3. 라이브 녹음 화면에 「마이크 선택」이 있으면 올바른 마이크가 선택돼 있는지 확인합니다.
4. 다른 프로그램(화상회의 앱 등)이 마이크를 독점하고 있지 않은지 확인합니다.

→ [라이브 녹음](../../recording/live/)

### 소리가 작거나 전사가 거의 안 됩니다

- 마이크를 말하는 사람 가까이에 둡니다. 소음이 큰 곳에서는 정확도가 크게 떨어집니다.
- 화상회의의 상대방 소리까지 기록하려면 마이크가 아니라 시스템 오디오 캡처를 사용합니다. → [시스템 오디오 캡처](../../recording/system-audio/)
- 인식 언어가 맞게 지정돼 있는지 「개인설정」의 「회의 언어」에서 확인합니다. 인식 모델 자체는 관리자가 정하므로 결과가 계속 나쁘면 관리자에게 알리세요. → [개인설정](../../settings/personal/), [음성·인식](../../settings/voice/)

### 회의 시작 버튼이 안 보이거나 안 눌립니다

회의를 시작하는 버튼은 회의 소유자와 관리자에게만 보입니다. 다음 안내가 나오는 경우도 있습니다.

| 안내 | 원인과 해결 |
|---|---|
| 이 회의에 접근 권한이 없습니다. 공유 코드로 참여하세요. | 내가 멤버가 아닌 회의입니다. 화면 문구에는 「공유 코드」라고 나오지만 코드를 입력하는 기능은 없습니다. 소유자에게 협업자 권한을 요청하거나 프로젝트 멤버로 초대받으세요. → [회의 협업자 권한](../../share/collaborators/) |
| 잠긴 회의입니다 — 잠금을 해제한 뒤 다시 시도하세요. | 회의가 잠겨(읽기 전용) 있습니다. 회의 상단의 「회의 잠금 해제」로 풀어야 수정할 수 있습니다. |
| 이 회의는 기밀 절단되어 더 이상 녹음/전사를 추가할 수 없습니다. | 기밀 구간 절단이 적용된 회의입니다. 새 회의를 만드세요. → [전사 편집](../../minutes/transcript/) |
| 녹음/전사 중인 회의에는 오디오를 추가할 수 없습니다. | 녹음이나 전사가 끝난 뒤에 오디오를 추가하세요. |

### 서버가 끊겨도 녹음이 계속됩니다 (Android)

Android에서 서버에 연결할 수 없게 되면 「서버에 연결할 수 없어 온디바이스 STT로 전사합니다 — 전사는 이 기기에만 저장됩니다」라고 알립니다. 기기 안에서 계속 전사하며, 이 경우 전사는 그 기기에만 저장됩니다. → [오프라인 녹음](../../recording/offline/)

### 녹음이 끝났는데 오디오가 보이지 않습니다

녹음 종료 직후 오디오를 서버로 올리는 데 시간이 걸릴 수 있습니다. 잠시 기다린 뒤 회의를 다시 열어 보세요. 올리기에 실패한 오디오는 기기에 보존되었다가 다음에 앱을 켤 때 다시 올립니다. 그동안 앱을 지우지 마세요.

## 파일 업로드

### 「업로드 실패」, 「업로드에 실패했습니다.」

1. 서버 연결 상태를 확인합니다.
2. 파일이 손상되지 않았는지 다른 재생기로 재생해 봅니다.
3. 실패한 파일에는 「재시도」 버튼이 나옵니다. 눌러서 해당 파일만 다시 올립니다.
4. 용량이 아주 큰 파일은 나누어 올리거나, 여러 파일이면 하나씩 올려 봅니다.

→ [오디오 파일 업로드](../../recording/upload/)

## 회의록

### AI 회의록이 만들어지지 않습니다

- 회의 중에는 일정 간격마다 회의록이 갱신됩니다. 「요약 실패 — 다음 주기에 재시도합니다」가 보이면 다음 갱신 때 자동으로 다시 시도합니다.
- 계속 실패하면 LLM 설정을 확인합니다. 서버의 요약용 LLM이 「선택 안함」으로 되어 있으면 요약이 만들어지지 않으니, 관리자에게 확인하세요. 개인 LLM을 지정했다면 그 설정이 우선 적용됩니다. → [LLM](../../settings/llm/)
- 내 컴퓨터에서 도는 로컬 LLM을 쓰는 경우 「로컬 서버에 연결할 수 없습니다. 실행 중인지 확인하세요.」가 보이면 해당 프로그램이 켜져 있는지 확인합니다.
- 회의가 끝난 뒤라면 회의 상세 화면에서 회의록을 다시 만들 수 있습니다. → [AI 회의록](../../minutes/ai-summary/)

### 회의록 내용이 이상하거나 이름이 틀립니다

사람 이름, 제품명처럼 자주 틀리는 낱말은 오타 사전에 등록해 두면 이후 전사에 반영됩니다. 이미 만들어진 전사는 직접 고칠 수 있습니다. → [전사 편집](../../minutes/transcript/)

### 화자가 잘못 나뉘었습니다

화자 이름을 바꾸거나, 발언 단위로 화자를 바꾸고 화자분리를 다시 실행할 수 있습니다. → [화자 정리](../../minutes/speakers/)

### 「다른 곳에서 이 발언이 수정되었습니다. 다시 시도하세요.」

같은 발언을 다른 사람이나 다른 기기에서 먼저 고친 경우입니다. 화면을 새로 고쳐 최신 내용을 본 뒤 다시 수정하세요.

## 공유와 내보내기

### 「내보내기에 실패했습니다. 다시 시도해 주세요.」

네트워크 상태를 확인하고 다시 시도합니다. 회의록이 아직 만들어지지 않은 회의는 「내보낼 요약이 없습니다」가 나옵니다. 회의록을 먼저 만든 뒤 내보내세요. → [회의록 내보내기](../../share/export/)

### D'Flow 전송이 안 됩니다

전송 대상 서버에 연결되지 않을 때 「Flow 서버에 연결할 수 없습니다.」가 나옵니다. 연동 설정의 연결 정보와 로그인 상태를 확인하세요. → [D'Flow 전송](../../share/dflow/), [연동](../../settings/integrations/)

### 다른 기기에서 실시간으로 볼 수 없습니다

다른 기기에서 해당 회의가 실제로 녹음 중인지 확인하세요. 녹음 중인 회의를 열 때만 읽기 전용 뷰어로 들어갑니다. 내가 그 회의의 멤버나 협업자인지도 확인하세요. → [다른 기기에서 실시간으로 보기](../../share/live-share/)

## 화면과 동작

### 화면이 하얗게 나오거나 멈춥니다

1. 앱을 완전히 종료한 뒤 다시 실행합니다.
2. 웹 브라우저라면 페이지를 새로 고칩니다. 단, 녹음 중에는 새로 고치지 마세요.
3. 그래도 반복되면 서버 관리자에게 알리세요.

### 창을 닫았는데 앱이 계속 켜져 있습니다

데스크톱 앱에서 창을 닫을 때 「또박또박을 어떻게 할까요?」 창이 뜨고, 백그라운드 유지를 고르면 예약 회의가 시각에 맞춰 자동으로 시작됩니다. 완전히 끝내려면 이 창에서 종료를 선택하세요. → [트레이·백그라운드](../../schedule/background/)

### 글자가 너무 작거나 큽니다

AI 회의록 본문의 글자 크기는 회의록 위쪽의 「A−」「A+」 버튼(「회의록 글자 크기」)으로 조절합니다. 가운데 숫자를 누르면 기본 크기로 돌아갑니다. → [AI 회의록](../../minutes/ai-summary/)

## 문의할 때 알려 주세요

문제가 해결되지 않으면 서버 관리자에게 다음 내용을 함께 전달하면 원인을 찾기 빠릅니다.

1. 사용한 환경: 데스크톱 앱(macOS/Windows), Android 앱, 웹 브라우저 중 어느 것인지
2. 화면에 나온 안내 문구(스크린샷이 가장 좋습니다)
3. 어떤 화면에서 무엇을 하다가 생겼는지, 같은 문제가 반복되는지
4. 문제가 생긴 회의의 제목과 시각

:::caution
스크린샷이나 문의 내용에 비밀번호, 개인 정보, 기밀 회의 내용이 들어 있지 않은지 보내기 전에 확인하세요.
:::
