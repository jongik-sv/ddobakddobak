또박또박은 마우스만으로 모든 기능을 쓸 수 있고, 자주 쓰는 동작에는 단축키가 있습니다. 아래 표에서 `Ctrl`은 Windows와 웹 브라우저의 키이고, macOS에서는 `Cmd`(⌘)를 대신 누릅니다.

## 어디서나 쓰는 단축키

| 단축키 | 동작 |
|---|---|
| `F1` | 현재 화면의 매뉴얼 열기 |
| `Esc` | 열려 있는 창(설정, 대화상자, 전체보기 등)을 닫기 |

### F1: 현재 화면의 매뉴얼 열기

`F1`을 누르면 지금 보고 있는 화면에 맞는 매뉴얼 페이지가 웹 브라우저로 열립니다. 예를 들어 라이브 녹음 화면에서는 라이브 녹음 페이지가, 설정의 「LLM」 탭에서는 LLM 설정 페이지가 열립니다. 로그인 화면과 첫 실행 화면에서도 쓸 수 있습니다.

사이드바와 모바일 내비게이션의 「매뉴얼」 버튼(물음표 아이콘, 마우스를 올리면 「매뉴얼 (F1)」)을 눌러도 같습니다. 휴대폰처럼 키보드가 없는 환경에서는 이 버튼을 사용하세요.

:::note
매뉴얼 사이트에 접속할 수 있는 인터넷 연결이 필요합니다. 연결되지 않는 환경에서는 열리지 않을 수 있습니다.
:::

## 회의 화면

| 단축키 | 화면 | 동작 |
|---|---|---|
| `Ctrl` + `F` | 회의 상세 | 전사와 요약에서 글자 찾기 바를 엽니다. 이미 열려 있으면 입력칸으로 커서를 옮기고 글자를 선택합니다. |
| `Ctrl` + `B` | 라이브 녹음 화면 | 현재 시점에 북마크를 추가하는 창을 엽니다. 녹음 중일 때만 동작합니다. |

데스크톱 앱에는 브라우저의 기본 찾기 기능이 없어서 `Ctrl` + `F`를 또박또박이 직접 처리합니다. 찾기 버튼에 마우스를 올리면 「페이지 내 검색 (Ctrl+F)」, 북마크 버튼에는 「북마크 추가 (Ctrl+B)」라고 나옵니다.

### 찾기 바 안에서

찾기 바에는 「전사·요약 검색」 입력칸이 있습니다. 일치하는 위치는 「3/12」처럼 몇 번째인지 표시됩니다.

| 키 | 동작 |
|---|---|
| `Enter` | 다음 일치 위치로 이동 |
| `Shift` + `Enter` | 이전 일치 위치로 이동 |
| `Esc` | 찾기 바 닫기 |

한글을 입력하는 도중에 누르는 `Enter`(글자를 확정하는 용도)는 이동으로 처리되지 않으니 안심하고 쓰세요.

## 입력칸에서 쓰는 Enter와 Esc

대부분의 편집 입력칸은 `Enter`로 저장하고 `Esc`로 취소합니다.

| 위치 | Enter | Esc |
|---|---|---|
| 회의 제목 수정 | 저장 | 취소 |
| 화자 이름 바꾸기 | 저장 | 취소 |
| 전사 문장 수정 (수정 중) | 저장 (`Shift` + `Enter`는 줄바꿈) | 수정 취소 |
| 전사 문장 (수정 전, 선택된 상태) | 수정 시작 | — |
| 북마크 라벨 입력 | 저장 | 창 닫기 |
| 북마크 목록의 이름 수정 | 저장 | 취소 |
| 회의 유형 템플릿 이름 수정 | 저장 | 취소 |
| 태그 이름 입력 | 태그 추가 | — |
| 회의 AI 챗 질문 입력 | 질문 전송 | — |
| 다이어그램 편집 | `Ctrl` + `Enter`로 적용 | — |

:::tip
한글 입력 중 `Enter`로 글자를 확정할 때 질문이 의도치 않게 전송되지 않도록 챗 입력은 조합 중의 `Enter`를 무시합니다. 질문을 보낼 때는 글자를 확정한 뒤 `Enter`를 한 번 더 누르면 됩니다.
:::

## 창을 닫는 Esc

다음 창은 `Esc`로 닫을 수 있습니다.

- 「설정」 창과 그 안의 「사용자 관리」, LLM 프로필 창
- 대화상자(새 프로젝트, 회의 편집 등 대부분의 창)
- AI 회의록 전체보기 창(데스크톱)
- 앱 종료 확인 창
- 모바일의 하단 시트와 사이드바

## 앱 동작에 관한 참고

- 데스크톱 앱에서는 입력칸 밖에서 `Backspace`를 눌러도 이전 화면으로 돌아가지 않습니다. 실수로 화면이 바뀌어 녹음 화면을 잃는 일을 막기 위한 동작입니다.
- 앱에서는 `Ctrl` + `R`(새로고침)이 동작하지 않습니다. 녹음 중 실수로 새로고침해서 상태가 사라지는 일을 막기 위해서입니다. 웹 브라우저에서 접속한 경우에는 브라우저의 새로고침이 동작하므로, 녹음 중에는 누르지 않도록 주의하세요.

:::caution
웹 브라우저로 접속해 녹음 중일 때 브라우저의 `Ctrl` + `W`(탭 닫기)나 새로고침을 누르면 녹음이 끊길 수 있습니다. 중요한 회의에서는 데스크톱 앱 사용을 권장합니다.
:::

단축키를 쓸 수 없는 상황이라면 화면의 버튼으로 같은 일을 할 수 있습니다. 화면별 사용법은 [라이브 녹음](../../recording/live/), [회의 상세 화면](../../minutes/meeting-detail/)에서 확인하세요.
