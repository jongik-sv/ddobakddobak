[회의 예약](../schedule/)은 예약 시각에 앱이 살아 있어야 동작합니다. 데스크톱 앱은 창을 닫아도 완전히 끝나지 않고 백그라운드에 남을 수 있어서, 화면에 창이 없어도 예약 회의를 받을 수 있습니다. 이 쪽에서는 창 닫기 동작, 트레이 아이콘, 로그인 시 자동 시작을 설명합니다.

:::note
이 내용은 내 컴퓨터만 쓰는 로컬 모드의 데스크톱 앱(macOS, Windows)에 해당합니다. 웹 브라우저와 Android 앱에는 이 기능이 없습니다. 웹에서는 또박또박 탭이 열려 있어야 예약이 동작합니다.
:::

## 창을 닫을 때

창의 닫기 단추(빨간 X 등)를 누르면 앱이 바로 끝나는 대신 「또박또박을 어떻게 할까요?」 창이 뜹니다.

![창 닫기 확인](../../../assets/screens/close-prompt.png)

안내 문구는 「백그라운드로 두면 예약 회의가 시각에 맞춰 자동 시작됩니다.」입니다. 단추는 세 개입니다.

| 단추 | 하는 일 |
|---|---|
| 백그라운드 유지 | 창만 숨기고 앱은 계속 실행합니다. 예약 회의를 받을 수 있습니다. |
| 완전 종료 | 앱을 완전히 끝냅니다. 예약 회의는 시작되지 않습니다. |
| 취소 | 아무것도 하지 않고 창을 닫지 않습니다. 바깥 영역을 누르거나 Esc 키를 눌러도 같습니다. |

창 아래쪽의 「다음부터 묻지 않기」를 체크하고 「백그라운드 유지」나 「완전 종료」를 누르면 그 선택이 기억되어 다음부터는 묻지 않고 바로 실행합니다. 이 선택은 앱 안에 저장되며, 되돌리는 설정 항목은 따로 없습니다. 앱 데이터를 지우면 다시 묻습니다.

:::caution
녹음 중에 「완전 종료」를 누르면 녹음이 중단됩니다. 진행 중인 회의가 있다면 먼저 회의를 끝내고 닫으세요.
:::

:::tip
macOS에서 Cmd+Q를 누르면 이 창을 거치지 않고 앱이 바로 종료됩니다. 백그라운드에 남기려면 빨간 닫기 단추를 쓰세요.
:::

## 트레이(메뉴 막대) 아이콘

앱이 실행 중이면 화면 막대에 또박또박 아이콘이 있습니다. macOS에서는 화면 위쪽의 메뉴 막대, Windows에서는 작업 표시줄 오른쪽의 시스템 트레이에 나타납니다. 아이콘에 마우스를 올리면 「또박또박」이라고 표시됩니다.

| 조작 | 결과 |
|---|---|
| 왼쪽 클릭 | 창이 숨겨져 있으면 보여 주고 앞으로 가져옵니다. 이미 보이면 숨깁니다. |
| 오른쪽 클릭(메뉴) | 「열기」와 「완전 종료」가 나옵니다. |

- 「열기」: 창을 보여 주고 앞으로 가져옵니다.
- 「완전 종료」: 앱을 완전히 끝냅니다. 「창 닫기」의 「완전 종료」와 같습니다.

백그라운드에 둔 앱을 다시 보려면 아이콘을 누르면 됩니다. 아이콘 메뉴는 오른쪽 클릭(macOS에서는 Control 클릭도 가능)으로 엽니다.

## 예약 시각이 되면 백그라운드에서는

앱이 백그라운드에 있어도 예약 시각이 가까워지면 다음 일이 일어납니다.

1. 예약 시각 1분 전부터 음성 인식 모델을 미리 준비해 시작을 빠르게 합니다.
2. macOS에서는 예약 시각 2분 전부터 컴퓨터가 잠들지 않게 붙들어 둡니다. 녹음 중에도 같습니다.
3. 시각이 되면 숨겨진 창을 자동으로 앞으로 가져옵니다.
4. 시작 방식이 「자동」이면 곧바로 녹음을 시작하고 「녹음 중: 예약 회의」 알림을 보냅니다. 「수동」이면 시작 1분 전에 「예약된 회의를 시작할까요?」라고 묻습니다. 알림 권한이 꺼져 있으면 허용 여부를 한 번 묻습니다.

시작 방식의 차이는 [회의 예약](../schedule/)을 보세요.

:::caution
컴퓨터가 이미 잠자기(절전) 상태에 들어가 있으면 예약 시각에 앱이 깨어나지 못할 수 있습니다. 중요한 예약이 있는 시간대에는 컴퓨터를 깨어 있게 두거나, 운영체제의 절전 설정을 조정하세요. 시각을 놓친 예약은 [대시보드](../../meetings/dashboard/)의 「놓친 예약 회의」에서 「지금 시작」으로 수습할 수 있습니다.
:::

## 로그인 시 자동 시작

컴퓨터를 켜고 로그인할 때마다 또박또박이 자동으로 실행되게 할 수 있습니다. 백그라운드에서 대기하다가 예약 회의를 받으므로, 매번 앱을 직접 열지 않아도 됩니다.

1. 사이드바의 「설정」을 엽니다.
2. 「회의록 설정」 탭을 엽니다.
3. 맨 위 「앱 자동시작」 영역에서 「로그인 시 자동 시작」 스위치를 켭니다.

이 영역의 안내 문구는 「로그인 시 또박또박을 자동으로 시작합니다.」이고, 스위치 아래에는 「예약 회의를 백그라운드에서 자동 시작하려면 켜세요 (기본 꺼짐)」라고 적혀 있습니다. 기본값은 꺼짐입니다. 끄려면 같은 스위치를 다시 누릅니다. 「앱 자동시작」 영역은 로컬 모드의 데스크톱 앱에서만 나타납니다.

설정 화면에 대한 자세한 내용은 [회의록 설정](../../settings/meeting/)을 보세요.

## 추천 설정

예약 회의를 안정적으로 쓰려면 다음처럼 해 두세요.

1. 「로그인 시 자동 시작」을 켭니다.
2. 창을 닫을 때 「백그라운드 유지」를 고르고 「다음부터 묻지 않기」를 체크합니다.
3. 정기 회의가 있는 시간에는 컴퓨터를 깨어 있게 둡니다.
4. 마이크 권한이 허용되어 있는지 확인합니다.

## 문제가 있을 때

- 예약 시각에 아무 일도 없었다: 앱이 완전히 종료되어 있었는지, 컴퓨터가 잠자기 상태였는지 확인하세요. 놓친 예약은 대시보드에서 「지금 시작」으로 시작할 수 있습니다.
- 창이 사라져서 못 찾겠다: 메뉴 막대나 시스템 트레이의 또박또박 아이콘을 누르세요.
- 닫기 때마다 묻는 창이 귀찮다: 「다음부터 묻지 않기」를 체크하세요.
- 그 밖의 문제는 [문제 해결](../../help/troubleshooting/)을 보세요.
