새 회의는 「새 회의 만들기」 창에서 만듭니다. 제목과 회의 유형만 정하면 바로 시작할 수 있고, 필요하면 이전 회의 연결, 도메인 파일, 예약 시작까지 한 번에 정할 수 있습니다.

## 창 열기

| 위치 | 단추 |
|---|---|
| 회의 목록(데스크톱) | 오른쪽 위의 「새 회의」 |
| 회의 목록(모바일) | 오른쪽 아래의 둥근 「새 회의」 단추 |
| 대시보드 | 오른쪽 위의 「회의 생성」 |

회의 목록에서 만들면 지금 보고 있는 폴더 안에 회의가 생깁니다. 「전체 회의」를 보고 있을 때나 대시보드에서 만들면 폴더 없는 미분류 회의가 됩니다.

![새 회의 만들기 창](../../../assets/screens/new-meeting-dialog.png)

## 입력 항목

창은 위에서 아래로 다음 순서로 되어 있습니다.

1. 「템플릿」: 저장해 둔 템플릿이 있을 때만 나옵니다.
2. 「회의 제목」
3. 「회의 유형」
4. 「회의 연결해서 진행하기(이전 회의 선택)」
5. 「도메인 파일」
6. 「⏰ 예약 시작」
7. 「이 회의를 모든 사용자에게 공유」
8. 「취소」와 「생성」 단추

### 회의 제목

창이 열리면 제목 칸에 오늘 날짜가 자동으로 들어 있고, 칸 전체가 선택되어 있어서 바로 덮어쓸 수 있습니다. 직접 고치기 전까지는 날짜를 따라갑니다. 예를 들어 예약 시작을 켜고 날짜를 정하면 제목의 날짜도 예약 날짜로 바뀝니다. 한 번이라도 제목을 직접 고치면 그 뒤로는 자동으로 바뀌지 않습니다. 제목이 비어 있으면 「생성」이 눌러지지 않습니다.

### 회의 유형

회의 유형은 AI 회의록의 구성 방식을 정합니다. 유형마다 요약 틀이 다르기 때문에, 회의 성격에 맞는 유형을 고르면 더 알맞은 회의록이 만들어집니다. 기본 유형은 다음과 같습니다.

| 유형 | 쓰임 |
|---|---|
| 일반 회의 | 기본값입니다. 핵심 요약, 참석자, 논의 사항, 결정사항, Action Items 순으로 정리합니다. |
| 팀 회의 | 팀 단위 정기 회의 |
| 개발진행회의 | 개발 일정과 진행 상황 점검 |
| 스탠드업 | 짧은 일일 공유 |
| 브레인스토밍 | 아이디어 모으기 |
| 리뷰/회고 | 결과 점검과 회고 |
| 인터뷰 | 일대일 질의응답 |
| 워크숍 | 길고 활동이 많은 모임 |
| 1:1 미팅 | 두 사람의 면담 |
| 강연 | 한 사람이 이끄는 발표 |
| 교육 | 교육·훈련 과정 |

유형 단추는 둥근 알약 모양이며, 누르면 파란색으로 선택됩니다. 관리자가 회의록 템플릿을 따로 설정해 두었다면 이 목록 대신 그 템플릿의 유형이 보입니다. 유형별 회의록 내용은 [AI 회의록](../../minutes/ai-summary/)을 보세요.

:::note
회의 유형은 나중에 회의 목록의 「정보 수정」에서 바꿀 수 있습니다. 이미 만들어진 회의록은 「회의록 재생성」을 해야 새 유형의 틀로 다시 만들어집니다.
:::

### 템플릿

반복해서 여는 회의(스탠드업, 주간회의 등)는 템플릿으로 저장해 두고 재사용합니다.

- 템플릿 고르기: 「템플릿」 상자에서 저장해 둔 템플릿을 고르면 그 템플릿의 회의 유형이 선택됩니다. 쓰지 않으려면 「템플릿 없이 시작」을 둡니다. 템플릿을 고른 뒤에도 유형이나 다른 항목을 자유롭게 바꿀 수 있습니다.
- 템플릿 저장하기: 녹음 화면 위쪽 도구 줄의 「템플릿으로 저장」 단추를 누르면 「템플릿으로 저장」 창이 열립니다. 「템플릿 이름」(예: 주간 스탠드업)을 입력하고 「저장」을 누릅니다. 저장되면 「템플릿이 저장되었습니다」가 나옵니다. 이 단추는 관리자(로컬 모드에서는 모든 사용자)에게만 보입니다.
- 템플릿 관리: 설정의 「회의록 설정」 탭에 「회의 템플릿」 영역이 있습니다. 저장된 템플릿을 고르는 것은 모든 사용자가 할 수 있지만, 저장·이름 변경·삭제는 관리자(로컬 모드에서는 모든 사용자)만 할 수 있습니다. 이름을 고치거나 지울 수 있고, 저장된 템플릿이 없으면 「저장된 템플릿이 없습니다. …」라는 안내가 보입니다. 자세한 내용은 [회의록 설정](../../settings/meeting/)을 보세요.

### 회의 연결해서 진행하기(이전 회의 선택)

같은 폴더에 있는 이전 회의를 고르면 이번 회의가 그 회의의 이어지는 회의가 됩니다. 이전 회의록을 이어받은 채 그 뒤에 이번 회의 내용을 작성합니다. 정기 회의에서 지난 회의의 결정사항을 이어 갈 때 편리합니다. 목록에는 같은 폴더의 최근 회의가 나오고, 기본값은 「없음」입니다. 자세한 내용은 [연결 회의](../../minutes/linked-meetings/)를 보세요.

### 도메인 파일

도메인 파일은 회의에 쓰이는 전문 용어나 배경 자료를 담은 파일입니다. AI가 전사와 회의록을 만들 때 참고합니다.

- 이미 상속된 파일: 이 회의가 들어갈 폴더나 프로젝트에 지정된 도메인 파일은 「상속된 도메인 파일 (읽기전용)」이라는 이름으로 보입니다. 이름 옆에 「프로젝트: …」 또는 「폴더: …」로 출처가 적힙니다. 따로 고를 필요가 없습니다.
- 이 회의에만 더하기: 「파일 선택」을 눌러 목록에서 고릅니다. 고른 파일은 파란 알약으로 나오고 「×」로 뺄 수 있습니다. 회의가 만들어진 뒤 자동으로 연결됩니다.
- 아무것도 없으면 「선택된 도메인 파일이 없습니다」가 보입니다.

회의는 만들어졌는데 도메인 파일을 붙이지 못했다면 「회의는 생성되었지만 도메인 파일 연결에 실패했습니다.」라고 알려 줍니다. 이때는 회의 상세에서 다시 연결하세요.

### 예약 시작

「⏰ 예약 시작 (지정한 시각에 자동/수동으로 시작)」을 체크하면 날짜, 시각, 시작 방식, 반복 항목이 나타납니다. 체크하지 않으면 지금 바로 시작하는 즉시 회의가 됩니다. 항목별 설명은 [회의 예약](../../schedule/schedule/)에서 자세히 다룹니다.

### 공유 설정

「이 회의를 모든 사용자에게 공유」는 기본으로 체크되어 있습니다. 체크를 풀면 작성자와 관리자만 이 회의를 볼 수 있습니다. 회의가 들어간 폴더가 비공개라면 이 설정과 관계없이 작성자와 관리자에게만 보입니다.

## 회의 만들기

1. 필요하면 템플릿을 고릅니다.
2. 「회의 제목」을 확인하고 필요하면 고칩니다.
3. 「회의 유형」을 고릅니다.
4. 필요하면 이전 회의, 도메인 파일, 예약 시작, 공유 설정을 정합니다.
5. 「생성」을 누릅니다.

생성이 끝나면 다음처럼 이어집니다.

- 즉시 회의(예약을 켜지 않은 경우): 회의 녹음 화면이 열립니다. 이어지는 녹음 방법은 [라이브 녹음](../../recording/live/)을 보세요.
- 예약 회의: 녹음 화면으로 가지 않고 목록에 추가됩니다. 예약 시각이 되면 설정한 방식으로 시작됩니다.

생성에 실패하면 창 위에 「회의 생성에 실패했습니다.」가 나옵니다. 연결 상태를 확인하고 다시 시도하세요.

:::caution
「새 회의 만들기」 창은 바깥 영역을 누르거나 Esc 키를 눌러도 닫히지 않습니다. 입력하던 내용이 실수로 사라지지 않게 하려는 동작이므로, 닫으려면 「취소」를 누르세요.
:::

## 오디오 파일로 회의 만들기

이미 녹음해 둔 오디오 파일이 있다면 「새 회의」 대신 「오디오 업로드」 단추로 시작하는 편이 빠릅니다. 파일을 올리면 새 회의가 만들어지고 전사와 회의록이 이어서 처리됩니다. 자세한 내용은 [오디오 업로드](../../recording/upload/)를 보세요.
