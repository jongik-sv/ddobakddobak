폴더·프로젝트 챗은 회의 한 건이 아니라 폴더 또는 프로젝트에 모인 여러 회의를 한꺼번에 놓고 질문하는 기능입니다. 「지난 분기 회의에서 가격 이야기가 어떻게 바뀌었지?」 같은 질문에 적합합니다.

## 챗 여는 방법

### 회의 목록에서

1. 사이드바의 「회의 목록」을 열고 원하는 폴더를 선택합니다. 폴더를 선택하지 않으면 프로젝트 전체가 대상이 됩니다.
2. 회의 목록 위쪽의 「폴더에게 묻기」 단추를 누릅니다. 모바일에서는 말풍선 모양 아이콘입니다.
3. 화면 오른쪽에서 챗 창이 밀려 나옵니다.

![폴더 챗 창](../../../assets/screens/folder-chat-drawer.png)

### 회의 상세 화면에서

회의 상세 화면 오른쪽 패널의 「AI 챗」 탭에서 범위 선택 줄의 「폴더」 또는 「프로젝트 전체」를 누르면 같은 방식으로 여러 회의를 대상으로 질문할 수 있습니다. 회의가 폴더나 프로젝트에 속하지 않으면 해당 단추가 비활성화됩니다.

## 챗 창 구성

1. 범위 단추: 왼쪽 위에 「이 폴더: 폴더 이름」과 「프로젝트 전체」가 있습니다. 눌러서 질문 범위를 바꿉니다. 폴더를 고르지 않고 열었다면 「프로젝트 전체」만 쓸 수 있습니다.
2. 답변 모델 표시: 오른쪽 위에 실제로 답할 AI 모델 이름이 표시됩니다. 모델은 내 [LLM 설정](../../settings/llm/)을 따릅니다.
3. 「닫기」(X): 창을 닫습니다. 창 바깥의 어두운 부분을 눌러도 닫힙니다.
4. 대화 영역과 입력칸: 아직 질문이 없으면 「이 폴더의 회의들에 대해 물어보세요.」 또는 「이 프로젝트의 회의들에 대해 물어보세요.」가 표시됩니다. 입력칸 안내는 「회의에 질문하기…」이며, 「전송」을 누르거나 Enter로 보냅니다.

데스크톱에서는 창의 왼쪽 가장자리를 마우스로 끌어 폭을 조절할 수 있고(「드래그하여 폭 조절」), 조절한 폭은 다음에도 유지됩니다. 모바일에서는 화면 전체로 열립니다.

## 범위 고르기

| 범위 | 질문 대상 |
|---|---|
| 이 폴더 | 선택한 폴더에 들어 있는 회의들 |
| 프로젝트 전체 | 현재 프로젝트의 모든 회의 |

범위를 바꾸면 범위마다 별도의 대화로 전환됩니다. 폴더에서 한 대화와 프로젝트 전체에서 한 대화는 각각 따로 저장되어 있다가 해당 범위로 돌아오면 이어서 볼 수 있습니다.

:::tip
회의가 많은 프로젝트에서는 가능하면 폴더로 범위를 좁혀 물어보세요. 관련 없는 회의가 섞이지 않아 답이 더 정확해집니다. 폴더 구성은 [사이드바와 폴더](../../projects/sidebar-folders/)를 보세요.
:::

## 질문과 답변

사용법은 [회의 AI 챗](../chat/)과 같습니다. 답변 중 표시, 제안 질문(최대 3개), 「확대 보기」, 「MD 저장」도 동일하게 쓸 수 있습니다.

폴더·프로젝트 챗에서만 다른 점은 인용 배지입니다. 답변에 붙은 시각 배지는 여러 회의 중 어느 회의의 발언인지를 가리키며, 배지를 누르면 그 회의의 상세 화면이 해당 시점으로 열립니다. 이때 챗 창은 닫히지 않고 그대로 유지되므로, 회의 내용을 확인하면서 같은 창에서 다음 질문을 이어갈 수 있습니다.

챗 창은 다른 화면으로 이동해도 열린 상태가 유지됩니다. 대화 내용도 서버에 저장되어, 새로고침하거나 나중에 다시 열어도 이어집니다. 단, 새로고침 직후에는 창이 닫힌 상태에서 시작합니다.

## 알아 두면 좋은 점

- 보이는 범위: 내가 접근 권한을 가진 회의만 답변의 근거가 됩니다. 공유되지 않은 회의의 내용은 답변에 쓰이지 않습니다.
- 정확성: AI 답변은 참고용입니다. 중요한 결정이나 수치는 인용 배지를 눌러 실제 발언으로 확인하세요.

:::note
회의 내용을 단어로 직접 찾으려면 [전역 검색](../search/)이 더 빠르고 정확합니다. 검색으로 후보 회의를 좁힌 뒤 챗으로 요점을 물어보는 흐름을 추천합니다.
:::
