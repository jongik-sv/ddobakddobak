전역 검색은 내가 볼 수 있는 모든 회의의 AI 회의록과 전사 내용에서 단어를 찾는 기능입니다. 「그 이야기가 어느 회의에서 나왔더라」를 기억해 내야 할 때 씁니다.

## 검색 화면 열기

왼쪽 사이드바의 「검색」을 누르면 검색 화면이 열립니다. 열자마자 검색 입력칸에 커서가 놓입니다.

![전역 검색 화면](../../../assets/screens/search-page.png)

1. 검색 입력칸: 「회의록, 기록 내용 검색...」이라는 안내가 보입니다.
2. 「검색」 단추: 검색을 실행합니다. 입력칸에서 Enter를 눌러도 됩니다.
3. 필터 단추(깔때기 모양, 마우스를 올리면 「필터」): 화자·기간·상태 필터를 펼치거나 접습니다.
4. 결과 영역: 검색된 회의가 묶음으로 나열됩니다.

## 검색하는 방법

1. 입력칸에 찾을 단어나 문장을 입력합니다.
2. 「검색」을 누르거나 Enter를 누릅니다.
3. 결과가 회의별로 묶여 나타납니다. 맨 위에 「총 N건의 결과」가 표시됩니다.

입력칸이 비어 있으면 「검색어를 입력하세요.」가, 맞는 내용이 없으면 「검색 결과가 없습니다.」가 표시됩니다. 검색어는 주소에 함께 기록되므로, 검색 결과 화면의 주소를 북마크하면 같은 검색을 다시 열 수 있습니다.

:::tip
짧은 단어 하나보다 회의에서 실제로 쓴 표현을 넣으면 더 정확합니다. 결과가 너무 많으면 아래의 필터로 범위를 줄이세요.
:::

## 검색 결과 읽기

결과는 회의 단위로 묶여 있고, 한 묶음은 다음으로 이루어집니다.

1. 접기/펼치기 화살표: 묶음 안의 상세 결과를 접거나 펼칩니다. 처음에는 펼쳐져 있습니다.
2. 회의 제목: 누르면 그 회의 상세 화면으로 이동합니다. 제목 옆에는 회의 날짜가 표시됩니다.
3. 건수 배지: 「요약 N건」(보라색)과 「기록 N건」(파란색)으로, 그 회의에서 찾은 위치의 수를 보여 줍니다.
4. 결과 항목: 찾은 대목의 앞뒤 문장입니다. 검색어는 노란색으로 강조됩니다.

각 결과 항목 위에는 어디서 찾았는지를 알려 주는 배지가 붙습니다.

| 배지 | 뜻 |
|---|---|
| 요약 | AI 회의록에서 찾은 내용 |
| 기록 | 전사에서 찾은 내용. 화자가 있으면 화자 이름이 함께 표시됩니다 |

회의 제목을 누르면 회의 상세 화면이 열리고, 같은 검색어가 화면 안 검색에 이어져 해당 위치를 바로 찾아볼 수 있습니다. 회의 상세 화면의 검색 막대에는 「전사·요약 검색」 칸과 「이전 매치」, 「다음 매치」 단추가 있고, Enter는 다음, Shift+Enter는 이전, Esc는 닫기입니다.

## 필터로 좁히기

필터 단추를 누르면 입력칸 아래에 필터가 나타납니다. 필터를 정한 뒤 「검색」을 눌러야 적용됩니다.

| 필터 | 설명 |
|---|---|
| 화자 | 「화자 (예: 화자 1)」 칸에 화자 이름을 입력합니다. 해당 화자의 발언만 찾습니다 |
| 기간 | 시작 날짜 `~` 끝 날짜를 고릅니다 |
| 상태 | 「상태 전체」, 「대기중」, 「녹음중」, 「완료」 중에서 고릅니다 |

## 결과가 많을 때

한 번에 20건씩 보여 줍니다. 결과 아래에 이전·다음 단추와 「1 / 5」 같은 쪽 번호가 나타나며, 단추로 쪽을 넘깁니다.

:::note
검색은 내가 접근할 수 있는 회의에서만 이루어집니다. 다른 사람이 공유하지 않은 회의의 내용은 나타나지 않습니다. 회의 한 곳 안에서만 찾고 싶다면 회의 상세 화면의 화면 내 검색을 쓰세요.
:::
