## 6. 작업 규칙

- **구현은 서브에이전트 dispatch.** 메인은 오케스트레이션만, 직접 Edit 금지. 수정 필요 시 재디스패치
- 모델: 문서/코드 = sonnet, 조사 = haiku, 설계 = 미지정
- **커밋·푸시는 명시 요청 시에만**
- **단일 파일 다중 편집은 순차** — 병렬 시 read-modify-write 레이스
- 서브에이전트가 보고 없이 유휴 전환하는 일이 있다 → **결과를 파일로 직접 검증할 것**
- 검증: `bundle exec rspec` · `rubocop` · **`npx tsc -p tsconfig.app.json`**(bare `tsc`는 루트 `files: []`라 거짓 green) · `npx vitest run`
- `db/migrate`에 파일 추가 금지(러닝 Rails dev 서버 전 요청 500)
- 러닝 dev 서버 실요청 / 실 `settings.yaml` 변경 금지
- 실서버는 **읽기 전용 SELECT ＋ 사용자 승인**
