## ⚠️ 소스로 확정 못 한 것 — 사람에게 물어야 하는 것

- **R1/R2/R3 실제 배포 일자** — decisions-final §A-1: "R1은 검증 종료 즉시 배포(**날짜 미확정** — 확정되면 별도 통보)". 소스 어디에도 구체 일자 없음.
- **통지문 실제 송부 여부·일시·수신자·채널** — 송부 이력 표가 완전히 공란. 소스만으로는 "아직 아무도 안 보냈다"까지만 확인 가능.
- **요청2(폴더명 통일) 취소를 D'Flow가 인지하는지** — 우리 쪽에서 수작업을 안 하기로 결정했다는 사실이 D'Flow decisions-final(§4-③ 판정 주체=PMO 전제)이나 notice 어디에도 반영돼 있지 않다. 회신문 정정판에서 명시적으로 알려야 하는지는 소스로 판단 불가.
- **회신문 정정판을 누가 언제 보낼지** — `team-lead-open-decisions-2026-07-28.md` 항목1 그대로 소유자·기한 미정.
- **요청3(#1 매칭 정합성)** — `_AS-IS` vs `_통합`이 같은 회의인지 여전히 PMO 확인 대기. §8 부록 갱신판에 제목이 `260721_글로벌영업담당_임원_인터뷰_통합__2026-07-21`로 바뀌어 있으나, 이것이 확인 완료를 의미하는지 단순 표기 변경인지는 소스만으로 판정 불가.
