## 1. 핵심 진단

- **기능은 다 있는데 '조직이 사야 할 이유'가 없다.** 현행 랜딩은 기능 나열(fgrid 12카드)과 4대 차별점 전달은 잘 하지만, 락인 없음·컴플라이언스 삭제·벤더 종속 해소·도입 비용 같은 **조직 경제성/리스크 프레이밍이 전무**하다.
- **최강 무기가 한 줄 bullet에 묻혀 있다.** 기밀 구간 비가역 파기, .tgz 전체 이관, 다중 오디오 병합, 완전 오프라인 온디바이스 전사, 폴더별 오타사전, CLI 무API키 LLM — 경쟁사(클로바노트·Otter·Teams)에 없는 기능들이 fgrid 한 줄로만 존재하거나(대부분) 아예 없다(CLI 무API키 앵글).
- **히어로가 solution-first다.** "회의는 느는데 기록할 시간은 없다 / 클라우드에 맡기긴 불안하다"는 pain 진술 없이 곧장 해결책으로 들어가고, IT 의사결정자·팀장/PM·셀프호스팅 개발자라는 서로 다른 3개 타깃을 단일 선형 내러티브 하나로 상대하고 있다.
- **CTA가 무차별이다.** 모든 방문자에게 동일한 3버튼(설치가이드/인벤토리/GitHub)이라, 타깃별 다음 행동 유도가 없다.

|---|---|---|---|

### 타깃별 1줄 메시지

- **IT 의사결정자**: "데이터가 외부로 나가는가?"라는 보안 심사 질문에 구조적으로 '아니오' — 외부 전송 경로 자체가 없습니다.
- **팀장/PM**: "저번에 그거 뭐로 하기로 했지?" — 회의록을 뒤지지 말고 프로젝트 전체에 한 줄로 물어보세요.
- **셀프호스팅 개발자**: STT 엔진 8종도, LLM 프로바이더 5종도, 배포 방식도 전부 당신이 고릅니다. 설정 파일 한 줄로 전환.

## 3. 비즈니스 장점 섹션 신설안 — "조직이 안심하는 네 가지 이유" (신규, #trust)

fgrid '권한·보안' 카드 한 칸에 묻힌 항목을 IT 의사결정자용 독립 섹션으로 승격. 4카드 구성:

1. **보안 심사, 구조로 통과** — "음성 인식부터 요약까지 사내 서버·개인 기기 안에서 완결됩니다. 인터넷이 끊겨도 로컬 LLM과 온디바이스 STT로 계속 동작합니다." *(근거: README 로컬 우선, 인벤토리 오프라인 온디바이스 전사 출시됨)*
2. **기밀 발언의 비가역 파기** — "실수로 녹음된 민감 발언은 전사뿐 아니라 원본 오디오까지 되돌릴 수 없게 파기합니다. '삭제 요구에 대응 가능한가'에 실증으로 답합니다." *(근거: `transcript_redaction_service.rb`·`audio_redactor.rb`, redact API)*
3. **락인 없는 데이터** — "회의·폴더·프로젝트를 통째로 .tgz로 백업·이관하고, 요약은 zip으로 일괄 내보냅니다. 데이터가 특정 벤더에 갇히지 않습니다." *(근거: README 내보내기&관리, export/import FK 리맵·롤백 안전)*
4. **AI 공급사에 휘둘리지 않는 LLM** — "프리셋 여러 개를 등록해 전환하고, API 키 없이 CLI로 돌리거나, 완전 내부망 로컬 LLM으로 바꿉니다. 가격·정책 변화에 조직이 종속되지 않습니다." *(근거: `llm_profiles`, claude/gemini/codex CLI 무API키, openai 호환으로 Ollama)*

보조 카피(섹션 하단 1줄): "별도 DB 서버·GPU 증설 없이 SQLite와 데스크톱 앱만으로, GPU 없는 PC에서도 CPU 엔진으로 오늘 바로 파일럿을 시작할 수 있습니다." *(근거: SQLite WAL, whisper_cpp 전 플랫폼 CPU, 자동 감지)*

- 접근통제 라인(협업자 읽기전용·회의 잠금·단일 기기 잠금)은 카드 2에 부제로 흡수 — 별도 카드로 늘리지 않음.

## 7. 하지 말 것

- **미구현 기능 언급 금지**: 감사 로그·2FA·보존정책·거버넌스 번들(전부 '계획'), 발언 점유율 스코어카드, Asana/Notion/Slack/Jira 커넥터, 아웃바운드 웹훅·API 토큰, SRT/VTT 내보내기, 자동 챕터, 번역, catch-me-up. "엔터프라이즈 감사·컴플라이언스 완비" 류 문구 일절 금지 — 소구 한계는 '로컬 저장 + 접근통제(잠금/협업자/파기)'까지.
- **라이선스 과장 금지**: README는 "개인/학습 목적"만 명시. 'MIT'·'오픈소스'·'무료 라이선스' 주장 금지 — "코드 공개"까지만. "구독료 없음" 카피도 금지(아키텍처상 좌석 과금이 없다는 사실 진술로만 축소 가능).
- **정량 수치 발명 금지**: "회의록 시간 X% 절감" 등 실측치가 코드·문서 어디에도 없음. 전부 정성 표현으로.
- **공유코드 20명 오용 금지**: 실시간 참관 동시 상한이지 요금제 좌석이 아님 — "20명까지 무료" 식 카피 금지.
- **Decision Log·Action Item 별도 관리 기능 강조 금지**: 요약 개편(8ed98cb7)으로 action_items 테이블 풀스택 제거됨 — "회의록 md의 Action Items 표"까지만 표현(현행 fgrid 문안은 이미 안전).
- **챗 후속질문 추천**: 인벤토리상 '계획'이나 현행 랜딩에 이미 존재(사실검증 완료 페이지) — 신규 확장 없이 현상 유지, 새 포인트로 만들지 말 것.
- **온디바이스 STT는 Android 전용**임을 문안에서 흐리지 말 것(iOS 포함처럼 읽히면 과장).
