다시 듣지 말고, 회의록에 물어보세요.

모든 전사와 요약은 저장되는 순간 한국어 특화 임베딩(KURE)으로 벡터화됩니다. 정확한 단어가 기억나지 않아도 의미로 찾아내고, AI가 근거를 붙여 답합니다. 전부 우리 서버 안에서 이뤄집니다.

이 회의 → 폴더 전체 → 프로젝트 전체
  • 의미로 찾습니다. 키워드 검색과 벡터 의미검색을 함께 쓰고, LLM이 질문을 여러 검색어로 확장해 놓친 발화까지 끌어옵니다.
  • 범위를 골라 묻습니다. 한 회의부터 폴더·프로젝트 전체까지. "DB는 왜 바꿨지?" 한 줄이면 여러 회의를 넘나들며 답이 옵니다.
  • 답변마다 근거가 붙습니다. 발화 시각·화자 인용을 누르면 그 순간으로, 다른 회의 인용은 그 회의로 이동합니다.
  • 대화가 이어집니다. 후속 질문 제안, 답변 확대보기와 Markdown 저장까지.

조직이 안심하는 네 가지 이유.

보안 심사, 데이터 삭제 요구, 벤더 종속, AI 공급사 리스크. IT 의사결정자라면 꼭 묻는 질문들입니다. 말이 아니라 기능으로 답을 준비했습니다.

보안 심사, 어렵지 않습니다

음성 인식부터 요약까지 사내 서버·개인 기기 안에서 완결됩니다. 인터넷이 끊겨도 로컬 LLM과 온디바이스 STT(Android)로 계속 동작합니다.

기밀 발언은 비가역 파기

실수로 녹음된 민감 발언은 전사뿐 아니라 원본 오디오까지 되돌릴 수 없게 파기합니다. 삭제해 달라고 하면, 정말 삭제됩니다.

협업자는 읽기 전용으로 제한하고, 회의 잠금·단일 기기 잠금으로 접근을 통제합니다.

락인 없는 데이터

회의·폴더·프로젝트를 통째로 .tgz로 백업·이관하고, 요약은 zip으로 일괄 내보냅니다. 데이터가 특정 벤더에 갇히지 않습니다.

AI 공급사에 휘둘리지 않는 LLM

프리셋 여러 개를 등록해두고 상황에 맞게 전환하거나, API 키 없이 CLI로 돌리거나, 아예 내부망 로컬 LLM으로 바꿔 씁니다. 가격이 오르거나 정책이 바뀌어도 끌려다니지 않습니다.

별도 DB 서버 없이 SQLite 하나로 돌고, 데스크톱 앱 설치만으로 오늘 바로 파일럿을 시작할 수 있습니다.

왜 또박또박인가

클라우드 회의록이 못 주는 네 가지.

받아쓰기 정확도는 어디나 비슷해집니다. 진짜 차이는 데이터가 어디 있는지, 회의록을 얼마나 믿을 수 있는지, 팀이 함께 쓸 수 있는지에서 갈립니다.

01

데이터 주권

음성·전사·요약이 우리 인프라 밖으로 나가지 않습니다. 민감한 사내 회의도 안심하고 맡길 수 있습니다.

02

근거 기반

모든 요약과 답변에 발화 시각·화자 근거가 달립니다. AI 환각인지 클릭 한 번으로 확인합니다.

03

교차 회의

한 회의가 아니라 폴더·프로젝트 전체에 질문합니다. 회의가 쌓일수록 팀의 지식도 함께 깊어집니다.

04

모델 자유

STT 엔진 8종·LLM 프로바이더 5종, 설정 파일 한 줄로 전환합니다. Claude·Gemini·Codex CLI를 그대로 붙이면 API 키 발급 없이도 요약·챗이 돌아갑니다. 인터넷이 아예 없어도 쓸 수 있습니다.
