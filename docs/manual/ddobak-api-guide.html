또박또박 사용 설명서

회의 데이터를 내 AI 에이전트의 지식으로

또박또박에 쌓인 회의 전사·요약·회의록을 Claude Code를 비롯한 LLM 에이전트가 읽고 검색하고 기록할 수 있습니다. 개인 API 토큰을 발급하고, 스킬 패키지를 설치하면 준비가 끝납니다.

무엇이 생겼나요

이번 업데이트로 세 가지가 추가되었습니다.

  • 외부 API — /api/ext/v1/* 경로로 회의 목록·전사·요약 조회, 하이브리드 검색(키워드+의미), 회의 등록·노트 작성·요약 재생성을 제공합니다.
  • 개인 API 토큰(PAT) — 설정 화면에서 발급하는 ddbk_로 시작하는 토큰입니다. 내 계정 권한 범위 안에서만 동작하며, 스코프를 좁혀 읽기 전용으로도 만들 수 있습니다.
  • LLM 스킬 패키지 — Claude Code용 스킬(SKILL.md)과 파이썬 CLI, 벤더 중립 가이드(AGENT.md)가 담긴 zip입니다. 설정 화면에서 바로 내려받습니다.

접근 범위는 항상 내 계정이 볼 수 있는 회의(내 소유 + 협업자로 초대된 회의 + 프로젝트의 공유 회의)로 제한되며, 기밀 구간을 절단한 회의는 절단 후 내용만 제공됩니다.

1단계API 토큰 발급

또박또박 웹에 로그인한 뒤 설정 → API 토큰 섹션으로 이동합니다.

토큰 발급 버튼을 누르면 발급 창이 열립니다. 이름은 용도를 알아볼 수 있게 적고(예: "Claude Code 연동"), 스코프는 필요한 것만 남기세요. 기본값은 읽기 4종이 켜져 있고 쓰기는 꺼져 있습니다. 만료일은 기본 90일입니다.

스코프허용되는 것
meetings:read프로젝트·폴더·회의 목록과 회의 상세, 에이전트 노트 조회
transcripts:read회의 전사 전체(화자·타임스탬프 포함)
summaries:read최종 요약(핵심 논의·결정 사항·회의록 마크다운)
search:read전사·요약 하이브리드 검색
meetings:write회의 등록(텍스트 전사·오디오), 에이전트 노트 추가, 요약 재생성

발급을 누르면 토큰 값이 딱 한 번 표시됩니다. 복사해서 안전한 곳에 보관하세요. 창을 닫으면 다시 볼 수 없고, 잃어버리면 폐기 후 새로 발급해야 합니다.

발급된 토큰은 목록에서 이름·마스킹된 값·스코프·만료일·마지막 사용 시각을 확인할 수 있고, 언제든 폐기로 즉시 무효화할 수 있습니다.

2단계LLM 스킬 설치

설치는 다운로드 두 번으로 끝납니다 — 스킬 패키지(zip)와 설정 파일(.env.ddobak). 각각 다운로드가 끝나면 화면에 설치 프롬프트가 나타나는데, 이것을 복사해 Claude Code 같은 LLM 에이전트에 붙여넣으면 압축 해제·파일 배치·연결 확인까지 에이전트가 대신 처리합니다. 폴더 경로를 외울 필요가 없습니다.

2-1 · 스킬 패키지 설치

설정 화면의 LLM 스킬 다운로드 버튼을 누르면 ddobak-skill.zip이 내려오고, 버튼 아래에 설치 프롬프트가 표시됩니다. 복사 버튼으로 복사해 Claude Code에 붙여넣으세요:

방금 다운로드한 또박또박 회의 스킬(ddobak-skill.zip)을 설치해줘.

1. 다운로드 폴더의 ddobak-skill.zip을 스킬 폴더에 풀어줘 — macOS/Linux: ~/.claude/skills/ddobak-meetings/ , Windows: %USERPROFILE%\.claude\skills\ddobak-meetings\
2. 이미 설치되어 있으면 설정 파일(.env.ddobak 또는 env.ddobak)은 보존하고 나머지 파일만 교체해줘
3. 설치 후 스킬 폴더에서 `python3 scripts/ddobak_api.py me`를 실행해 연결을 확인해줘 (Windows는 python). 설정 파일이 없다고 나오면, 또박또박 설정 → API 토큰에서 토큰을 발급하고 .env.ddobak을 받아야 한다고 알려줘

zip에는 아래 파일이 들어 있습니다. 서버 주소가 담긴 설정 파일이 자동으로 동봉되므로 주소를 따로 적을 필요가 없습니다.

파일내용
SKILL.mdClaude Code용 스킬 본문 — 언제·어떻게 회의 데이터를 조회할지 에이전트에게 알려줍니다
scripts/ddobak_api.py파이썬 표준 라이브러리만 쓰는 CLI. 별도 설치 없이 python3만 있으면 동작합니다
AGENT.md벤더 중립 가이드 — Claude가 아닌 LLM 에이전트도 이 문서만 읽으면 연동 가능합니다
README.md사람용 설치 안내
.env.ddobak설정 파일 — 서버 주소는 자동 주입, 토큰은 들어 있지 않습니다

2-2 · 설정 파일(.env.ddobak) 설치

1단계에서 토큰을 발급한 직후 화면의 설정 파일(.env.ddobak) 다운로드 버튼을 누르면 서버 주소와 토큰이 채워진 파일이 내려오고, 마찬가지로 설치 프롬프트가 표시됩니다. 복사해 붙여넣으면 파일 배치와 연결 확인, 토큰이 담긴 다운로드 원본 삭제까지 에이전트가 처리합니다:

방금 다운로드한 또박또박 설정 파일을 회의 스킬 폴더에 설치해줘.

1. 다운로드 폴더에서 .env.ddobak 파일을 찾아줘 (브라우저에 따라 env.ddobak으로 저장되는데, 파일명은 바꾸지 않아도 동작해)
2. 스킬 폴더로 복사해줘 — macOS/Linux: ~/.claude/skills/ddobak-meetings/ , Windows: %USERPROFILE%\.claude\skills\ddobak-meetings\
3. 복사 후 스킬 폴더에서 `python3 scripts/ddobak_api.py me`를 실행해 연결을 확인해줘 (Windows는 python)
4. 확인이 끝나면 다운로드 폴더의 원본 파일은 삭제해줘 (토큰이 평문으로 들어 있어)

두 프롬프트가 모두 성공하면 설치가 끝난 것입니다. Claude Code를 재시작하면 회의 관련 요청에서 스킬이 자동으로 동작합니다.

직접 설치하기 (수동)

LLM에 맡기지 않고 직접 설치하려면 아래 절차를 따릅니다.

  1. zip을 풀어 스킬 폴더로 복사합니다: 
    # macOS / Linux
unzip ddobak-skill.zip -d ~/.claude/skills/ddobak-meetings

# Windows (PowerShell)
Expand-Archive ddobak-skill.zip -DestinationPath "$env:USERPROFILE\.claude\skills\ddobak-meetings"
  2. 발급 화면에서 받은 .env.ddobak 파일을 스킬 폴더 루트(SKILL.md와 같은 위치)에 넣습니다. 서버 주소와 토큰이 미리 채워져 있어 이 한 파일로 설정이 끝납니다. 파일을 안 받았다면 zip에 동봉된 .env.ddobak의 DDOBAK_API_TOKEN= 줄에 1단계 토큰을 직접 적어도 됩니다.
  3. 스킬 폴더에서 python3 scripts/ddobak_api.py me를 실행해 연결을 확인합니다 (Windows는 python).
환경변수도 그대로 씁니다 — DDOBAK_API_URL/DDOBAK_API_TOKEN을 환경변수로 설정해 두면 파일보다 우선 적용됩니다(기존 사용자 호환). 탐색 순서는 환경변수 → 스킬 폴더의 .env.ddobak → 현재 디렉토리의 .env.ddobak 순입니다.
사설 인증서 환경이라면 — 사내 서버가 mkcert 등 사설 인증서를 쓰는 경우 .env.ddobak에서 DDOBAK_API_INSECURE=1 줄의 주석을 해제하면 TLS 검증을 생략합니다. 사내망 전용 옵션입니다.
토큰이 담긴 .env.ddobak은 비밀 파일입니다 — 공유·커밋하지 마세요. macOS/Linux에서는 chmod 600 .env.ddobak을 권장합니다.

3단계스킬 사용법

설치가 끝나면 명령어를 외울 필요가 없습니다. Claude Code에 평소처럼 자연어로 요청하면, 회의와 관련된 요청에서 스킬이 자동으로 동작해 API를 호출하고 그 결과를 근거로 답합니다.

하고 싶은 일이렇게 말해 보세요필요 스코프
지난 회의 내용 찾기"지난주 예산 회의에서 뭐가 결정됐지?"search:read + transcripts:read
회의 목록 확인"물류 폴더에 있는 회의 목록 보여줘"meetings:read
요약 확인"307번 회의 요약해줘" — 진행중 회의라면 실시간 회의록이 나옵니다summaries:read
문서로 만들기"171번 회의 내용으로 보고서 초안을 만들어줘"읽기 3종
로컬에 저장"307번 회의를 마크다운으로 ./notes 폴더에 저장해줘"읽기 3종
메모 남기기"307번 회의에 메모 남겨줘: 다음 주까지 견적 재요청"meetings:write
녹음 올리기"이 녹음 파일(recording.m4a)을 물류 폴더에 회의로 올려줘"meetings:write

여러 회의를 묶는 요청도 됩니다 — "이번 달 물류 회의들을 훑어서 반품 이슈 진행 상황을 정리해줘"처럼 검색·목록·전사를 조합해야 하는 요청도 스킬이 알아서 처리합니다.

스코프가 모자라면 — 요청한 작업에 필요한 스코프가 토큰에 없으면 403 오류가 납니다. "또박또박 토큰 정보 확인해줘"라고 요청해 발급 시 켠 스코프를 점검하고, 부족하면 토큰을 새로 발급하세요.
스킬이 반응하지 않으면 — Claude Code를 재시작했는지, 스킬 폴더 이름이 ddobak-meetings인지 확인하세요. 그래도 반응이 없으면 "또박또박 회의 스킬로 …"처럼 스킬을 직접 언급하면 동작합니다.

4단계다른 LLM 에이전트 연동

Claude가 아닌 에이전트(Codex, Gemini CLI, 자체 에이전트 등)는 zip 안의 AGENT.md를 컨텍스트로 넣어주면 됩니다. REST 계약 전체와 curl 예시가 들어 있어, CLI 없이 HTTP 호출만으로도 동일하게 동작합니다.

$ curl -H "Authorization: Bearer $DDOBAK_API_TOKEN" \
    "$DDOBAK_API_URL/api/ext/v1/search?q=%EC%98%88%EC%82%B0&limit=5"

Claude 앱(claude.ai)은 클라우드에서 실행되어 사내망 서버에 접근할 수 없으므로 이번 버전에서는 지원하지 않습니다. 공개 엔드포인트가 마련되면 추가될 예정입니다.

REST API 요약

모든 요청은 Authorization: Bearer ddbk_... 헤더가 필요합니다.

오류와 제한

코드의미대응
401토큰 없음·무효·만료·폐기토큰 값과 만료일을 확인하고 필요하면 재발급
403스코프 부족 또는 권한 없음토큰 스코프를 확인 — 재시도해도 소용없음
404없거나 내 접근 범위 밖의 회의회의 번호와 계정 권한 확인
409잠긴 회의, 절단된 회의 쓰기, 요약 진행 중상태가 바뀐 뒤 다시 시도
422요청 내용 오류(빈 검색어, 잘못된 폴더, 전사 있는 회의에 오디오 등)요청을 고쳐야 함 — 그대로 재시도 금지
429속도 제한 — 읽기 120회/분, 쓰기 20회/분Retry-After 헤더(초)만큼 대기 후 재시도

보안 수칙

  • 스코프는 최소로. 조회만 한다면 읽기 스코프만 켜세요. 쓰기 스코프는 실제로 회의를 등록할 도구에만 부여합니다.
  • 토큰은 .env.ddobak 파일이나 환경변수로만. 코드·문서·대화 로그에 토큰 평문을 남기지 말고, 토큰이 담긴 설정 파일은 공유·커밋하지 마세요. zip 패키지에는 토큰이 포함되지 않습니다.
  • 유출이 의심되면 즉시 폐기. 설정 화면에서 폐기하면 그 순간부터 모든 요청이 거부됩니다. 어떤 토큰이 어떤 회의를 읽었는지는 서버 감사 로그에 기록됩니다.
  • 토큰은 내 권한을 넘지 못합니다. 협업자로 초대되지 않은 회의, 공유되지 않은 다른 프로젝트의 회의는 토큰으로도 볼 수 없습니다.

부록 · CLI 사용법

스킬 없이 동봉된 CLI(scripts/ddobak_api.py)를 직접 실행할 수도 있습니다. 셸 스크립트나 자동화 파이프라인에 끼워 넣을 때 유용합니다. 모든 명령은 --json을 붙이면 원본 JSON을 출력합니다. Windows에서는 python3 대신 python 또는 py를 사용하세요.

# 연결 확인 — 토큰·스코프·만료일이 나오면 성공
$ python3 scripts/ddobak_api.py me

# 회의 목록 (프로젝트·기간·페이지 필터)
$ python3 scripts/ddobak_api.py meetings --project 9 --page 1
307  기술스택 검토회의 2026.08.07 10시50분  2026-08-12
306  기술스택 검토회의 2026.08.07 10시50분  2026-08-07

# 전사 · 요약 · 검색
$ python3 scripts/ddobak_api.py transcript 307
[00:02] 화자1: 이 동서 클로드 뭐야?
[00:30] 화자1: 그래서 지금 이때까지 이야기한 것은…
$ python3 scripts/ddobak_api.py summary 307
$ python3 scripts/ddobak_api.py search "예산 결정" --limit 5

# 회의를 마크다운 파일로 저장 (상세+전사+요약)
$ python3 scripts/ddobak_api.py dump 307 --out ./meetings
저장됨: ./meetings/기술스택 검토회의 2026.08.07 10시50분.md

# 쓰기 (meetings:write 스코프 필요)
$ python3 scripts/ddobak_api.py create --title "외부 미팅록" --project 9 --transcript-file notes.json

오디오 업로드는 2단계입니다 — 전사가 이미 있는 회의에는 오디오를 올릴 수 없습니다(422). 먼저 create를 전사 파일 없이 실행해 빈 회의를 만들고, 그 회의 번호로 upload-audio를 실행하면 서버가 음성 인식을 시작합니다. 진행 상태는 meeting <id>의 상태 값으로 확인합니다.
